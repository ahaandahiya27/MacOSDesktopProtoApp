**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. "Congruent" means same shape AND same size — never confuse it with "similar" (same shape, any size). The classic traps here are: treating AAA or SSA as congruence rules (they are not), forgetting that SAS needs the *included* angle, and answering the wrong angle in an isosceles triangle. Read every figure description carefully. Do not write on this paper — mark answers on your answer sheet.

1. Two figures are said to be congruent when:
   (A) they have the same shape and the same size
   (B) they have the same area only
   (C) they have the same shape only
   (D) one is an enlargement of the other

2. The symbol used to denote "is congruent to" is:
   (A) ≈
   (B) ≅
   (C) =
   (D) ∼

3. A drawing is photocopied at 150% (enlarged). The copy and the original are:
   (A) congruent
   (B) neither similar nor congruent
   (C) similar but not congruent

4. Which set of equal parts does NOT, by itself, guarantee that two triangles are congruent?

5. Two triangles have all three pairs of corresponding sides equal. The criterion that proves them congruent is:

   (D) nothing — only the equal sides match
