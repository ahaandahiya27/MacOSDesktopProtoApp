**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Remember that 4n means 4 × n (not 4 + n), that only LIKE terms combine (2a + 3b stays as it is, never 5ab), and that l + l = 2l (not l²). When you substitute, keep every sign exactly as given. This chapter is about building and simplifying expressions — never about solving equations. Do not write on this paper — mark answers on your answer sheet.
