Worked Solutions

1. (B) "Twice a number" = 2n; "7 less than" it = 2n − 7. (2(n − 7) would be "7 less than the number, then doubled".)

2. (D) "Thrice a number" = 3x; "5 added" = 3x + 5; "result is 26" → 3x + 5 = 26.

3. (A) 4x − 9 = 11 → 4x = 20 → x = 5.

4. (C) x/3 + 2 = 6 → x/3 = 4 → x = 12. (Dividing 6 by 3 first gives the trap 8.)

5. (C) 7x + 4 = 3x + 20 → 7x − 3x = 20 − 4 → 4x = 16 → x = 4. Check: 7·4 + 4 = 32 = 3·4 + 20. ✓

6. (A) 2(x − 3) = 10 → x − 3 = 5 → x = 8. Check: 2·5 = 10. ✓

7. (D) 3(2x + 1) = 27 → 6x + 3 = 27 → 6x = 24 → x = 4. Check: 3(8 + 1) = 27. ✓

8. (B) (2x − 1)/3 = 5 → 2x − 1 = 15 → 2x = 16 → x = 8. Check: (16 − 1)/3 = 5. ✓

9. (D) 5x − 7 = 2x + 5 → 3x = 12 → x = 4. Check: 20 − 7 = 13 = 8 + 5. ✓

10. (B) Let the integers be n, n + 1, n + 2. Sum = 3n + 3 = 72 → 3n = 69 → n = 23. Largest = n + 2 = 25. (23 is the smallest — a common trap.)

11. (C) Son = s, father = 4s. s + 4s = 50 → 5s = 50 → s = 10. (40 is the father's age.)

12. (A) 4x + 10 = 38 → 4x = 28 → x = 7.

13. (A) breadth = b, length = b + 5. Perimeter 2(b + 5 + b) = 50 → 2(2b + 5) = 50 → 2b + 5 = 25 → 2b = 20 → b = 10. (Length is 15.)

14. (C) Sticks for n squares = 3n + 1. Set 3n + 1 = 31 → 3n = 30 → n = 10. Check: 3·10 + 1 = 31. ✓

15. (B) x + 12 = 3x → 12 = 2x → x = 6.

16. (D) x/2 + x/3 = 10 → multiply by 6: 3x + 2x = 60 → 5x = 60 → x = 12. Check: 6 + 4 = 10. ✓

17. (D) 4(x − 1) = 2(x + 3) → 4x − 4 = 2x + 6 → 2x = 10 → x = 5. Check: 4·4 = 16 = 2·8. ✓

18. (A) 9 − 2x = 3 → −2x = −6 → x = 3. (Sign slips give −3.)

19. (C) n + (n + 2) = 54 → 2n + 2 = 54 → 2n = 52 → n = 26. Check: 26 + 28 = 54. ✓

20. (B) Let t = number of ₹2 coins; then 20 − t are ₹1 coins. 2t + 1·(20 − t) = 35 → t + 20 = 35 → t = 15. Check: 15·2 + 5·1 = 35. ✓

21. (C) Test x = 3: (A) 2·3 + 1 = 7 ≠ 5; (B) 3 − 3 = 0 ≠ 3; (C) 4·3 − 5 = 7 ✓; (D) 3/3 = 1 ≠ 9. So (C).

22. (D) x/4 − 2 = 1 → x/4 = 3 → x = 12.

23. (B) 5 − 2(x − 1) = 1 → 5 − 2x + 2 = 1 → 7 − 2x = 1 → 2x = 6 → x = 3. (The trap is writing 5 − 2x − 2; the bracket flips the sign of −1 to +2.) Check: 5 − 2(2) = 1. ✓

24. (A) Now: Sam = s, Reena = s + 5. In 3 years: (s + 3) + (s + 5 + 3) = 33 → 2s + 11 = 33 → 2s = 22 → s = 11. Check: in 3 years 14 + 19 = 33. ✓

25. (B) 2n + 1 = 25 → 2n = 24 → n = 12. So the 12th term.

26. (A) 3(x + 2) = 2(x + 5) → 3x + 6 = 2x + 10 → x = 4. Check: 3·6 = 18 = 2·9. ✓

27. (D) (x − 3)/2 = (x + 1)/4 → cross-multiply: 4(x − 3) = 2(x + 1) → 4x − 12 = 2x + 2 → 2x = 14 → x = 7. Check: 4/2 = 2 = 8/4. ✓

28. (C) B = b, A = 2b. 2b + b = 120 → 3b = 120 → b = 40. (A gets 80.)

29. (A) 2x + 3 = 3x − 2 → 3 + 2 = 3x − 2x → x = 5. Check: 2·5 + 3 = 13 = 3·5 − 2. ✓

30. (D) x + x + (x + 30) = 180 → 3x + 30 = 180 → 3x = 150 → x = 50. Each equal angle = 50° (third = 80°). ✓

31. (C) 12 − 3x = 2x − 8 → 12 + 8 = 2x + 3x → 20 = 5x → x = 4. Check: 12 − 12 = 0 = 8 − 8. ✓

32. (B) x/5 + 3 = 8 → x/5 = 5 → x = 25.

33. (D) Three consecutive odd numbers average to the middle one, so middle = 81 ÷ 3 = 27. (Numbers: 25, 27, 29.) ✓

34. (C) 2x/3 − x/2 = 1 → multiply by 6: 4x − 3x = 6 → x = 6. Check: 12/3 − 6/2 = 4 − 3 = 1. ✓

35. (A) Child tickets = c, adult = 5 − c. 40(5 − c) + 25c = 155 → 200 − 40c + 25c = 155 → 200 − 15c = 155 → 15c = 45 → c = 3. Check: 3 child (₹75) + 2 adult (₹80) = ₹155. ✓

36. (B) Test x = −2: (B) 2(−2) + 9 = 5 ✓. The others: (A) −5 ≠ 5, (C) −4 ≠ 0, (D) −8 ≠ 8. So (B).

37. (C) 2(3x − 1) = 4(x + 2) → 6x − 2 = 4x + 8 → 2x = 10 → x = 5. Check: 2·14 = 28 = 4·7. ✓

38. (B) 50 + 12k = 158 → 12k = 108 → k = 9.

39. (D) Bina now = 15, so 5 years ago Bina = 10 and Anil = 3·10 = 30. Anil now = 30 + 5 = 35.

40. (A) x/2 + x/4 = 9 → multiply by 4: 2x + x = 36 → 3x = 36 → x = 12. Check: 6 + 3 = 9. ✓

41. (B) 6x − 5 = 4x + 7 → 2x = 12 → x = 6. Check: 36 − 5 = 31 = 24 + 7. ✓

42. (A) Numbers x and x + 6. x + (x + 6) = 30 → 2x = 24 → x = 12. Larger = x + 6 = 18.

43. (C) x + x + (x − 2) = 25 → 3x − 2 = 25 → 3x = 27 → x = 9. Check: 9 + 9 + 7 = 25. ✓

44. (D) 3x/4 = 9 → 3x = 36 → x = 12.

45. (A) Cost of n notebooks = 15n; "after a ₹20 discount" = 15n − 20.

46. (D) units = u, tens = 2u. Digit-sum 2u + u = 9 → 3u = 9 → u = 3, tens = 6 → the number is 63. Check: 6 + 3 = 9 and 6 = 2·3. ✓

47. (B) Test x = 2: (A) 5 = 5 ✓, (B) 2·2 + 3 = 7 ≠ 5 ✗, (C) 6 = 6 ✓, (D) 10 = 10 ✓. The exception is (B).

48. (C) 3 − (2x − 5) = 4 → 3 − 2x + 5 = 4 → 8 − 2x = 4 → 2x = 4 → x = 2. Check: 3 − (4 − 5) = 3 − (−1) = 4. ✓

49. (C) A = a, B = a + 50, C = a + 100. Sum = 3a + 150 = 600 → 3a = 450 → a = 150. Check: 150 + 200 + 250 = 600. ✓

50. (B) 2x − 7 = x + 5 → x = 12. Check: 2·12 − 7 = 17 = 12 + 5. ✓

51. (A) (x − 5)/3 = 2 → x − 5 = 6 → x = 11.

52. (D) Angles x, 2x, 3x. x + 2x + 3x = 180 → 6x = 180 → x = 30. Largest = 3x = 90°.

53. (D) x/2 + 4 = x − 1 → 4 + 1 = x − x/2 → 5 = x/2 → x = 10. Check: 10/2 + 4 = 9 = 10 − 1. ✓

54. (C) (x − 4)/3 = 5 → x − 4 = 15 → x = 19.

55. (B) n + (n+1) + (n+2) + (n+3) = 90 → 4n + 6 = 90 → 4n = 84 → n = 21. Check: 21 + 22 + 23 + 24 = 90. ✓

56. (A) 2(x + 4) − 3 = x + 9 → 2x + 8 − 3 = x + 9 → 2x + 5 = x + 9 → x = 4. Check: 2·8 − 3 = 13 = 4 + 9. ✓

57. (A) daughter = d, mother = d + 26. In 6 years: (d + 26 + 6) = 3(d + 6) → d + 32 = 3d + 18 → 14 = 2d → d = 7. Check: mother 33; in 6 years 39 = 3·13. ✓

58. (B) apples = a, oranges = 30 − a. 8a + 5(30 − a) = 201 → 8a + 150 − 5a = 201 → 3a = 51 → a = 17. Check: 17·8 + 13·5 = 136 + 65 = 201. ✓

59. (D) (2x + 1)/3 = (x + 4)/2 → cross-multiply: 2(2x + 1) = 3(x + 4) → 4x + 2 = 3x + 12 → x = 10. Check: 21/3 = 7 = 14/2. ✓

60. (C) 3x = 2x + 8 → x = 8. Check: 3·8 = 24 = 2·8 + 8. ✓
