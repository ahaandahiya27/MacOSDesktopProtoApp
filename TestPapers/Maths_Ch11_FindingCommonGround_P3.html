1. (D) Factorise: 252 = 2^2 x 3^2 x 7, 378 = 2 x 3^3 x 7, 630 = 2 x 3^2 x 5 x 7. Common primes 2, 3, 7. Take the LOWEST power of each present in all three: 2^1, 3^2, 7^1, giving 2 x 9 x 7 = 126. 63 drops the factor 2; 42 wrongly uses 3^1 instead of 3^2; 18 drops the 7. HCF = 126.

2. (A) 96 = 2^5 x 3, 240 = 2^4 x 3 x 5, 336 = 2^4 x 3 x 7. Lowest powers of common primes: 2^4 and 3^1, so HCF = 16 x 3 = 48. 24 uses 2^3; 16 forgets the shared 3; 12 = 2^2 x 3 takes too low a power of 2. HCF = 48.

3. (D) 8 = 2^3, 9 = 3^2, 12 = 2^2 x 3, 15 = 3 x 5. Highest powers: 2^3, 3^2, 5 = 8 x 9 x 5 = 360. 180 misses one factor of 2 (8 needs 2^3); 720 doubles needlessly; 120 misses one factor of 3 (9 needs 3^2). LCM = 360.

4. (C) 14 = 2 x 7, 21 = 3 x 7, 28 = 2^2 x 7, 35 = 5 x 7. Highest powers: 2^2, 3, 5, 7 = 4 x 3 x 5 x 7 = 420. 210 uses only 2^1; 140 omits the factor 3; 840 doubles needlessly. LCM = 420.

5. (B) 144 = 2^4 x 3^2, 180 = 2^2 x 3^2 x 5, 192 = 2^6 x 3. Lowest common powers: 2^2 and 3^1, so HCF = 4 x 3 = 12. 6 takes 2^1; 36 = 2^2 x 3^2 wrongly keeps 3^2 (192 has only 3^1); 24 = 2^3 x 3 takes too high a power of 2. HCF = 12.

6. (D) 6 = 2 x 3, 8 = 2^3, 10 = 2 x 5, 15 = 3 x 5. Highest powers: 2^3, 3, 5 = 8 x 3 x 5 = 120. 60 = 2^2 x 3 x 5 misses one factor of 2; 240 doubles; 30 = 2 x 3 x 5 misses two factors of 2. LCM = 120.

7. (B) HCF takes the lowest power of each shared prime. For 2: min(2,3)=2; for 3: min(1,2)=1; for 7: min(2,1)=1. HCF = 2^2 x 3 x 7 = 84. The value 3528 is the LCM (highest powers); 1764 wrongly keeps 7^2; 42 wrongly uses 2^1. HCF = 84.

8. (A) LCM takes the highest power of each prime. For 2: max(2,3)=3; for 3: max(1,2)=2; for 7: max(2,1)=2. LCM = 2^3 x 3^2 x 7^2 = 3528. 84 is the HCF (lowest powers); 504 wrongly uses 7^1; the last option adds the exponents instead of taking the maximum. LCM = 3528.

9. (A) A factor 2^a x 3^b x 5^c is a perfect square when a, b, c are all even. a in {0,2} (2 ways), b in {0,2} (2 ways), c in {0} (1 way, since exponent of 5 is only 1). Total = 2 x 2 x 1 = 4: namely 1, 4, 9 and 36. Counting c=1 as allowed gives 6 (wrong, 5 is not squared); counting all factors loosely gives 8; forgetting 1 gives 3. Answer 4.

10. (C) The number of factors is found by adding 1 to each exponent and multiplying: (4+1)(2+1)(1+1) = 5 x 3 x 2 = 30. Adding the exponents (4+2+1=7) and adding the primes is the common error giving 11 or similar; 15 forgets the +1 on one prime; 24 = 4 x 3 x 2 forgets all the +1s. Answer 30.

11. (B) HCF takes lowest powers: 2^2 x 3 x 5 = 60. LCM takes highest powers: 2^3 x 3^2 x 5^2 = 1800. Ratio = 1800/60 = 30. In general LCM/HCF = product of (prime^|difference of exponents|) = 2^(3-2) x 3^(2-1) x 5^(2-1) = 2 x 3 x 5 = 30. Picking 6 uses only two primes; 15 drops the 2; 60 is the HCF itself. Ratio = 30.

12. (B) HCF x LCM = product of the numbers: 9 x 360 = 45 x other, so other = 3240/45 = 72. Check HCF(45,72)=9, LCM=360. 40 = 360/9 confuses LCM/HCF with the number; 8 is the cofactor 72/9, not the number; 81 has LCM 405 with 45. Answer 72.

13. (D) Write a = 16m, b = 16n with HCF(m,n) = 1, and LCM = 16mn = 240 so mn = 15. Co-prime factorisations of 15: (1,15) and (3,5). That gives pairs (16,240) and (48,80). So 2 pairs. (3,5) and (1,15) are the only co-prime splits; (5,3) repeats. Counting ordered pairs gives 4; missing one split gives 1. Answer 2.

14. (D) Let the numbers be 5k and 7k. Since 5 and 7 are co-prime, HCF = k and LCM = 5 x 7 x k = 35k. So 35k = 700, k = 20. The numbers are 100 and 140; the larger is 140. 100 is the smaller; 700 is the LCM itself; 35 = 35 x 1 ignores k. Larger number = 140.

15. (A) HCF x LCM = product: 20 x 1200 = 24000 = 80 x other, so other = 24000/80 = 300. Check HCF(80,300)=20, LCM=1200. 240 = 1200/(60) is a guess; 60 = 1200/20 confuses formula; 1200 is the LCM. Answer 300.

16. (C) Product of two numbers = HCF x LCM = 12 x 504 = 6048. 516 = 12 + 504 adds instead of multiplying; 42 = 504/12 is the LCM/HCF ratio; 6000 is a rounding slip. Product = 6048.

17. (B) Write 6m and 6n with co-prime m, n and 6mn = 90 so mn = 15 = 3 x 5. Co-prime pair (3,5) gives 18 and 30, both between 10 and 50. (1,15) gives 6 and 90, outside the range. 12 and 45 do not both share HCF 6 (45 is not even). 30 and 90 have HCF 30. Answer 18 and 30.

18. (A) Largest equal row dividing both is the HCF. 1024 = 2^10, 768 = 2^8 x 3. Lowest common power of 2 is 2^8 = 256 (the 3 is not shared). 128 = 2^7 is common but not greatest; 512 = 2^9 does not divide 768; 192 = 2^6 x 3 does not divide 1024. Answer 256.

19. (B) In cm: 700, 1260, 1680. 700 = 2^2 x 5^2 x 7, 1260 = 2^2 x 3^2 x 5 x 7, 1680 = 2^4 x 3 x 5 x 7. Common primes 2, 5, 7 at lowest powers: 2^2 x 5^1 x 7^1 = 4 x 5 x 7 = 140. So 140 cm. 70 uses 2^1; 35 drops the 4; 280 = 2^3 x 5 x 7 takes too high a power of 2. Answer 140 cm.

20. (D) Need HCF of 391, 425, 527. 391 = 17 x 23, 425 = 5^2 x 17, 527 = 17 x 31. The only common prime is 17. HCF = 17. 23 divides only 391; 19 divides none; 13 divides none. Answer 17.

21. (B) In cm: 864 and 432. The largest tile is the HCF. Since 432 divides 864 exactly (864 = 2 x 432), the HCF is 432. So tiles are 432 cm square: the room is 2 tiles by 1 tile. 144, 216 and 108 are smaller common divisors but not the greatest. Answer 432 cm.

22. (A) Need HCF of 403, 434, 465. 403 = 13 x 31, 434 = 2 x 7 x 31, 465 = 3 x 5 x 31. The only common prime is 31. HCF = 31. 13 divides only 403; 11 divides none; 7 divides only 434. Answer 31 L.

23. (B) HCF of 504, 630, 756. 504 = 2^3 x 3^2 x 7, 630 = 2 x 3^2 x 5 x 7, 756 = 2^2 x 3^3 x 7. Common primes 2, 3, 7 at lowest powers: 2^1 x 3^2 x 7 = 2 x 9 x 7 = 126. 63 drops the 2; 42 uses 3^1; 18 drops the 7. Answer 126.

24. (A) Meeting time = LCM. 84 = 2^2 x 3 x 7, 105 = 3 x 5 x 7, 140 = 2^2 x 5 x 7. Highest powers: 2^2, 3, 5, 7 = 4 x 3 x 5 x 7 = 420. 210 drops a factor of 2; 840 doubles; 329 is the sum. Answer 420 seconds.

25. (D) LCM of 5, 6, 8, 9: 5, 2 x 3, 2^3, 3^2 -> 2^3 x 3^2 x 5 = 360 seconds = 6 minutes. So they next toll together exactly at 360 s, the very end of 6 minutes — that is 1 time (excluding the start). 2 or 3 would need a shorter LCM. Answer 1.

26. (C) LCM of 16, 24, 40. 16 = 2^4, 24 = 2^3 x 3, 40 = 2^3 x 5. Highest powers: 2^4 x 3 x 5 = 16 x 15 = 240. 120 = 2^3 x 3 x 5 uses too low a power of 2; 480 doubles; 80 = 2^4 x 5 drops the 3. Answer 240 seconds.

27. (C) LCM of 9, 15, 25. 9 = 3^2, 15 = 3 x 5, 25 = 5^2. Highest powers: 3^2 x 5^2 = 9 x 25 = 225 minutes = 3 h 45 min. 12:00 + 3:45 = 3:45 pm. 2:15 = 135 min misses a factor; 6:15 = 375 min overshoots; 1:15 = 75 min is too short. Answer 3:45 pm.

28. (C) Meeting time = LCM(48, 60, 72). 48 = 2^4 x 3, 60 = 2^2 x 3 x 5, 72 = 2^3 x 3^2. Highest powers: 2^4 x 3^2 x 5 = 16 x 9 x 5 = 720 s. A's laps = 720/48 = 15. 12 = 720/60 is B's laps; 6 is a slip; 20 confuses. A has done 15 laps.

29. (D) Next alignment = LCM(35, 45). 35 = 5 x 7, 45 = 3^2 x 5. Highest powers: 3^2 x 5 x 7 = 9 x 5 x 7 = 315. 1575 = 35 x 45 wrongly takes the product (they are not co-prime, sharing factor 5); 9 = 45/5; 630 doubles. Answer 315 minutes.

32. (A) Product = 8 x HCF^2 = 8 x 81 = 648. LCM = product/HCF = 648/9 = 72. Equivalently LCM = 8 x HCF = 72 since product = HCF x LCM = 8 x HCF^2. 648 is the product, not LCM; 81 = HCF^2; 9 is the HCF. LCM = 72.

33. (C) Product = HCF x LCM = 23 x 1449 = 33327 = 207 x smaller, so smaller = 33327/207 = 161. Check HCF(161,207): 161 = 7 x 23, 207 = 9 x 23, HCF = 23, LCM = 7 x 9 x 23 = 1449. 63 and 69 do not pair correctly; 1449 is the LCM. Smaller = 161.

34. (A) LCM = 12 x HCF = 12 x 8 = 96. Product = HCF x LCM = 8 x 96 = 768. 104 = 8 + 96 adds; 96 is the LCM only; 12 is the multiple factor. Product = 768.

35. (A) For co-prime numbers the HCF is 1, so LCM = product/HCF = 391/1 = 391. (Here 391 = 17 x 23, two co-primes.) 1 is the HCF; 17 and 23 are the individual numbers. LCM = 391.

36. (C) First find LCM(24, 36, 54). 24 = 2^3 x 3, 36 = 2^2 x 3^2, 54 = 2 x 3^3. Highest powers: 2^3 x 3^3 = 8 x 27 = 216. The smallest such number is LCM + remainder = 216 + 7 = 223. 216 forgets to add 7; 209 = 216 - 7 subtracts; 231 = 224 + 7 uses a wrong LCM. Answer 223.

37. (C) When the same remainder is left, the number divides the differences. 1868 - 1356 = 512, 2764 - 1868 = 896, 2764 - 1356 = 1408. HCF of 512 (2^9), 896 (2^7 x 7), 1408 (2^7 x 11) = 2^7 = 128. 64 = 2^6 is common but not greatest; 256 = 2^8 does not divide 896; 32 = 2^5 is too small. Answer 128.

38. (C) The number minus 3 is divisible by 5, 6 and 8, so it is a multiple of LCM(5,6,8). 6 = 2 x 3, 8 = 2^3, 5 = 5: LCM = 2^3 x 3 x 5 = 120. Smallest such number above 3 is 120 + 3 = 123. 120 forgets the +3; 117 = 120 - 3; 240 is the next multiple. Answer 123.

39. (D) The number minus 4 must be a multiple of LCM(6,9,12). 6 = 2 x 3, 9 = 3^2, 12 = 2^2 x 3: LCM = 2^2 x 3^2 = 36. Largest 3-digit multiple of 36 is 972 (36 x 27). Add 4: 976, still 3-digit. 972 forgets the +4; 964 uses a wrong multiple; 940 is not of the right form. Answer 976.

40. (A) We need LCM(15, 25, 35) then subtract 9. 15 = 3 x 5, 25 = 5^2, 35 = 5 x 7: LCM = 3 x 5^2 x 7 = 525. The number is 525 - 9 = 516. 525 forgets the -9; 534 = 525 + 9 adds instead; 491 uses a wrong LCM. Answer 516.

41. (B) Pairwise co-prime means each pair shares no prime factor. 8 = 2^3, 9 = 3^2, 25 = 5^2 share no primes pairwise — co-prime. In 6,10,15 each pair shares a factor (2, 3 or 5). In 4,9,12: 4 and 12 share 4. In 12,25,15: 12 and 15 share 3. Answer 8, 9 and 25.

42. (A) Numbers divisible by both 8 and 9 are exactly the multiples of LCM(8,9). Since 8 and 9 are co-prime, LCM = 72. So such a number is always divisible by 72. 17 = 8 + 9 adds; 36 = LCM(4,9) is too small (e.g. 72 is divisible by 8 and 9 but 36 only divides 72, while 72 always divides — yet not every multiple of 8 and 9, like 72 itself, fails 36? 72 is divisible by 36, but the guaranteed divisor is 72); 144 is not guaranteed (72 is divisible by 8 and 9 but not 144). Answer 72.

43. (A) Since the numbers are co-prime, their product equals their LCM and each is built from distinct primes. Factor 1147 = 31 x 37, both prime, hence co-prime and both above 1. 1 and 1147 fails the 'greater than 1' condition; 29 x 39 = 1131, not 1147; 23 x 49 = 1127, not 1147. Answer 31 and 37.

44. (D) If a and b share no prime factor, then a^2 and b^2 also share no prime factor, so their HCF is 1. Squaring cannot create a new common prime. The options a, b, ab assume a shared factor that does not exist. Answer 1.

45. (B) Divisible by 11 and 6 means divisible by LCM(11,6) = 66 (since 11 and 6 are co-prime). It need not be divisible by 4, so we cannot claim 44 = 11 x 4 or 132 = 11 x 12. 22 = 11 x 2 is guaranteed but is not the largest guaranteed divisor; the question asks for what it is always divisible by from the list, and 66 is the LCM. Answer 66.

46. (C) n must be a common multiple of 12 and 18; the smallest is LCM(12,18). 12 = 2^2 x 3, 18 = 2 x 3^2: LCM = 2^2 x 3^2 = 36. 6 is the HCF (a divisor, not a multiple); 216 = 12 x 18 takes the product; 72 is a larger common multiple. Smallest n = 36.

47. (B) Common factors are factors of HCF(144,192). 144 = 2^4 x 3^2, 192 = 2^6 x 3: HCF = 2^4 x 3 = 48. Number of factors of 48 = (4+1)(1+1) = 5 x 2 = 10. 6 forgets a +1; 8 miscounts; 12 uses a wrong HCF. Answer 10.

48. (D) Let a = 6m, b = 6n, HCF(m,n) = 1, and LCM = 6mn = 90 so mn = 15. Co-prime splits of 15: (1,15) and (3,5), giving (6,90) and (18,30). So 2 unordered pairs with a<b. Counting ordered gives 4; missing a split gives 1. Answer 2.

49. (B) 360 = 2^3 x 3^2 x 5. Total factors = (3+1)(2+1)(1+1) = 24. Odd factors come from 2^0: (2+1)(1+1) = 6. Even factors = total - odd = 24 - 6 = 18. 24 counts all; 12 halves wrongly; 6 is the odd count. Answer 18.

50. (B) Common multiples of 4 and 6 are multiples of LCM(4,6) = 12. Multiples of 12 up to 100: 12, 24, 36, 48, 60, 72, 84, 96 — that is 8 numbers. 16 counts multiples of 6; 25 counts multiples of 4; 4 undercounts. Answer 8.

51. (B) Since 1 divides everything, LCM(1, n) = n and HCF(1, n) = 1. So the LCM equals the other number n. LCM = 1 only if both were 1; n^2 and n+1 misapply the formula. Answer LCM = n.

52. (D) Write a = 7m, b = 7n with co-prime m, n and mn = 11 x 13 = 143. Co-prime splits of 143 = 11 x 13: (1,143) and (11,13). That gives pairs (7,1001) and (77,91). So 2 pairs. In general the count is 2^(k-1) where k = number of distinct primes in LCM/HCF; here k = 2, so 2. Answer 2.

53. (C) Plot side = HCF(1054, 952). 1054 = 2 x 17 x 31, 952 = 2^3 x 7 x 17. Common: 2 x 17 = 34. So plots are 34 m square. Along the 1054 m side: 1054/34 = 31 plots. 28 = 952/34 is along the shorter side; 17 and 34 confuse the side length with the count. Answer 31.

54. (C) All toll together every LCM(6,8,12) = 24 seconds (6 = 2x3, 8 = 2^3, 12 = 2^2x3 -> 2^3 x 3 = 24). In 3600 seconds the simultaneous tolls occur at 0, 24, 48, ... up to 3600. Count = 3600/24 + 1 = 150 + 1 = 151. 150 forgets the start toll; 75 halves; 301 double counts. Answer 151.

55. (B) Write the numbers as 33a and 33b with co-prime a, b. Then 33(a + b) = 528, so a + b = 16. Co-prime pairs summing to 16 with a < b: (1,15),(3,13),(5,11),(7,9). That is 4 pairs. Pairs like (2,14),(4,12) share a factor; (8,8) is not distinct/co-prime. Answer 4.

56. (D) All three toll together again after LCM(4, 7, 14) seconds. Since 14 = 2 x 7 and 4 = 2 x 2, LCM(4,7,14) = 28 s. The first bell tolls every 4 s, at t = 4, 8, 12, 16, 20, 24, 28. Excluding the toll at t = 0 and including the simultaneous toll at t = 28, that is 28 ÷ 4 = 7 tolls. Answering 14 uses the wrong interval (the 2-second half-step); 4 just repeats an interval; 28 is the cycle length in seconds, not a count.

57. (D) Using HCF x LCM = product: 8 x 96 = 768 = n x 24, so n = 768/24 = 32. Check: HCF(32,24)=8, LCM(32,24)=96, and 32 is two-digit. 16 has LCM 48 with 24; 48 has HCF 24 with 24; 8 is the HCF itself. Answer 32.

58. (A) Let the numbers be 4k and 9k. Since 4 and 9 are co-prime, the HCF is k and the LCM is 4 x 9 x k = 36k. So 36k = 180 gives k = 5, which is the HCF. The numbers are 20 and 45. 20 and 45 are the numbers themselves, not the HCF; 36 = 36 x 1 ignores k. HCF = 5.

59. (D) The number minus 1 must be divisible by 2, 3, 4, 5 and 6, so it is a multiple of LCM(2,3,4,5,6). 4 = 2^2, 6 = 2x3, 5 = 5, 3 = 3: LCM = 2^2 x 3 x 5 = 60. Smallest such number above 1 is 60 + 1 = 61. 60 forgets the +1; 31 uses a wrong LCM; 121 is the next multiple plus 1. Answer 61.

60. (C) In cm: 300, 510, 1275. HCF: 300 = 2^2 x 3 x 5^2, 510 = 2 x 3 x 5 x 17, 1275 = 3 x 5^2 x 17. Common primes 3 and 5 at lowest powers: 3 x 5 = 15. So 15 cm. 5 takes only the 5; 17 divides 510 and 1275 but not 300; 85 = 5 x 17 does not divide 300. Answer 15 cm.
