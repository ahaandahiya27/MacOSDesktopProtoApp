1. Three readers each defend a different parsing of वन्दे: (i) a passive 'is saluted', (ii) an optative 'may I salute', (iii) an indicative present 'I salute'. Which single grammatical fact, drawn from the form alone, simultaneously eliminates the passive AND the optative reading the chapter teaches?
(A) वन्दे is genuinely a passive whose subject is 'the Mother', so only the optative reading is wrong.(B) वन्दे is a present-indicative ātmanepada finite verb carrying the agent 'I' and asserting the action as a fact now — it has neither the passive marker that would make the Mother the agent nor the mood-marker of a wish, so both rival readings are ruled out by the same form.(C) वन्दे has no person built into it, so it could equally be any of the three and grammar cannot decide.(D) वन्दे is an imperative addressed to the Mother, so 'be saluted' is right and only the indicative is excluded.
2. A learner reasons: 'मातरम् is the object, and the dictionary lists माता; so to make the object I just append -म् to माता, giving मातम्.' Two separate things are wrong here. Which option names BOTH?
(A) मातम् is actually correct; the only error is that वन्दे should govern the nominative माता instead.(B) Both steps are fine; the sole error is that the object should be the dual मातरौ.(C) The base for case-endings is the stem मातृ (not the nominative माता), and the accusative singular of this ऋ-stem is मातरम् — formed by strengthening मातृ to मातर- then adding -म्; so the learner used the wrong base (the nominative form) and skipped the required stem-strengthening.(D) The base माता is correct, but the ending should be -आम्, giving मातआम्.
3. मातरम् (acc. sg.) and मातरौ (acc. du.) share the strengthened piece मातर-. A student concludes 'therefore -म् marks singular and -औ marks dual as endings tacked on मातर- in the same way.' What subtle correction does the chapter's declension actually require?
(A) The student is wrong: मातरौ is built on a different stem मातार-, not मातर-, so the two do not share a base.(B) The student is wrong: -औ is a plural ending, so मातरौ means more than two mothers.(C) Both forms do ride on the strengthened stem मातर-, and there the student is right; the genuine subtlety is only that -म् is the accusative-SINGULAR marker while -औ is the accusative-DUAL marker, so number is read off the ending while the strengthened stem is shared — the student's description is essentially correct.(D) The student is wrong: -म् is the nominative ending, so मातरम् is the subject form.
4. The chapter says वन्दे governs an accusative object while नमः can be construed with a dative. A student infers: 'so every verb meaning salute takes accusative, and every indeclinable meaning salute takes dative.' Why is this generalisation unsafe even within the chapter's logic?
(A) Because नमः is actually a verb and वन्दे an indeclinable, so the student's labels are swapped but the rule holds.(B) Because both वन्दे and नमः really take the genitive, so neither part of the generalisation is correct.(C) Because the dative and accusative are the same case in Sanskrit, so the distinction the student draws does not exist.(D) Case-government is a lexical property of each particular word, not of the meaning 'salute' or of the word's part of speech as a class — the chapter shows वन्दे (a verb) demanding accusative and नमः (an indeclinable) licensing dative as two specific facts, from which no blanket rule keyed to meaning or to verb-versus-indeclinable can be safely projected.
5. From वन्दे ('I salute', 1 sg. ātmanepada) the third singular is वन्दते and the first plural is वन्दामहे. A student must produce 'they (all) salute'. Choosing among वन्दे, वन्दते, वन्दामहे and वन्दन्ते, which is correct, and why is each rejected form rejected by a DIFFERENT mismatch?
(A) वन्दामहे is correct for 'they salute'; the others are all simply singular forms.(B) वन्दते is correct for 'they salute'; -ते is the plural ending here.(C) वन्दन्ते is correct for 'they salute' (3rd plural); वन्दे is rejected as 1st singular ('I'), वन्दते as 3rd singular ('he/she'), and वन्दामहे as 1st plural ('we') — each wrong option fails on a distinct person-or-number value.(D) वन्दे is correct for 'they salute'; in ātmanepada the 1st-singular form doubles as the 3rd plural.
6. सिञ्चन्ति ('they water') ends in -अन्ति (parasmaipada) while वन्दते ('he/she salutes') ends in -ते (ātmanepada), yet both are third person. A learner says: 'since both are third person, the endings should match; the difference must mark tense, not person.' Correct the reasoning.
(A) Correct: the endings differ because सिञ्चन्ति is present and वन्दते is past tense.(B) Correct: Sanskrit has only one ending-set, so -अन्ति and -ते must be two persons, third and second.(C) The learner is right that endings should match; वन्दते is therefore a misprint for वन्दन्ति.(D) Both endings do mark third person, but they belong to two different sets of personal endings (parasmaipada -अन्ति vs ātmanepada -ते) selected by the verb's class/pada — so the difference reflects which ending-set the root takes, not a difference of tense.
7. A student writes वन्दे सुजला सुफला सस्यश्यामला माता, then writes वन्दे सुजलाम् सुफलाम् सस्यश्यामलाम् मातरम्. The chapter calls the first wrong on a SINGLE underlying ground covering all four words. What is that ground, stated as a principle rather than a list?
(A) The single ground is that all four words should be instrumental, since they describe the means by which the Mother is honoured.(B) As the object of वन्दे, the noun must stand in the accusative, and every adjective agreeing with it must copy that case, number and gender — so the lone principle 'agreement of the qualifiers with the accusative head' simultaneously requires मातरम् and all three adjectives to be accusative, which the first version violates by leaving them in their nominative citation forms.(C) There is no single ground; the noun is wrong for one reason (object-case) and the adjectives for an unrelated reason (gender).(D) The single ground is that वन्दे takes no object, so all four should remain nominative as in the first version.
8. पर्वतराजः is read पर्वतानाम् राजा ('king of mountains'), a तत्पुरुष naming its own head (a king). नीलकण्ठः ('blue-throated', a name of Shiva) names not a throat or a colour but an outside person who HAS a blue throat. Using these as models, classify देशभक्तः and identify why it is NOT of the नीलकण्ठः type.
(A) देशभक्तः is a बहुव्रीहि like नीलकण्ठः, because it points to a country outside the compound that the devotee belongs to.(B) देशभक्तः is a तत्पुरुष like पर्वतराजः: its head भक्तः names exactly what the whole denotes (a devotee, qualified as country-directed), so it points INSIDE itself — unlike नीलकण्ठः, a बहुव्रीहि that points to an outside bearer, देशभक्तः does not denote some third thing 'possessing' a country-devotee.(C) देशभक्तः is a द्वन्द्व meaning 'country and devotee', two coordinated nouns, so it names neither member as head.(D) देशभक्तः and नीलकण्ठः are both तत्पुरुष, since each simply names its first member.
9. रत्नाकरः = रत्नानाम् आकरः ('mine of jewels') and names the ocean, yet the word समुद्र never appears. A student concludes 'so रत्नाकरः must secretly contain the letters of समुद्र.' Replace this with the correct account of how the epithet refers.
(A) It refers by DESCRIPTION: its members ('jewels' + 'store/mine') name a characteristic property of the ocean, and the reader decodes the intended referent from that sense plus context — there is no hidden copy of समुद्र inside the word at all.(B) It refers because रत्नाकरः is merely an alternative spelling of समुद्र with identical letters rearranged.(C) It refers because Sanskrit poetry forbids the word समुद्र, so a legally required substitute is inserted.(D) It refers because आकरः by itself already means 'ocean', and रत्न- is only decorative.
10. कृषकबान्धवाः is glossed 'farmer-brethren'. A student claims the plural ending sits on the head AND that the head is the member naming the broad category 'brethren', so the compound denotes brethren who happen to be farmers. Evaluate both halves of the claim.
(A) The head is correctly बान्धव, but the plural ending actually sits on कृषक, giving कृषकाः-बान्धव.(B) Both halves are right: in this तत्पुरुष the head is the last member बान्धव ('brethren'), which carries the nominative-plural ending -आः, and कृषक merely qualifies it — so the compound denotes brethren (the kinsmen) characterised as farmers.(C) The head is कृषक (the first member), so the compound denotes farmers who are merely brotherly, and the plural marks those farmers.(D) Neither member is head; this is a द्वन्द्व 'farmers and brethren', so both members would independently take plural endings.
11. सस्यश्यामला is split सस्य + श्यामला, an instrumental-type तत्पुरुष 'dark-green BY/WITH crops'. Applying the SAME relation, the coined word तपःकृशा (तपस् + कृशा) about an ascetic woman would most naturally mean:

12. समुद्रः भारतमातुः चरणौ प्रक्षालयति packs three roles. A student labels समुद्रः accusative (because it is first), चरणौ nominative (because -औ 'looks like a subject ending'), and भारतमातुः instrumental (because it precedes the object). Correct ALL THREE at once.
(A) समुद्रः nominative subject, चरणौ accusative dual, भारतमातुः instrumental means — only the third label was wrong.(B) समुद्रः accusative object, चरणौ nominative subject, भारतमातुः genitive — only the first two were wrong.(C) समुद्रः is the nominative subject (the doer), चरणौ is the accusative dual (the two feet, the thing washed), and भारतमातुः is the genitive of possession ('whose feet') — none of the student's three labels is right.(D) समुद्रः instrumental means, चरणौ genitive dual, भारतमातुः nominative subject — all three differ from the student but in this way.
13. The chapter expresses 'the Motherland's feet' as भारतमातुः चरणौ with a genitive possessor. Now consider the invented देवाः भारतमातुः वन्दनम् कुर्वन्ति ('the gods perform salutation of the Motherland'). The SAME genitive भारतमातुः appears, yet वन्दे मातरम् uses the accusative. What single distinction explains why the SAME idea (salute the Motherland) takes different cases here?
(A) What governs the case is the word the noun depends on: the finite verb वन्दे directly takes its object in the accusative (मातरम्), whereas the action-NOUN वन्दनम् takes a genitive complement ('salutation OF the Motherland'), so भारतमातुः is genitive — the difference is verb-government vs noun-complement, not a change in meaning.(B) The difference is that भारतमातुः is plural here and मातरम् singular, so number forces different cases.(C) The difference is that कुर्वन्ति is passive while वन्दे is active, so the object switches to genitive under the passive.(D) There is no real difference; भारतमातुः in the gods-sentence is actually accusative, just spelled like a genitive.
14. चरणौ ('two feet') and a hypothetical चरणाः ('many feet') differ only in the ending. A student says: 'since a person has exactly two feet, चरणौ and चरणाः would mean the same in practice, so the ending is redundant here.' Why does the chapter's dual/plural distinction make the ending NOT redundant?
(A) Because Sanskrit has no plural for body-parts, चरणाः is impossible, so only the dual exists and the ending is trivially forced.(B) Because the dual and plural endings are identical in Sanskrit, the student is right that the choice is redundant.(C) Because -औ here is actually a singular, naming one foot, so it does differ from a plural but not as a dual.(D) Sanskrit grammatically marks 'exactly two' (dual -औ) distinctly from 'three or more' (plural), so चरणौ asserts precisely the pair of feet while चरणाः would assert three-or-more — the ending carries number information the meaning does not supply, and choosing dual is what correctly fits a two-footed referent.
15. स्वेदबिन्दुभिः सिञ्चन्ति uses instrumental -भिः. A learner argues: 'the drops do the watering, so the drops are the real agent; -भिः must therefore be marking the subject.' Untangle the roles the chapter assigns.
(A) Correct: the drops are the agent, so -भिः is the agent-marker and the farmers are only the location of the action.(B) The grammatical subject (agent) is the farmers, carried by the verb सिञ्चन्ति and the nominative कृषक(बान्धव)-, while स्वेदबिन्दुभिः is the instrumental MEANS ('by means of sweat-drops') — the drops are the instrument the agents use, not the agent, so -भिः marks means and not the subject.(C) The drops are the object being watered, so -भिः is accusative, and the farmers water the drops.(D) The drops are the possessor, so -भिः is genitive ('of the drops'), and the watering has no stated means.
16. आनन्द ('bliss') has a long आ; carelessly shortening it yields the spurious अनन्द. A learner generalises: 'so only the आ/अ pair is meaning-bearing; the इ/ई and उ/ऊ pairs are just spelling variants.' Apply the chapter's मात्रा principle to judge this.
(A) Correct: only आ/अ carries meaning because आ is the sole vowel with two मात्राः; इ, ई, उ, ऊ all share one मात्रा.(B) Wrong, but only because इ and उ have no long counterparts, so the pairs the learner names do not exist.(C) Every short/long pair differs by duration (one मात्रा vs two) and is meaning-bearing, not just आ/अ — so इ vs ई and उ vs ऊ are likewise distinct sounds that can change a word's identity, and the learner's restriction to a single pair is wrong.(D) Correct in spirit: length matters for आ but for इ/उ it changes only gender, never the core meaning.
17. A student splits रत्नाकरः as रत्न + आकरः and asks why the seam shows a single long आ rather than two separate vowels अ + आ. What does the chapter's view of joins predict here?
(A) The seam shows आ because आकर actually begins with आ and रत्न ends in a consonant, so no fusion happens and the vowels never met.(B) The seam shows आ because अ + आ fuses to ए, which is then written as आ for short.(C) The seam shows आ by accident of spelling; there is no rule, so the split cannot be recovered.(D) At the seam रत्न(अ) + आकर, a final short अ meets an initial long आ and they coalesce into a single long आ (अ + आ → आ); so the visible long आ is the fused outcome, and to split the compound one restores the underlying boundary by undoing that vowel-fusion.
18. The poem builds Himalaya-as-crown, ocean-washing-feet, crop-green body, and holy places. A reader proposes: 'these are four independent compliments that could be reordered or dropped without affecting the central figure.' Why does the chapter's reading resist this?
(A) Because the four images are arranged in strict chronological order narrating Bharat's history, so reordering would falsify the timeline.(B) The four images cohere as one extended personification — the land IS the Mother's body — so crown-at-head, washing-at-feet, green-fertile-body and sacredness-throughout jointly compose a single head-to-foot-and-in-spirit portrait; remove or scatter them and the unified figure of the living Motherland is diminished, not merely shortened.(C) Because each image names a different deity, so dropping one would omit a god from the hymn.(D) Because the images are literal geography only, so the reader is right that they are independent and interchangeable.

20. मातृ (kinship, feminine ऋ-stem) makes accusative singular मातरम् with short अ in the strong stem, while दातृ (agent, masculine ऋ-stem) makes दातारम् with long आ. A student must form the accusative singular of नप्तृ ('grandson', an agent-type masculine ऋ-stem like दातृ) and of दुहितृ ('daughter', a kinship feminine ऋ-stem like मातृ). Which pair is right?

21. A learner writes नमः मातरम् for 'homage to the Mother', copying वन्दे's accusative onto नमः, AND writes वन्दे मात्रे for 'I salute the Mother', copying नमः's dative onto वन्दे. The learner has made a symmetrical pair of mistakes. State the correction for BOTH at once.

24. In वन्दे मातरम् the two words sit side by side with no vowel-fusion at the seam. A student claims: 'therefore no two adjacent Sanskrit words ever fuse, and sandhi is only a within-word phenomenon.' Use the chapter's own observation to correct this.
(A) वन्दे sits unchanged before मातरम् only because मातरम् begins with a consonant; had a vowel-initial word followed (e.g. वन्दे इह), the seam could trigger vowel-sandhi — so word-boundary sandhi is real and depends on the sounds meeting, not absent everywhere.(B) Correct: sandhi never operates across word boundaries, so वन्दे can never change before any following word.(C) Correct: मातरम् blocks all sandhi because it is an accusative, and accusatives are sandhi-proof.(D) The student is wrong only because वन्दे is indeclinable and indeclinables alone undergo external sandhi.
25. A student renders सस्यश्यामला as 'the Mother who possesses dark crops' (a बहुव्रीहि, 'one whose crops are dark'), instead of the तत्पुरुष 'dark-green BY crops'. Both readings touch 'crops' and 'dark'. What decisive difference in what the compound DENOTES separates the two analyses, and which does the chapter intend?
(A) There is no difference in denotation; तत्पुरुष and बहुव्रीहि always denote the same thing, so either label is fine.(B) The chapter intends the तत्पुरुष 'dark-green by/with crops', which denotes the very quality (the Mother is dark-green because of crops); the बहुव्रीहि reading would denote an outside possessor 'one whose crops are dark', shifting the focus from the colour-quality caused by crops to mere ownership of dark crops — a different referential structure the chapter does not use here.(C) The बहुव्रीहि is intended, because सस्यश्यामला must name an outside person, and तत्पुरुष compounds can never describe the Mother.(D) The difference is only in gender: the तत्पुरुष is masculine and the बहुव्रीहि feminine, with identical meaning otherwise.
26. वन्दे मातरम् is described as a complete sentence, while मातरम् alone is not. A student counters: 'but माता (the nominative) names the subject, so माता alone should be a complete sentence even if मातरम् is not.' Resolve this.
(A) Neither माता nor मातरम् alone is a complete sentence, because a finite verb is what makes a Sanskrit clause complete by asserting an action; माता is only a subject-naming noun with no predicated action, whereas वन्दे, a finite verb, already contains subject ('I') and asserts the act, so it alone is complete.(B) Correct: माता alone is a complete sentence because the nominative subject by itself states a complete thought.(C) Neither is complete because every Sanskrit sentence needs at least one noun and one adjective.(D) मातरम् alone is in fact complete, since the accusative implies the verb वन्दे and so carries it silently.

1. (B) The chapter glosses वन्दे as 'I salute/revere' — a present-indicative, first-person-singular ātmanepada verb. Two features settle the matter at once. First, the action is asserted as actually happening (indicative), not merely wished for, so the optative 'may I salute' is excluded; the form carries no wish-mood. Second, the agent 'I' is built into the personal ending, so the speaker is the one performing the salutation; there is no passive construction making the Mother the agent of being saluted. The passive reading would require a different morphology and would put the Mother in the nominative as the thing-saluted, which is not what we have — मातरम् is accusative, the object. The claim that वन्दे carries no person is false: ātmanepada -ए is precisely the first-singular marker. The imperative idea fails because an imperative would address the Mother as 'you', not state 'I' as agent. Only one fact — that the form is a present-indicative finite verb with the agent inside — knocks out both the passive and the optative together.

2. (C) Sanskrit builds case-forms from the STEM, here मातृ, an ऋ-ending feminine. The nominative singular माता is itself an output of that stem and is not the base for further endings; treating माता as a base is the first error. The second error is mechanical: the accusative singular is not stem-plus-म् mechanically, because ऋ-stems strengthen in the strong cases — मातृ becomes मातर-, which then takes -म्, yielding मातरम्. So मातम् both starts from the wrong piece (the nominative) and omits the strengthening step. The option claiming मातम् is correct and only the verb is at fault inverts reality: वन्दे demands an accusative object, and the correct accusative is मातरम्, not a nominative. The dual idea (मातरौ) is irrelevant — the meaning is one Mother, so singular is wanted. The -आम् idea confuses the feminine adjective ending (श्यामला → श्यामलाम्, where the long आ belongs to the आ-stem) with the ऋ-stem noun, which does not take -आम् in the accusative singular. Only the option naming both the wrong base and the missing strengthening is fully right.

3. (C) This question tests whether a learner can resist over-correcting a CORRECT observation. मातरम् and मातरौ genuinely share the strengthened stem मातर-, and number is signalled by the ending attached: -म् for accusative singular, -औ for accusative dual. The only refinement worth making is to keep singular vs dual straight, which the student already had right in substance. The distractor inventing a stem मातार- is false — that long-आ strengthening belongs to agent ऋ-stems like दातृ → दातारम्, not to kinship मातृ, whose strong stem is मातर-. The claim that -औ is plural is the standard dual/plural trap: -औ is dual (exactly two); plurals appear as मातरः (nom.) etc. The claim that -म् is nominative ignores that the nominative singular is माता with no -म्. So the only fully sound statement affirms the shared stem and merely pins the numbers correctly.

4. (D) The deep point is that how a word selects its complement's case is a fact stored with that individual word (its government), not something deducible merely from its meaning ('salute') or from its grammatical class ('verb' or 'indeclinable'). The chapter gives two concrete data points: वन्दे takes a direct object in the accusative, and नमः is naturally construed with a dative of the one honoured. Promoting these to a sweeping rule — 'all salute-verbs → accusative, all salute-indeclinables → dative' — overreaches, because other words could behave differently; the data underdetermine such a law. The swapped-labels distractor is factually wrong: वन्दे is the finite verb, नमः the indeclinable. The genitive distractor is wrong because नमः pairs with dative ('homage TO') and वन्दे with accusative (the object), not genitive. The claim that dative and accusative are one case is simply false — they are distinct, with distinct endings (e.g. मात्रे dative vs मातरम् accusative). Hence the only sound inference is that government is word-specific.

5. (C) All four are ātmanepada forms of root वन्द्, differing by the personal ending. वन्दे = 1st singular ('I salute'). वन्दते = 3rd singular ('he/she salutes'). वन्दामहे = 1st plural ('we salute'). वन्दन्ते = 3rd plural ('they salute'). For 'they (all) salute' the answer is वन्दन्ते. The instructive design is that each distractor fails on its own axis: वन्दामहे has the right plural number but wrong person (1st, not 3rd); वन्दते has the right person (3rd) but wrong number (singular); वन्दे misses on both, being 1st singular. The distractor that calls -ते a plural ending confuses 3rd-singular -ते with 3rd-plural -न्ते. The claim that 1st-singular वन्दे doubles as 3rd plural is false — Sanskrit keeps these distinct. So only वन्दन्ते matches both person and number.

6. (D) Sanskrit verbs draw their personal endings from sets (पद): parasmaipada and ātmanepada. A given root takes one set (or both, with nuance). सिञ्च् is parasmaipada-type, so 'they' is सिञ्चन्ति with -अन्ति; वन्द् is ātmanepada-type, so 'he/she' is वन्दते with -ते (and 'they' would be वन्दन्ते). Both -अन्ति and -न्ते encode third person — the difference is the ending-SET, governed by the root's class/pada, not a difference in tense; both verbs here are present. The tense distractor invents a past for वन्दते, which is present. The 'only one set' distractor denies the existence of pada, contradicting the very contrast vowel given. The misprint distractor assumes all 3rd persons must look identical, which is exactly the misconception under test. So the correct statement attributes the contrast to different ending-sets at the same (third) person.

7. (B) Adjective–noun agreement is the unifying principle: an adjective copies the case, number and gender of the noun it qualifies. Since मातरम् is the accusative-singular-feminine object of वन्दे, सुजलाम्, सुफलाम् and सस्यश्यामलाम् must all be accusative-singular-feminine too. The first version leaves the noun and its three adjectives in their citation (nominative) forms माता / सुजला / सुफला / सस्यश्यामला, so a single error — failure of accusative agreement across the head and its qualifiers — explains all four altered words. The instrumental distractor invents a 'means' role that is absent: nothing here is the instrument of honouring. The 'no single ground' distractor wrongly splits the error into noun-case plus a gender problem; gender is consistently feminine throughout, so gender is not the issue. The 'no object' distractor denies that वन्दे is transitive, contradicting the chapter. Thus one principle, agreement with the accusative head, covers the whole group.

8. (B) The contrast is between a compound that denotes one of its own members (तत्पुरुष) and one that denotes an outside referent characterised by the compound (बहुव्रीहि). पर्वतराजः denotes a king (its head राजा), so it is तत्पुरुष. नीलकण्ठः denotes neither 'blue' nor 'throat' but Shiva, who possesses a blue throat — a बहुव्रीहि pointing outside. देशभक्तः denotes a devotee (head भक्तः) who is country-directed; the whole IS a devotee, so it points inside and is तत्पुरुष, structurally like पर्वतराजः, not like नीलकण्ठः. The बहुव्रीहि distractor mislocates the referent outside (a 'country the devotee belongs to'), but the compound names the devotee himself. The द्वन्द्व distractor wrongly coordinates the members ('country and devotee'), whereas the first member qualifies the head, not coordinates with it. The 'both तत्पुरुष / names first member' distractor is doubly wrong: नीलकण्ठः is बहुव्रीहि, and तत्पुरुष names its LAST (head) member, not its first.

9. (A) An epithet like रत्नाकरः works by describing a salient property — the sea as the source/store of jewels (pearls, corals) — so the reader infers 'ocean' from the descriptive sense and context, not from any concealed instance of the word समुद्र. The 'hidden letters' idea is a category mistake: reference here is semantic, through meaning, not orthographic. The 'forbidden word' distractor invents a non-existent prohibition; poets may use समुद्र freely and choose epithets for richness, not by rule. The 'आकरः alone means ocean' distractor is false: आकरः means 'mine/store' generally (a mine of anything), so it is the combination रत्न + आकर that picks out the sea; रत्न- is load-bearing, not decorative. Hence the correct account is reference by descriptive property.

10. (B) In a तत्पुरुष the LAST member is the head and fixes what the whole denotes; the preceding member qualifies it. Here बान्धव ('brethren/kinsmen') is the head, कृषक ('farmer') the qualifier, and the inflection rides on the head: बान्धवाः, nominative plural masculine. So the compound denotes brethren who are farmers — exactly what the student said on both counts. The distractor placing the plural on कृषक mislocates inflection, which attaches to the head, not the qualifier. The distractor making कृषक the head reverses the तत्पुरुष head rule. The द्वन्द्व distractor wrongly coordinates the members; a द्वन्द्व would mean 'farmers and brethren' as two separate groups, but here farmers and brethren are not two sets — the farmers ARE the brethren. Hence both halves of the student's claim hold.

11. (A) The model सस्यश्यामला means 'dark/green by means of crops' — the first member gives the cause/instrument, the second the resulting quality. Transferring this instrumental-तत्पुरुष relation to तपःकृशा (तपस् 'austerity' + कृशा 'thin/lean'), the natural sense is 'thin BY/THROUGH austerity', i.e. made lean by penance. The 'queen of austerities' reading imposes a genitive तत्पुरुष ('ruler of') not present in the model. The 'austerity-less' reading smuggles in a negative prefix that the model lacks (there is no अ-). The 'paired together' reading treats the compound as a द्वन्द्व coordinating two things, but the model relation subordinates the first member as the instrument of the second's quality. So the parallel yields 'thin through austerity'.

12. (C) Word-order in Sanskrit does not fix case; endings do. समुद्रः ends in -ः (nominative singular), and it agrees with the singular verb प्रक्षालयति, so it is the subject doing the washing. चरणौ ends in -औ (accusative dual here), naming the two feet that are washed — the object. भारतमातुः ends in the genitive -उः, expressing 'whose feet' — possession. The student's reasoning is positional and therefore wrong on every count: 'first word = accusative', '-औ = subject', 'precedes object = instrumental' are all non-rules. The first distractor keeps two right but re-labels भारतमातुः as instrumental; there is no 'means' here, and -उः is genitive, so it is wrong. The second distractor wrongly keeps समुद्रः accusative and चरणौ nominative, inverting subject and object. The third distractor scrambles all three into instrumental/genitive/nominative, contradicting the endings. Only nominative–accusative–genitive matches the morphology and the verb agreement.

13. (A) The deep idea is that the SAME relation ('the saluting of X') is expressed differently depending on whether the saluting is carried by a finite verb or by a noun. वन्दे, a finite transitive verb, takes a direct object in the accusative: मातरम्. In देवाः भारतमातुः वन्दनम् कुर्वन्ति, the actual finite verb is कुर्वन्ति ('perform'), and the saluting is named by the noun वन्दनम्; an action-noun governs its 'object' as a genitive complement, hence भारतमातुः ('salutation OF the Motherland'). So the controlling factor is what the noun depends on — verb (accusative) or noun (genitive). The number distractor is false: both refer to one Motherland. The passive distractor is false: कुर्वन्ति is active, and even passives in Sanskrit do not turn objects into genitives in this way. The 'no difference / really accusative' distractor denies the visible genitive ending -उः. Hence the single distinction is verb-government versus noun-complement.

14. (D) Sanskrit has three numbers: singular, dual (exactly two), and plural (three or more). The dual is a real, separately marked category, not absorbed into the plural. So चरणौ specifically means 'the two feet' and would be the correct, precise form for a two-footed Motherland; चरणाः (plural) would assert three or more, which is wrong for feet. The ending is therefore meaning-bearing, not redundant — it encodes 'exactly two', a fact the bare noun does not state. The 'no plural for body-parts' distractor invents a non-rule; plurals of body-part nouns exist. The 'dual and plural identical' distractor is false — they have distinct endings (-औ vs -अः etc.). The 'singular' distractor misreads -औ; -औ on चरण is dual, while a singular would be चरणम्/चरणः-type forms. Hence the dual ending does real work.

15. (B) The agent of an active verb is its nominative subject — here the farmers (कृषकबान्धवाः, with सिञ्चन्ति 'they water'). The sweat-drops are the MEANS through which the farmers accomplish the watering, and means is the instrumental, marked -भिः: 'they water (the land) with sweat-drops'. So although the drops physically do the wetting, grammatically they are the instrument, not the agent; the agent is the human doer. Calling -भिः an agent-marker confuses means with agent and demotes the farmers to mere 'location', which the syntax does not support. The accusative reading would make the drops the thing watered, reversing instrument and patient; the object is the land. The genitive reading ('of the drops') is the classic -भिः/possession confusion: possession would be स्वेदबिन्दूनाम्. Hence -भिः is the instrumental of means, with the farmers as agent.

16. (C) The मात्रा principle assigns one मात्रा to every ह्रस्व (short) vowel and two to every दीर्घ (long) vowel — this applies across the board: अ/आ, इ/ई, उ/ऊ, and so on. So length is meaning-bearing for all such pairs, not uniquely for आ/अ. Swapping इ for ई or उ for ऊ can change a word just as आनन्द → अनन्द does. The 'only आ has two मात्राः' distractor is false — ई and ऊ each have two मात्राः too. The 'no long counterparts' distractor denies the existence of ई and ऊ, which plainly exist. The 'changes only gender' distractor invents a gender-only effect; length can alter the core lexical identity, not merely gender. Hence the learner's restriction is mistaken: all short/long pairs are durational and meaning-bearing.

17. (D) रत्न ends in a short अ (रत्न = र-त्-न-अ) and आकर begins with long आ. When these meet, vowel-sandhi merges a/ā + a/ā into a single long आ (अ + आ → आ). So the one long आ at the seam is the fused product of two underlying vowels, and splitting means recognising the fusion and restoring रत्न + आकर. The 'no fusion / रत्न ends in a consonant' distractor is phonetically wrong: रत्न ends in the vowel अ, so a vowel does meet a vowel. The 'fuses to ए' distractor misapplies the rule for अ/आ + इ/ई → ए; with आ the result is आ, not ए. The 'accident of spelling / cannot recover' distractor denies the regular, reversible sandhi that makes recovery possible. Hence the long आ is the predicted अ + आ → आ coalescence.

18. (B) The chapter reads the images as a single sustained personification: the geography is the Mother's body. The Himalaya crowns her head (north/top), the ocean washes her feet (south/below), the crops make her body green and fertile, and the holy places give her sacred, spiritual worth. Together they form one head-to-foot-and-in-spirit figure of a living Motherland; they are not detachable compliments but parts of one body-image, so reordering or dropping them weakens the unified figure. The 'chronological history' distractor mislabels a spatial body-image as a timeline. The 'different deities' distractor invents gods where the poem personifies the land itself, not a pantheon. The 'literal geography only' distractor concedes the reader's premise and misses the figurative unity the chapter teaches. Hence the images are integrated, not independent.

19. (C) वन्दे takes its object in the accusative, and adjectives qualifying that object copy its case, number and gender (feminine accusative singular). So the noun is मातरम् and each adjective ends in feminine-accusative-singular -आम्: रत्नाकरयुक्ताम्, पर्वतराजमुकुटाम्. The first distractor leaves everything in the nominative citation forms (माता, -युक्ता, -मुकुटा), the wrong case for an object. The second distractor puts the adjectives in the instrumental plural -ऐः (as if 'by means of' several things), which neither agrees with मातरम् nor expresses any means. The third distractor uses the genitive (-आयाः ... मातुः), expressing possession ('of the Mother') rather than the saluted object. Only वन्दे रत्नाकरयुक्ताम् पर्वतराजमुकुटाम् मातरम् keeps full accusative agreement.

20. (D) The chapter's own contrast is the key: kinship ऋ-stems like मातृ keep the SHORT strong stem (मातर-, giving मातरम्), while agent ऋ-stems like दातृ LENGTHEN it (दातार-, giving दातारम्). नप्तृ ('grandson') is an agent-type masculine ऋ-stem, so it lengthens: accusative नप्तारम्. दुहितृ ('daughter') is a kinship term like मातृ/पितृ, so it keeps the short stem दुहितर-: accusative दुहितरम्. So the correct pair is नप्तारम् and दुहितरम्. The first distractor reverses the assignment (short for the agent, long for the kinship term). The 'lengthen both' distractor ignores that kinship terms stay short. The bare-stem-plus-म् distractor (नप्तृम्/दुहितृम्) skips the obligatory stem-strengthening of ऋ-stems. Hence नप्तारम् (agent, long) and दुहितरम् (kinship, short) is right.

(A) Sandhi operates both within words and across word boundaries (external sandhi). वन्दे happens to stay unchanged before मातरम् because मातरम् begins with a consonant (म), and the final ए of वन्दे simply abuts it. But if a vowel-initial word followed — say इह — the meeting of ए with इ could trigger external vowel-sandhi, altering the written seam.
