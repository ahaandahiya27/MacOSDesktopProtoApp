Worked Solutions

1. (A) OC and OD are opposite rays, so ∠AOC + ∠AOD = 180: (2x+18)+(3x−8)=180 → 5x+10=180 → x=34. ∠AOD = 3(34)−8 = 94°. ∠BOC is vertically opposite ∠AOD, so ∠BOC = 94°. The value 86° is the vertical of ∠AOC (2·34+18) instead; 34° is x; 46° wrongly computes 180−134.

2. (C) Vertically opposite angles are equal: 5x−4 = 3x+30 → 2x=34 → x=17. The angle is 5(17)−4 = 81°. Its linear-pair neighbour = 180 − 81 = 99°. The value 81° stops at the vertical angle; 17° is x; 162° doubles 81 instead of subtracting from 180.

3. (C) ∠BOD = ∠AOC = 4(12)+9 = 57°. OE splits ∠BOD into ∠BOE = 31° and ∠DOE, so ∠DOE = 57 − 31 = 26°. Taking 57° forgets to subtract ∠BOE; 31° re-reads the given; 88° adds 57+31.

4. (A) Adjacent angles form a linear pair: 3x + (x+40) = 180 → 4x = 140 → x = 35. The two values are 3x = 105° and x+40 = 75°. The larger is 105°. The value 75° is the smaller; 35° is x; 115° comes from x+80 in error.

5. (B) (6x−10)+(4x+30)=180 → 10x+20=180 → x=16. The angles are 6(16)−10 = 86° and 4(16)+30 = 94°. Difference = 94 − 86 = 8°. The value 16° is x; 94° is only the larger angle; 180° is the sum.

6. (D) Vertical angles are equal: 7x−16 = 5x+22 → 2x=38 → x=19. ∠1 = 7(19)−16 = 117°. The other vertical pair is the linear-pair neighbour: 180 − 117 = 63°. The value 117° is ∠1 itself; 19° is x; 126° doubles 63 instead of using it directly.

7. (C) Angles at a point sum to 360: (2x+5)+(3x−15)+(4x+10)=360 → 9x+0=360 → x=40. The angles are 85°, 105°, 170°. The largest is 4(40)+10 = 170°. The values 85° and 105° are smaller angles; 150° drops the +10.

8. (D) Sum at a point = 360: 2y + 3y + (y+60) = 360 → 6y + 60 = 360 → 6y = 300 → y = 50. Angles: 2y = 100°, 3y = 150°, y+60 = 110°. Smallest = 100°. Its supplement = 180 − 100 = 80°. The value 100° is the angle itself; 150° is the largest; 30° mis-subtracts.

9. (A) Sum at a point = 360: a + (a+10) + (a+20) + (a+30) = 360 → 4a + 60 = 360 → 4a = 300 → a = 75. The largest is a+30 = 105°. The value 75° is the smallest (a); 95° is a+20; 90° is the mean, not any actual angle.

10. (B) Five equal angles around a point: each = 360 ÷ 5 = 72°. The bisector splits one into two equal parts of 72 ÷ 2 = 36° each. The value 72° forgets to bisect; 45° wrongly halves a right angle; 18° bisects twice.

11. (C) Sum at a point = 360: 3x + 90 + 2x + (x+30) = 360 → 6x + 120 = 360 → 6x = 240 → x = 40. ∠AOB = 3(40) = 120°. The value 40° is x; 80° is ∠COD (2x); 70° is ∠DOA (x+30).

12. (C) Sum at a point = 360: (3x−10)+(x+40)+(2x+30)=360 → 6x+60=360 → 6x=300 → x=50. Angles: 3x−10 = 140°, x+40 = 90°, 2x+30 = 130°. The middle-sized is 130°. The value 140° is the largest; 90° is the smallest; 50° is x.

13. (B) Corresponding angles between parallel lines are equal: 5x−12 = 3x+8 → 2x=20 → x=10. The angle = 5(10)−12 = 38°. Its linear-pair neighbour = 180 − 38 = 142°. The value 38° is the angle itself; 10° is x; 122° mis-subtracts (180−58).

14. (C) Corresponding angles equal: 4x+15 = 6x−25 → 40 = 2x → x=20. The angle = 4(20)+15 = 95°. Its co-interior partner is supplementary: 180 − 95 = 85°. The value 95° equates co-interior instead of supplementing; 20° is x; 105° mis-subtracts.

15. (C) The corresponding angle at Q equals 118° (lines parallel). Its vertically opposite angle is also 118°. So the answer is 118°. The value 62° takes the linear pair instead of the vertical; 236° doubles; 90° assumes a perpendicular crossing.

16. (B) Corresponding angles equal: 2x+30 = 4x−10 → 40 = 2x → x=20. The angle = 2(20)+30 = 70°. Its linear-pair neighbour = 180 − 70 = 110°. The value 70° stops at the angle; 20° is x; 140° doubles 70.

17. (A) The 64° interior angle and the same-side interior angle at m are co-interior, hence supplementary: 180 − 64 = 116°. The value 64° wrongly equates co-interior angles; 26° subtracts from 90; 128° doubles 64.

18. (D) Corresponding angles equal: x+25 = 2x−15 → x=40. The angle = 40+25 = 65°. Its vertically opposite angle is equal, 65°. The value 115° takes the linear pair; 40° is x; 50° mis-computes.

19. (C) Alternate interior angles are equal: 3x−5 = x+41 → 2x=46 → x=23. The angle = 3(23)−5 = 64°. Its co-interior partner (linear pair at the crossing) = 180 − 64 = 116°. The value 64° is the alternate angle; 23° is x; 46° mis-computes.

20. (B) Alternate exterior angles are equal: 5x−30 = 3x+10 → 2x=40 → x=20. The angle = 5(20)−30 = 70°. Its linear-pair neighbour = 180 − 70 = 110°. The value 70° is the angle itself; 20° is x; 40° mis-computes.

21. (A) Alternate interior angles are equal, so ∠A = ∠B. Substituting: ∠A = 2∠A − 24 → ∠A = 24°. The value 48° doubles; 12° halves; 156° takes the supplement.

22. (A) Alternate interior angles equal: 7x−4 = 5x+14 → 2x=18 → x=9. The angle = 7(9)−4 = 59°. Its co-interior partner = 180 − 59 = 121°. The value 59° is the alternate angle; 9° is x; 31° subtracts from 90.

23. (B) The exterior 142° angle has an interior linear-pair neighbour of 180 − 142 = 38° at the same crossing; that interior angle's alternate interior angle at the lower line equals it, 38°. The value 142° forgets the linear-pair step; 52° subtracts from 90 wrongly; 48° mis-computes.

24. (D) Alternate exterior angles equal: 3x+15 = 4x−5 → x=20. The angle = 3(20)+15 = 75°. Its linear-pair neighbour = 180 − 75 = 105°. The value 75° is the exterior angle; 20° is x; 95° mis-computes.

25. (B) Co-interior angles are supplementary: (3x+20)+(2x+10)=180 → 5x+30=180 → x=30. The angles are 3(30)+20 = 110° and 2(30)+10 = 70°; larger = 110°. Its alternate interior angle equals it, 110°. The value 70° is the smaller co-interior angle; 30° is x; 100° mis-computes.

26. (D) Co-interior angles are supplementary: 7k + 2k = 180 → 9k = 180 → k = 20. Angles: 7k = 140°, 2k = 40°. Smaller = 40°. The value 140° is the larger; 20° is k; 90° wrongly assumes equality.

27. (A) Let the smaller be t; the larger is 4t. Co-interior angles are supplementary: 4t + t = 180 → 5t = 180 → t = 36. Larger = 4(36) = 144°. The value 36° is the smaller; 45° and 135° come from wrongly treating them as equal halves or a 3:1 split.

28. (B) Co-interior angles sum to 180: a + b = 180 and a − b = 36. Adding: 2a = 216 → a = 108°. Larger = 108°. The value 72° is the smaller; 36° is the difference; 90° assumes equality.

29. (A) Co-interior angles are supplementary: 5x + (4x−9) = 180 → 9x − 9 = 180 → 9x = 189 → x = 21. The (5x)° angle = 105°. Its corresponding angle at the other line equals it, 105°. The value 75° is the other co-interior angle (4x−9); 21° is x; 115° mis-computes.

30. (B) The two angles form a linear pair, so they sum to 180 in ratio 3:2: 3k + 2k = 180 → 5k = 180 → k = 36. The alternate-interior (3 parts) = 108°. The value 72° is the 2-part angle; 54° halves wrongly; 120° uses a 2:1 split.

31. (D) Corresponding angles equal: 8x−12 = 5x+21 → 3x=33 → x=11. ∠Q = 5(11)+21 = 76°. Its linear-pair neighbour = 180 − 76 = 104°. The value 76° is ∠Q itself; 11° is x; 94° mis-computes.

32. (B) Linear pair: 7x + 2x = 180 → 9x = 180 → x = 20. ∠AOC = 7(20) = 140°. The bisector halves it: ∠DOC = 140 ÷ 2 = 70°. The value 140° forgets to bisect; 40° is ∠COB (2x); 20° is x.

33. (D) Alternate interior angles equal: 2x+9 = 3x−6 → x=15. The angle = 2(15)+9 = 39°. Its co-interior partner = 180 − 39 = 141°. The value 39° is the alternate angle; 15° is x; 151° mis-subtracts.

34. (D) Co-interior angles supplementary: (x+30) + 2x = 180 → 3x = 150 → x = 50. Angles: x+30 = 80°, 2x = 100°; larger = 100°. Its vertically opposite angle equals it, 100°. The value 80° is the smaller; 50° is x; 130° mis-computes.

35. (C) Vertical angles equal: 4x+5 = 6x−25 → 30 = 2x → x=15. ∠AOC = 4(15)+5 = 65°. ∠AOD = 180 − 65 = 115°. The value 65° is ∠AOC; 15° is x; 130° doubles 65.

36. (A) Corresponding angles equal: 6x−8 = 4x+22 → 2x=30 → x=15. The angle = 6(15)−8 = 82°. Its co-interior partner = 180 − 82 = 98°. The value 82° is the angle itself; 15° is x; 108° mis-computes.

37. (C) Corresponding angles between parallel lines must be EQUAL. Here 88° ≠ 92°, so the lines are not parallel. Treating 88° and 92° as 'close enough' or as supplementary (88+92=180) wrongly suggests parallel; neither line is perpendicular nor coincident.

38. (D) For parallel lines, co-interior angles must sum to exactly 180°. Here 95 + 86 = 181° ≠ 180°, so the lines are not parallel. Reading the test as 'equal' or 'sums to 180' is the trap; nearness to 90° is irrelevant.

39. (C) Alternate interior angles between parallel lines must be EQUAL. Since 70° ≠ 76°, the lines are not parallel. The 6° difference does not give the angle of meeting; nothing here makes them perpendicular.
