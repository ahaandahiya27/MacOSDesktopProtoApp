"What If?" — Working with Fractions

Hypothetical questions with no single right answer. Think hard before you read the discussion.

≈ 7 min read · brain-stretcher level

The textbook tells you what is. The best way to really understand an idea is to ask what if? Pick a question below, pause and think for a minute, then read one possible discussion.

What if 1 — we could only use unit fractions?

The question: What if every fraction had to be written Egyptian-style, with 1 on top?

🧠 Think first

How would you write 3/4?

One discussion path: You would build it from pieces: 1/2 + 1/4. It works, but it is slower — which is exactly why the modern numerator/denominator notation eventually replaced it.

What if 2 — there were no common-denominator trick?

The question: What if you tried to add 1/2 and 1/3 directly?

🧠 Think first

What size are the pieces?

One discussion path: Halves and thirds are different-sized pieces, so 'one plus one' is meaningless until you re-cut both into sixths. The common denominator is the one idea that makes fraction addition possible.

What if 3 — dividing by a fraction made numbers smaller?

The question: What if 3 ÷ 1/4 gave less than 3?

🧠 Think first

How many quarter-slices fit in 3 whole things?

One discussion path: It gives 12, because you are counting how many small pieces fit — and many small pieces fit in a big whole. Dividing by a number less than 1 makes the result bigger, which surprises everyone at first.

📝 Stretch your thinking

None of these has one 'correct' answer — they are for arguing about. Try one on a friend or a parent and see whether their discussion path differs from yours.
