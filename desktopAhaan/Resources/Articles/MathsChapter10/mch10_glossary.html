Operations with Integers: Key Words

Every term in this chapter, with a one-line meaning and an example.

&#8776; quick reference &middot; 10 terms

Knowing the exact words makes the maths click. Here is every key term from the chapter, defined plainly with an example you can picture.

Integer

A whole number that may be positive, negative, or zero.

Example: −3, 0, 7 are integers.

In Hindi: पूर्णांक

Number line

A line with 0 in the middle, positives to the right and negatives to the left.

Example: −2 is two steps left of 0.

In Hindi: संख्या रेखा

Zero pair

A positive and a negative token together, summing to 0.

Example: +1 and −1 form a zero pair.

Additive inverse (opposite)

The number with the same size but opposite sign; it sums with the original to 0.

Example: The opposite of −12 is 12.

In Hindi: योज्य प्रतिलोम

Commutative property

Order doesn't change the result: a+b=b+a and a×b=b×a.

Example: (−6)×3 = 3×(−6).

Associative property

Grouping doesn't change the result of addition (or multiplication).

Example: (a+b)+c = a+(b+c).

Magnitude

The size of a number ignoring its sign.

Example: The magnitude of −8 is 8.

Sign rules (multiplication)

Same signs give a positive product; different signs give a negative product.

Example: (−)(−)=+, (+)(−)=−.

Token model

Using green (positive) and red (negative) tokens to model integer operations.

Example: 4×(−2) = put 2 red tokens in 4 times.

Identity element

A number that leaves others unchanged: 0 for addition, 1 for multiplication.

Example: 7 + 0 = 7.
