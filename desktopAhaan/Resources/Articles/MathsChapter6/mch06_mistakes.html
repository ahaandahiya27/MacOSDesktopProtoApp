Common Mistakes in Number Play

The places students slip on this chapter — and the one-line fix for each.

&#8776; 5 min read &middot; revision-tier &middot; 5 fixes

These wrong answers come back year after year. None are silly — they are almost right, which is what makes them worth knowing. Read each, then cover the fix and try to spot what is off.

1. “Adding any number of odd numbers gives an even result.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Only an EVEN count of odds gives even; an ODD count of odds gives odd. Five odds sum to odd.

2. “Checking a few examples proves a statement.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Examples can only DISPROVE (one counterexample) or suggest. A proof needs a general argument (like 2m+1 + 2n+1 = even) covering all cases.

3. “The Fibonacci sequence was invented by Fibonacci.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Indian scholars (Pingala, Virahāṅka) described it centuries earlier while studying poetic metre — hence Virahāṅka–Fibonacci.

4. “In a Virahāṅka–Fibonacci sequence you add a fixed number each time.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: You add the TWO PREVIOUS terms, not a constant. The gaps grow: +1, +2, +3, +5, …

5. “In a cryptarithm any letter can be any digit independently.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: The digits are constrained by place value and carrying — usually only one assignment is consistent, found by elimination.
