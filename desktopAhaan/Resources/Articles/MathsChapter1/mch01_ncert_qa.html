Q1. Write the following numbers in Indian place value notation: (a) One crore one lakh one thousand ten (b) One billion one million one thousand one

Answer: (a) 1,01,01,010 (b) 1,00,10,01,001

Q2. Compare: 30 thousand ___ 3 lakhs. Fill < > or =.

Answer: 30 thousand < 3 lakhs (since 30,000 < 3,00,000).

Q3. Compare: 500 lakhs ___ 5 million. Fill < > or =.

Answer: 500 lakhs > 5 million. (500 lakhs = 5 crore = 50 million.)

Q4. Compare: 800 thousand ___ 8 million.

Answer: 800 thousand < 8 million (800,000 < 8,000,000).

Q5. Compare: 640 crore ___ 60 billion.

Answer: 640 crore < 60 billion. (640 crore = 6.4 billion.)

Q6. Write the five nearest neighbours of 3,87,69,957 (nearest thousand, ten thousand, lakh, ten lakh, crore).

Answer: Nearest thousand: 3,87,70,000. Nearest ten thousand: 3,87,70,000. Nearest lakh: 3,87,70,000 (or 3,88,00,000 if rounding to lakh from 69,957 → 70,000; closer is 3,87,70,000 if precision allows; for the nearest LAKH boundary the closest is 3,88,00,000). Nearest ten lakh: 3,90,00,000. Nearest crore: 4,00,00,000.

Q7. How many sticks are needed to write the number 5108 in the toothpick-digit shapes shown in the chapter?

Answer: Sticks per digit (from the chapter): 0 = 6, 1 = 2, 5 = 5, 8 = 7. For 5108: 5+2+6+7 = 20 sticks.

Q8. If Chitti has +1, +10, +100, +1000, +10000, +100000, +1000000 buttons, what is the fewest number of presses to display 70,25,700?

Answer: Sum of digits 7+0+2+5+7+0+0 = 21 presses.
