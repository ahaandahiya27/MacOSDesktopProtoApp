"What If?" — Connecting the Dots

Hypothetical questions with no single right answer. Think hard before you read the discussion.

≈ 7 min read · brain-stretcher level

The textbook tells you what is. The best way to really understand an idea is to ask what if? Pick a question below, pause and think for a minute, then read one possible discussion.

What if 1 — we only ever reported the mean?

The question: What if the median and mode were never used?

🧠 Think first

Picture nine people earning ₹10,000 and one earning ₹10,00,000.

One discussion path: The mean alone would suggest everyone is well-off, hiding the truth. The median (₹10,000) tells the honest story. Different 'averages' answer different questions; using only one can mislead.

What if 2 — a graph's axis didn't start at zero?

The question: What if a bar chart began at 90 instead of 0?

🧠 Think first

How big would the gap between 95 and 100 look?

One discussion path: A tiny real difference would look like a huge jump. Where the scale begins changes the story a graph appears to tell — which is why honest graphs label their axes carefully.

What if 3 — a survey sampled only one kind of person?

The question: What if you asked only cricket fans about the best sport?

🧠 Think first

Would the result describe the whole school?

One discussion path: No — the sample would be biased and the 'representative value' meaningless. Good statistics depends on sampling fairly, the lesson at the heart of this chapter.

📝 Stretch your thinking

None of these has one 'correct' answer — they are for arguing about. Try one on a friend or a parent and see whether their discussion path differs from yours.
