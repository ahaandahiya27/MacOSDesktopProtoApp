"What If?" — नित्यं पिबामः सुभाषितरसम्

Hypothetical questions with no single right answer. Think hard before you read the discussion.

≈ 7 min read · brain-stretcher level

The textbook teaches what IS. Real understanding comes from asking what IF? Pick a question below, pause and think for a minute, then read one possible discussion.

What if 1 — subhashitas had ten lines instead of four?

The question: Sanskrit chose four-line श्लोकs as the gem-format. What if the tradition had settled on ten?

🧠 Think first

Would you memorise fewer of them? Would they be richer or just longer?

One discussion path: Four lines is a deliberate compression — it forces the poet to leave words OUT, which is where the gemstone effect comes from. Ten lines would have given more room to elaborate, but the punchline-by-line discipline would weaken. Form shapes function.

What if 2 — you had to memorise 100 subhashitas in a row?

The question: Traditional gurukula students did exactly this. Try imagining it.

🧠 Think first

How would you scaffold the memorisation? What devices would you use?

One discussion path: Sanskrit students used the antyakshari chain (last-letter → next-verse-first-letter), thematic grouping, rhythmic chanting, and association with daily rituals. Without those scaffolds, raw memorisation would crumble. The TRICKS are the curriculum.

What if 3 — the antyakshari rule had been first-letter → first-letter, not last → first?

The question: The current rule chains last syllable to next first syllable. What if every verse just had to start with the same letter as the previous one's start?

🧠 Think first

Which game would be harder? More fun? Why?

One discussion path: First-to-first chains all verses through one letter, which is dull — you can plan ahead easily. Last-to-first is unpredictable: you don't know the seed until the previous verse ends. The current rule is harder and more engaging. Game design is hidden grammar.

📝 Stretch your thinking

None of these has one 'correct' answer — they are for arguing about. Try one on a friend or a parent and see if their discussion path differs from yours.
