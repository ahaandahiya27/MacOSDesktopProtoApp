"What If?" — A Peek Beyond the Point

Hypothetical questions with no single right answer. Think hard before you read the discussion.

≈ 7 min read · brain-stretcher level

The textbook tells you what is. The best way to really understand an idea is to ask what if? Pick a question below, pause and think for a minute, then read one possible discussion.

What if 1 — money had no decimal point?

The question: What if prices could only be whole rupees, never paise?

🧠 Think first

How would you split a ₹10 bill three ways?

One discussion path: You could not write ₹3.33 — you would round, and small amounts would be lost or gained on every transaction. Decimals let us measure value finer than the smallest coin.

What if 2 — we wrote 1/3 exactly instead of 0.333…?

The question: What if calculators showed fractions, never decimals?

🧠 Think first

Which is easier to add to 0.5: 1/3 or 0.333…?

One discussion path: Fractions are exact but awkward to add unless denominators match; decimals are quick to add but sometimes never end. Each form is better for a different job — which is why we keep both.

What if 3 — a decimal point slipped one place?

The question: What if a ₹250.00 bill were typed as ₹2500.0?

🧠 Think first

How big is the mistake?

One discussion path: Shifting the point one place multiplies (or divides) by ten — here a ten-fold overcharge. The point's position is not decoration; it carries the entire size of the number.

📝 Stretch your thinking

None of these has one 'correct' answer — they are for arguing about. Try one on a friend or a parent and see whether their discussion path differs from yours.
