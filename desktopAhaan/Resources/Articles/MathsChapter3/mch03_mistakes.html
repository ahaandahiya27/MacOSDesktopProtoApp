Common Mistakes in A Peek Beyond the Point

The places students slip on this chapter — and the one-line fix for each.

&#8776; 5 min read &middot; revision-tier &middot; 5 fixes

These wrong answers come back year after year. None are silly — they are almost right, which is what makes them worth knowing. Read each, then cover the fix and try to spot what is off.

1. “A decimal with more digits is always bigger (so 1.04 > 1.4).”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Compare place by place from the left: 1.4 has 4 tenths, 1.04 has 0 tenths, so 1.4 > 1.04. More digits does NOT mean bigger.

2. “Adding a zero after a decimal changes its value (0.2 → 0.20).”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Trailing zeros add nothing: 0.2 = 0.20 = 0.200. But 0.2, 0.02, 0.002 ARE different — those zeros shift the digit into smaller places.

3. “You can add decimals by lining up the right-hand ends (like whole numbers).”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: You must line up the DECIMAL POINTS, not the ends. 2.7 + 3.5 needs tenths under tenths; aligning the ends would add tenths to ones.

4. “The first place after the point is 'oneths'.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: There is no 'oneths' place. The first place right of the point is TENTHS (1/10), then hundredths, then thousandths.

5. “You must split a unit into 10 parts; no other split is allowed.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: You CAN split into 4, 8, or any number of parts — people do (quarters, eighths). We choose 10 because it matches the base-ten place value system, so one uniform arithmetic works everywhere.
