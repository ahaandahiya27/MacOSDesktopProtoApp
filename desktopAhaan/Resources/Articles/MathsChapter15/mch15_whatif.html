"What If?" — Finding the Unknown

Hypothetical questions with no single right answer. Think hard before you read the discussion.

≈ 7 min read · brain-stretcher level

The textbook tells you what is. The best way to really understand an idea is to ask what if? Pick a question below, pause and think for a minute, then read one possible discussion.

What if 1 — you changed one side of an equation only?

The question: What if you subtracted 3 from the left but not the right?

🧠 Think first

Does the balance stay level?

One discussion path: The scale tips and the equation becomes false. The golden rule — do the same to both sides — is exactly what keeps the two sides equal while you solve.

What if 2 — an equation had no solution?

The question: What if you were asked to solve x = x + 1?

🧠 Think first

Is there any number that works?

One discussion path: None — no number equals itself plus one. Some equations genuinely have no solution, and recognising that is as important as finding one when it exists.

What if 3 — every equation had exactly one answer?

The question: What if no equation could have many solutions or none?

🧠 Think first

Is x + 0 = x true for one value of x or all of them?

One discussion path: It is true for every number, so it has infinitely many solutions. Equations can have one, none, or infinitely many answers — part of learning to 'find the unknown' is knowing which case you're in.

📝 Stretch your thinking

None of these has one 'correct' answer — they are for arguing about. Try one on a friend or a parent and see whether their discussion path differs from yours.
