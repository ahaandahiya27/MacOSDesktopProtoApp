Common Mistakes in Expressions Using Letter-Numbers

The places students slip on this chapter — and the one-line fix for each.

&#8776; 5 min read &middot; revision-tier &middot; 5 fixes

These wrong answers come back year after year. None are silly — they are almost right, which is what makes them worth knowing. Read each, then cover the fix and try to spot what is off.

1. “4n means 4 + n.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: 4n means 4 × n (the multiplication sign is just omitted). So 4n with n = 5 is 20, not 9.

2. “When you substitute a negative value, you can ignore its sign.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Keep the sign: if a = −4, then 10 − a = 10 − (−4) = 14, not 6. The letter stands for the whole signed number.

3. “Any two terms can be added into one (2l + 3b = 5lb).”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: Only LIKE terms (same letter) combine: 2l + 3l = 5l. Unlike terms (2l + 3b) cannot be merged.

4. “l + l = l² (or 2l means l × l).”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: l + l = 2l (two of them added). l × l would be l², a different thing entirely.

5. “A simplified expression like 2l + 2b is a different value from l + b + l + b.”

🚫 The mistake

A belief that feels right — but misses a key detail.

The fix: They are EQUAL — same value for every l and b. Simplification only changes the form, never the value.
