"What If?" — Expressions Using Letter-Numbers

Hypothetical questions with no single right answer. Think hard before you read the discussion.

≈ 7 min read · brain-stretcher level

The textbook tells you what is. The best way to really understand an idea is to ask what if? Pick a question below, pause and think for a minute, then read one possible discussion.

What if 1 — we had no letter-numbers?

The question: What if every rule had to be written out in words for each number separately?

🧠 Think first

How would you state 'a number plus three' for all numbers at once?

One discussion path: You would need an endless list: 1+3, 2+3, 3+3… A single letter-number, n + 3, captures every case in one short expression. That compression is the whole power of algebra.

What if 2 — a formula had to be re-checked for every number?

The question: What if proving a pattern meant testing it on all numbers, one by one?

🧠 Think first

Could you ever finish?

One discussion path: You never could — there are infinitely many numbers. Letter-numbers let you prove a pattern holds for all of them in a single argument, instead of testing forever.

What if 3 — a letter-number could only be a whole number?

The question: What if n in n + 3 were never allowed to be 2.5 or −1?

🧠 Think first

Which everyday problems would you lose?

One discussion path: You could not describe half a litre, a temperature below zero, or a price in paise. Letting letter-numbers stand for any value — not just whole ones — is what makes algebra describe the real world.

📝 Stretch your thinking

None of these has one 'correct' answer — they are for arguing about. Try one on a friend or a parent and see whether their discussion path differs from yours.
