Expressions Using Letter-Numbers: Key Words

Every term in this chapter, with a one-line meaning and an example.

&#8776; quick reference &middot; 10 terms

Knowing the exact words makes the maths click. Here is every key term from the chapter, defined plainly with an example you can picture.

Letter-number (variable)

A letter used to represent a number that is unknown or can change.

Example: In a + 3, the letter a is a letter-number.

In Hindi: चर

Algebraic expression

An expression containing one or more letter-numbers.

Example: 5m + 3 is an algebraic expression.

Formula

An algebraic expression or equation stating a general relationship.

Example: Perimeter of a square = 4q.

In Hindi: सूत्र

Coefficient

The number multiplying a letter-number in a term.

Example: In 5m, the coefficient is 5.

Substitution

Replacing a letter-number with a specific value to evaluate an expression.

Example: 5m + 3 with m = 2 gives 13.

In Hindi: प्रतिस्थापन

Like terms

Terms with the same letter-number part, which can be combined by adding coefficients.

Example: 2l and 3l are like terms; 2l + 3l = 5l.

Unlike terms

Terms with different letter parts, which cannot be combined.

Example: 2l and 3b cannot be added into one term.

Simplify

To rewrite an expression in a shorter equivalent form by collecting like terms.

Example: l + b + l + b simplifies to 2l + 2b.

Equal expressions

Two expressions that give the same value for every substitution.

Example: l + b + l + b = 2l + 2b for all l, b.

nth term

An expression giving any term of a sequence from its position number n.

Example: For 4, 8, 12, …, the nth term is 4n.
