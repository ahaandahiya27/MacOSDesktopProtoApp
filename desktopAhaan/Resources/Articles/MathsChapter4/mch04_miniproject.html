Expressions Using Letter-Numbers · Mini Project

🔤 Mini Project — Letter-Number Detective

A hands-on activity that turns this chapter into something you actually do, not just read.

≈ 35 min · do-it-yourself level

Reading about maths and doing maths are two different things. This short project lets you see the ideas of "Expressions Using Letter-Numbers" at work with your own hands.

What you'll need

  • A notebook
  • A pen
  • Everyday situations from home

Steps

  1. Find three situations at home where one quantity always relates to another by a fixed rule (e.g. 'total legs = 4 × number of chairs', 'cost = 12 × number of eggs').
  2. For each, choose a letter for the changing quantity and write the algebraic expression.
  3. Make a small table: try three different values of the letter and compute the result each time.
  4. Write the relationship as a 'formula' sentence too (e.g. 'total cost = 12 × number of eggs').
  5. Challenge a family member: give them your formula and a value, and check they get the same answer you did.

🔍 What you should notice

You'll see that one expression with a letter captures a whole table of cases — change the letter's value and the result follows the same rule every time.

Why it works

A letter-number stands for 'any value' of a changing quantity, so an expression built from it encodes the general relationship. Substituting different values just reads off different rows of the same underlying pattern — which is exactly what algebra is for.
