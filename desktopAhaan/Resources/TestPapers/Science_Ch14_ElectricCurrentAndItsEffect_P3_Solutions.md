## Worked Solutions

**1. (B)** Standard convention: long thin line = positive terminal, short thick line = negative terminal; the student called the short thick line positive, so it is reversed. The lines are terminals of the cell, not wires (wires are plain lines), so the 'connecting wires' option fails. Thickness is purely a drawing convention for marking the negative side, not a measure of cell strength. The symbol's meaning does not depend on whether it is drawn left or right, so position cannot decide the sign.

**2. (C)** Voltages add only when cells are in series, i.e. + of one to − of the next, giving 2+2+2 = 6 V. Joining all positives together and all negatives together is a parallel arrangement that keeps the voltage at one cell (2 V), not 6 V. Joining + to + and − to − makes cells oppose, so their pushes partly cancel rather than add. Air gaps break the conducting path entirely, so no current and no battery action.

**3. (B)** When cells oppose (+ to +), their voltages subtract; two equal cells leave roughly zero net push, so the bulb stays dark — that is the correct reason. The cells are not individually too weak; the issue is cancellation, not weakness. Opposing cells do not double the voltage — that would require series aiding (+ to −), so the 'burns out' option is wrong. Two correctly arranged cells routinely light torch bulbs, so 'a torch must use one cell' is false.

**4. (B)** Series-aiding cells add their pushes, so each extra cell raises the voltage and current, making the bulb brighter — and excess current can burn the filament, which is the full correct statement. Series cells do not 'share' current; current is the same all round the loop, so the dimmer option is wrong. Brightness is set by the total voltage, not capped by the first cell, so 'stays the same' fails. The number of cells being odd or even has nothing to do with completing a loop.

**5. (A)** Conventional current leaves the positive (long thin) terminal, travels the external loop, and returns to the negative (short thick) terminal — the correct path. Starting at the negative terminal reverses this, so that option is wrong. Current does not emerge from the 'middle' of a cell in two directions; it follows the single loop. Current must complete the whole loop back to the cell, so 'never back to the cell' is impossible for a working circuit.

**6. (C)** A small circle with a cross is the standard symbol for a bulb; with a cell and a closed switch the loop is complete, so the bulb glows — the correct reading. A cell is drawn as long-thin and short-thick lines, not a crossed circle, so 'cell' is wrong. An open switch is a raised arm leaving a gap, not a crossed circle. A fuse is usually shown as a thin line in a rectangle, not a crossed circle, so the fuse reading is also wrong.

**7. (D)** An arm lying flat across both contacts bridges the gap, making the switch closed and the loop complete, so the bulb can glow — correct. An open switch is the raised-arm form leaving a gap, not the flat form, so 'open' is wrong. A switch arm lying flat is its normal closed position, not a melted fuse. A switch arm has nothing to do with recharging a cell, so that option is irrelevant.

**8. (B)** Having a cell and bulb is not enough; the loop must be unbroken, and the open switch breaks it, so no current flows — that is the correct reason. A cell does not need 'charging' to drive a bulb, so that option is false. Connecting wires have very low resistance and do not 'absorb' the current, so the bulb-receives-nothing claim is wrong. A single fresh cell can easily light a torch bulb, so 'never enough push' is false.

**9. (D)** A low-resistance wire across the bulb gives current an easy bypass, so most current avoids the high-resistance filament and the bulb stays dark — correct. The extra path steals current from the bulb rather than feeding it more, so 'brighter' is wrong. The short clearly does change behaviour, so 'nothing changes' is false. The cell is heavily loaded but does not become permanently dead just from a brief short, so 'stops forever' overstates it.

**10. (C)** A break anywhere — even hidden inside insulation — makes the circuit open, so no current flows and the bulb stays dark; that is correct. A circuit with a break is not closed, so 'closed circuit, wrong colour' is wrong (and bulb colour is irrelevant to glowing). A short circuit is an unintended low-resistance path, not a break, and would not be caused by a snapped wire. A single cell does not turn into a two-cell battery, so that option is nonsense.

**11. (D)** Dry wood is an insulator; placed in series it breaks the conducting path, so no current flows and the bulb stays dark — correct. Wood is a poor conductor, not a good one, so the 'carries current away' option is the opposite of the truth. Wood is not a metal and does not melt like a fuse wire. Magnetism does not block ordinary current flow, and wood is not magnetic, so that option fails.

**12. (B)** Rubber is a classic insulator; using it in place of a wire leaves the loop electrically incomplete, so no current flows and the bulb is dark — correct. Rubber conducts far worse than metal, not better, so the 'better conductor' option is wrong. The bulb fails immediately on connection, not because rubber melted; rubber is not a fuse element. Inserting rubber does not flip the cell's terminals, so the 'reverses current' option is false.

**13. (A)** Of the four, only copper is a metal conductor; glass, plastic and dry wood are insulators that block the loop, so the bulb glows only with copper — correct. Not 'anything' completes a circuit; insulators do not, so 'all four' is wrong. A single cell can light a torch bulb, so 'needs two cells' is false. Being clear or smooth has nothing to do with conduction; glass and plastic are insulators, so that option fails.

**14. (C)** Graphite conducts electricity despite being a non-metal, so it completes the loop and the bulb glows — the correct lesson. The wooden casing is an insulator; if it carried the current the bulb would not glow, so that option is wrong. A faint steady glow does not mean the graphite is melting like a fuse. Graphite produces no current of its own; the cell drives the current, so the 'generates its own current' option is false.

**15. (A)** For the same material and length, a thinner wire has higher resistance, allowing less current, so the bulb is dimmer — correct. The wire is not an insulator (the bulb still glows dimly), so 'perfect insulator' is wrong. The two wires are stated to be the same length, so the higher resistance is due to thinness, not length. More current would make the bulb brighter, not dimmer, so the 'carries more current' option is self-contradictory.

**16. (B)** Every ordinary wire has some resistance, so current always produces at least a little heat — the claim is wrong, which is the correct verdict. Heating is not unique to nichrome; nichrome simply heats much more, so 'only special wires' is false. Carrying current never cools a wire below its surroundings, so the 'copper cools down' option is wrong. Most wires get warm without glowing; only very hot filaments emit visible light, so 'every wire glows' is false.

**17. (B)** Same current through both means the higher-resistance nichrome produces much more heat, so it glows while copper stays cool — correct. In a series loop the same current flows through both, so 'copper carries no current' is false. Heating is due to resistance, not magnetism, and being magnetic would not heat a wire, so that option is wrong. Copper actually has a lower melting point than nichrome, and melting point does not stop a wire heating; this reasoning is backwards.

**18. (C)** For the same voltage, the shorter wire has lower resistance and so passes more current, producing more heat — correct. 'More metal' does not guarantee more heat; the long wire's higher resistance limits the current, so X does not automatically win. Length does change resistance (longer = more resistance), so 'no difference' is false. A longer wire has higher resistance and so carries less current, not more, making the 'more room' option wrong.

**19. (D)** Nichrome's high resistance produces strong heating and its high melting point lets it glow red without melting — exactly why it is chosen. A better conductor (like copper) has lower resistance and heats less, so 'far better conductor' is the opposite of what is wanted. Glowing comes from heat, not magnetism, so the magnetic option is wrong. A low melting point would make the element melt when hot; nichrome's melting point is high, so that option is false.

**20. (A)** Tungsten's extremely high melting point lets the filament reach white heat without melting, and the coil fits a long, thin, high-resistance wire into a tiny space — the correct full reason. Copper would melt long before reaching glowing temperatures, so 'copper glows more brightly' is false. The coil is functional, not decorative, so that option is wrong. A low melting point would be a fatal flaw for a filament; tungsten's point is high, so that reasoning is backwards.

**21. (C)** More running time means more heat delivered, so the longer-heated water is warmer — correct. There is no fixed 'final temperature' from power alone; longer heating keeps adding energy, so 'same temperature' is wrong. A shorter time delivers less energy, not more, so the 'quick burst' option is false. Immersion heaters work on the heating effect, not the magnetic effect, so the last option misidentifies the principle.

**22. (C)** An iron, a toaster and a geyser all heat a high-resistance element, so they rely on the heating effect — correct. A bell, crane magnet and loudspeaker rely on the magnetic effect, not heating. A fan, mixer and pump use motors (magnetic effect) to produce motion, not heat. A compass and bar magnet are not even powered appliances, and a torch switch only opens or closes a circuit, so that set is wrong.

**23. (A)** A fuse is a thin, low-melting-point wire that overheats first under excess current and melts to open the circuit, protecting the rest — correct. A wire that carries 'any current' would never melt and so could not protect anything, so the high-melting option is wrong. A fuse does not store charge; it simply melts when overloaded, so the 'stores charge' option is false. A fuse does not speed up current; that misunderstands its purpose entirely.

**24. (D)** A fuse rated at the safe limit (5 A) passes normal current but blows just above it, giving protection — correct. A 50 A fuse would let dangerously large currents flow without melting, defeating the protection, so it is wrong. A 0.5 A fuse would blow constantly during normal use, making the circuit unusable. Fitting no fuse removes all protection, which is unsafe, so that option fails.

**25. (D)** A thick copper link never melts, so an overload is no longer cut off and the wiring can overheat and catch fire — the correct danger. The fix does not dim bulbs; it removes protection, so the 'dimmer bulbs' option misses the point. Mains wiring has no cells to charge backwards, so that option is irrelevant. The hazard is overheating/fire, not a strong magnetic effect, so the last option is wrong.

**26. (B)** Drawing too much current at once is an overload, and the fuse melts to interrupt it — correct. Fuses respond to excessive current, not to a current that is too low, so the 'drop in current' option is wrong. Mains appliances are not cell-powered, so 'cells the wrong way' is irrelevant. The fuse melts from heating, not from a magnetic pull, so the magnetic option is false.

**27. (D)** Being thin (higher resistance) and made of low-melting metal, the fuse wire heats fastest and melts first, protecting the thicker wiring — correct. In series the same current flows through the fuse and the wiring, so 'carries no current' is false. A better conductor has lower resistance and heats less, so 'better conductor' is the opposite of the truth. Melting is caused by heating, not magnetism, so the magnetic option is wrong.

**28. (B)** A fuse works by melting to open the circuit, not by quietly conducting the surplus current onward — so the statement is wrong, which is the correct verdict. It is not 'exactly how every fuse works,' since fuses break rather than conduct excess, so that option is false. A fuse does not raise the current; it cuts it off, so the 'increases current' option is wrong. Electric bells do not contain protective fuses of this kind, so that qualifier is meaningless.

**29. (D)** An MCB trips on overload and is reset by flicking it back on, replacing the one-use fuse — correct. A tungsten filament is the light-emitting part of a bulb and offers no resettable protection. An electromagnet is a coil-and-core magnet, not a circuit protector. A cell supplies energy and does not protect against overload, so it is wrong.

**30. (B)** A 30 A fuse tolerates much larger currents before melting, removing protection and risking overheated wiring — the correct concern. A higher rating melts less easily, not more, so the 'cuts supply more often' option is backwards. Fuse rating does not reverse current direction, so that option is nonsense. A bigger fuse does not halve appliance power; it just permits more current, so the last option is wrong.

**31. (A)** The needle deflected only when current flowed, because a current produces a magnetic field — that is Oersted's discovery and the correct condition. A wire with no current produces no field, so the still-wire option cannot deflect the needle. Painting a wire changes nothing electrically or magnetically. Merely shortening the wire does not start a current, so that option is also wrong.

**32. (C)** The wire's magnetic field exists only while current flows, so when it stops the needle returns to north–south — correct. The wire is not permanently magnetised by a brief current, so the 'locked forever' option is wrong. Switching off does not make the needle spin endlessly; it settles back, so that option is false. There is no stored heat that melts a compass needle on switch-off, so the 'melts' option is absurd.

**33. (B)** A current produces a magnetic field, so a nearby compass deflecting on switch-on confirms current flows without opening the cable — correct. Current does not change a cable's colour, so that observation proves nothing. Carrying current does not add mass, so 'heavier' is false. A cable does not measurably lengthen because current flows, so the 'longer' option is wrong.

**34. (A)** Winding the wire into a coil adds the fields of many turns, and a soft-iron core multiplies the effect, so the electromagnet is much stronger — correct. Coiling reinforces rather than cancels the field, so 'no effect' is wrong. The iron does not absorb the magnetism; it strengthens it, so 'weaker' is false. A coil still has both effects; coiling does not remove magnetism, so the 'only heating' option is wrong.

**35. (C)** With the cell fixed, adding more turns increases the magnetic effect, so it is the sensible choice — correct. Removing the iron core weakens the magnet, the opposite of the goal. Fewer turns also weaken it, so that option is wrong. A wooden rod is non-magnetic and does not strengthen the field the way iron does, so replacing iron with wood weakens the electromagnet.

**36. (A)** More current (two cells in series) and more turns both strengthen the electromagnet, so it lifts more nails — correct. Cells in series add their push and do not 'share' the effect, so 'decrease' is wrong. An electromagnet's strength is adjustable, not fixed, so 'stay the same' is false. Extra turns add to, rather than cancel, the magnetism, so the 'drop to zero' option is wrong.

**37. (D)** An electromagnet attracts magnetic materials such as iron and steel, so it lifts the iron rods but leaves aluminium, copper and plastic — correct. It does not attract every material, so 'every object' is wrong. Plastic is non-magnetic and is not picked up at all, so 'only the plastic crates' is false. Electromagnets in cranes do lift heavy iron loads, so 'nothing at all' is wrong.

**38. (C)** An electromagnet's magnetism can be switched on and off with the current, letting the crane grab and release scrap — the correct advantage. It does need current to work, so the 'works without current' option is false. Electromagnets are built from coil and iron core, not plastic, so that option is wrong. The very point is that it can be switched off to drop the load, so 'always magnetic, never drops' contradicts its useful behaviour.

**39. (C)** Breaking the contact stops the current, the electromagnet de-magnetises, the spring returns the armature, the contact remakes and the whole cycle repeats — giving continuous ringing, which is correct. The current does not grow each cycle, and the bell does not melt, so that option is wrong. The core is soft iron, not a permanent magnet, so it cannot hold the armature, making that option false. Because the cycle repeats, the bell does not stop after one strike, so the 'once and silent' option is wrong.

**40. (C)** An electromagnet (soft-iron core plus coil) is magnetic only while current flows and loses it when the current stops — exactly the described behaviour. A permanent steel magnet keeps its magnetism with no current, so it does not fit. A plain copper wire carries current but is non-magnetic as a material and makes a very weak field without a core or coil, so it is not the intended answer. A tungsten filament heats and glows; it is not a magnet, so it is wrong.

**41. (B)** A current simultaneously warms the wire (heating effect) and sets up a magnetic field around it (magnetic effect) — both occur together, which is correct. It is not heating only, since the magnetic effect is real (Oersted), so that option is wrong. It is not magnetic only, since resistive heating always occurs, so that option is wrong. Both effects exist while current flows, not after switch-off, so the last option is false.

**42. (D)** A soft-iron core multiplies a coil's magnetic effect, so the iron-cored coil P is much stronger — correct. Air does not boost magnetism the way iron does, so the air-cored Q is weaker, not stronger. The core makes a large difference, so 'exactly equal' is false. A current-carrying coil is magnetic whether or not it has a core, so 'neither is magnetic' is wrong.

**43. (A)** A soft-iron electromagnet loses its magnetism when the current stops, so the nails drop — that is the whole point and the correct reason. Soft iron does not stay strongly magnetised after switch-off, so 'stays a magnet for ever' is wrong. The nails fall as soon as the current stops, without any need to unwind the coil, so that option is false. The current does switch off when the circuit is broken, so 'never switches off' is incorrect.

**44. (A)** Closing the switch removes the gap, completing the loop so current flows through the bulb and it lights — correct. A switch does not add a cell or raise the voltage, so that option is wrong. Closing a switch does not increase the bulb's resistance; the bulb glows because current can now flow, so that option is false. A switch does not flip the cell's terminals, so the 'reverses terminals' option is wrong.

**45. (A)** Cells facing against each other have voltages that subtract, leaving nearly zero net push, so the bulb stays dark — correct. Opposing cells subtract rather than double the voltage, so the 'double, destroys bulb' option is wrong. Opposing cells do not create a low-resistance bypass; the dark bulb is due to cancellation, not a short. The switch is closed and good; the real cause is the opposing cells, so 'must be the switch' is false.

**46. (B)** Series-aiding cells add their voltages, so the current and brightness increase — the child's 'dimmer' prediction is wrong, which is the correct verdict. Cells in series do not split the work; current is the same throughout, so the 'share the work' reasoning is false. The result does not depend on the filament being tungsten, so that qualifier is meaningless. The bulb brightens rather than going out, so the 'goes out' option is also wrong.

**47. (B)** A switch makes or breaks the loop to turn current on or off — correct. Breaking the circuit on excess current is the fuse's job, not the bulb's, so that pairing is wrong. A fuse melts to break the circuit; it does not store charge, so 'fuse — store charge' is false. A cell supplies energy; it does not measure current, so the last pairing is wrong.

**48. (D)** A toaster heats a high-resistance element (heating effect) and a fan spins a motor driven by magnetism (magnetic effect) — correct. Swapping the two is wrong, since toasters do not spin and fans do not heat to cook, so the swapped option fails. A fan does not rely on heating, so 'both heating' is wrong. A toaster's job is heat, not motion, so 'both magnetic' is also wrong.

**49. (A)** An immersion heater warms water through a resistive element (heating effect) and a bell uses an electromagnet (magnetic effect) — correct. The two are not swapped: a heater does not work by magnetism nor a bell by heating, so the swapped option is wrong. A bell does not heat water, so 'both heating' fails. A heater does not ring by magnetism, so 'both magnetic' is also wrong.

**50. (D)** Electromagnets attract magnetic materials like iron and steel, but not plastic, aluminium or wood, so the claim that it attracts them 'just as strongly as iron' is the incorrect statement — the right pick. The on/off control over a permanent magnet is a true property. Strength rising with more turns or current is true. Attracting iron and steel while current flows is true. So the three true statements are not the answer.

**51. (C)** A plain wire straight across the cell's terminals is a low-resistance short that draws most of the current away from the bulb, so the bulb is dim or dark — correct. The short steals current rather than giving the bulb more, so 'brighter' is wrong. A direct short across the cell clearly changes the behaviour, so 'changes nothing' is false. A cell can have many wires connected; nothing forbids two, so the 'only one wire' option is wrong.

**52. (D)** In a single series loop, both switches must be closed; an open switch anywhere breaks the loop and stops current — correct. With switches in series, closing only one still leaves the other gap open, so 'either one is enough' is wrong. Open switches break the loop, so 'both open' would give no current. Mixing one open and one closed still leaves an open gap, so the 'balance' option is false.

**53. (C)** In a series loop a broken filament opens the whole loop, so no current flows and the second bulb is also dark — correct. With the loop broken, no current flows at all, so the second bulb cannot glow brighter, ruling out 'twice as bright.' Series bulbs share one path, not separate paths, so 'glows normally' is false. With zero current there is nothing to make a bulb explode, so that option is wrong.

**54. (B)** A closed switch in an unbroken loop makes a closed circuit, so the bulb should glow — the student misread it. A multi-cell battery does not force the circuit open; it just supplies more voltage, so that option is false. Having a bulb in the loop does not make the circuit open, so that reasoning is wrong. A circuit being on paper does not make it open; the switch state decides, so the last option is false.

**55. (C)** A cell gradually discharges with use, weakening the current until the bulb goes out — correct, especially as wires and switch test fine. Copper wires do not transform into insulators with use, so that option is wrong. A closed switch does not open itself, and the switch tested fine, so that option is false. Bulb glass does not thicken to block light; the dimming is from the failing cell, so the last option is wrong.

**56. (D)** The very thin tungsten filament reaches white heat and emits bright light, while the heater element glows only dull red — correct. Both work by the heating effect; the bulb does not use the magnetic effect, so that option is wrong. The filament does not stay cool; it must get extremely hot to glow, so 'lower resistance, stays cool' is false. Filaments are tungsten, not copper, and copper would melt before glowing, so the last option is wrong.

**57. (D)** An open switch cuts the current, the field collapses, and the soft-iron core loses its magnetism, so the pins fall — correct. Stopping the current weakens the magnet to nearly nothing rather than strengthening it, so 'stronger magnet flings them' is wrong. No current means no heating, so 'melts the pins' is false. Gravity is constant; the pins fall because the magnetism vanished, so the 'gravity increased' option is absurd.

**58. (A)** An electromagnet attracts magnetic iron, so it pulls iron filings out of a sand mixture, leaving the non-magnetic sand — correct. Salt and sugar are both non-magnetic, so the magnet cannot pick out the salt, ruling that out. Sand and sawdust are both non-magnetic, so the magnet attracts neither. Copper and aluminium are both non-magnetic, so the magnet cannot separate them either.

**59. (A)** If the springy strip never touches the screw, the circuit cannot close, so no current flows to the electromagnet and the bell stays silent — correct. A permanent gap means the loop never closes, so it cannot ring louder or faster, ruling out 'continuous and louder.' With no current ever flowing, even a single strike is impossible, so 'rings once' is wrong. An open contact carries no current, so there is nothing to overheat or melt, making the last option false.

**60. (A)** A fuse protects by melting when the current is too high, so it must be thin and low-melting; a thick high-melting copper wire would never melt and would give no protection — the correct explanation. The claim is not correct, because a fuse that never melts cannot protect, so the 'it is correct' option is wrong. Thick high-melting copper melts less easily, not more, so 'melts too easily' is backwards. Copper is widely used for connecting wires, so 'cannot be used in any circuit' is false.
