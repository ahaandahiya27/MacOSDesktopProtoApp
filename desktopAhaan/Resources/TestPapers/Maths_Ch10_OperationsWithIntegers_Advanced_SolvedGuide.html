Q1

A token at 0 on a number line is moved −8, then +15, then −4. Its final position is:

  • A−3
  • B+27
  • C+3✓
  • D−27

Working

✓

Add left to right: 0 + (−8) = −8; −8 + 15 = +7; +7 + (−4) = +3. The token lands at +3. Trap: forgetting the last −4 lands you at +7.
