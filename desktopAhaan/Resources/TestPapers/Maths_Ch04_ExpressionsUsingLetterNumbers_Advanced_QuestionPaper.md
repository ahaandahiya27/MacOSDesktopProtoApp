**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Remember 4n means 4 × n; only LIKE terms combine (2a + 3b stays, never 5ab); l + l = 2l, not l²; and when you substitute, keep every sign exactly as given. This paper is about building, simplifying and evaluating expressions — never solving equations. It does not repeat any question from Paper 1.
