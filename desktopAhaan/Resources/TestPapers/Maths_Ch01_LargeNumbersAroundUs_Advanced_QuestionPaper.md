**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Most questions need two or more steps — estimate first, then compute exactly when the options are close. Work in the Indian system (lakh, crore, arab) unless a question names the International system (thousand, million, billion). Watch the classic traps: confusing one lakh (10⁵) with one million (10⁶), miscounting zeros, rounding the wrong way, and comparing numbers with different digit-counts before lining up place values. This paper does not repeat any question from Paper 1.
