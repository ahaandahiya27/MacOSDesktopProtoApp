**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Every distractor is a number you reach by a real slip — a one-lakh-for-one-million swap, a comma shifted one period, place value confused with face value, rounding the wrong direction, or a digit miscounted by one. Do not write on this paper — mark answers on your answer sheet.
