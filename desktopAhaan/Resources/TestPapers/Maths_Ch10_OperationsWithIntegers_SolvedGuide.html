Q1

A carrom coin at 0 is struck +6, then −9, then +1 on a number line. Its final position is:

  • A−2✓
  • B+2
  • C+16
  • D−16

Working

✓

Track position: 0 + 6 = +6, then +6 + (−9) = −3, then −3 + 1 = −2. The trap +16 comes from adding magnitudes 6+9+1 ignoring direction; +2 forgets that the −9 strike overshoots 0.

Q2

Compute (−13) + (+13) + (−13).

  • A−39
  • B−13✓
  • C+13
  • D0

Working

✓

(−13) + (+13) = 0 (opposite tokens cancel), then 0 + (−13) = −13. Adding magnitudes gives the trap −39; cancelling the wrong pair gives +13.

Q3

Subtracting a negative integer from another integer is the same as:

  • Asubtracting its magnitude
  • Bleaving the number unchanged
  • Cadding its opposite✓
  • Dmultiplying by −1

Working

✓

The golden rule: subtracting an integer = adding its opposite. So a − (−b) = a + b. It is not "multiply by −1" or any of the others.

Q4

Evaluate (−8) − (−15).

  • A7✓
  • B−23
  • C−7
  • D23

Working

✓

(−8) − (−15) = (−8) + (+15) = +7. Subtracting a negative ADDS. The trap −23 treats it as (−8) + (−15).

Q10

A diver is at −18 m. She rises 7 m and then descends 12 m. Her final depth is:

Q11

Which sign rule is INCORRECT?

  • A(−)(−) = −✓
  • B(+)(+) = +
  • C(+)(−) = −
  • D(−)(+) = −

Working

✓

The correct rules are (+)(+)=+, (+)(−)=−, (−)(+)=−, (−)(−)=+. So "(−)(−) = −" in option (A) is the INCORRECT statement — two negatives give a POSITIVE.

Q12

Evaluate (−3) × (5 − 8) + (−2) × (−4).

  • A1
  • B−17
  • C25
  • D17✓

Working

✓

Brackets first: 5 − 8 = −3. So (−3) × (−3) = +9, and (−2) × (−4) = +8. Sum = 9 + 8 = 17. The trap 1 uses 9 + (−8); −17 mishandles a sign.

Q13

The product of several non-zero integers is negative. This means the number of negative factors is:

  • Aodd✓
  • Beven
  • Cexactly one
  • Dexactly two

Working

✓

A product is negative only when there is an ODD number of negative factors (so one survives unpaired). Even → positive. "Exactly one" is too restrictive (3, 5, … also work).

Q19

Which statement about 0 is TRUE for integers?

  • A0 is the identity for multiplication
  • B0 has no opposite
  • C0 is the identity for addition✓
  • Devery integer times 0 is itself

Working

✓

0 is the additive identity: n + 0 = n for every integer. (1 is the multiplicative identity, so (A) is false; 0 IS its own opposite, so (B) is false; any integer × 0 = 0, so (D) is false.)

Q21

A submarine at −250 m rises in three equal stages and reaches −40 m. Each stage was:

  • A+210 m
  • B−70 m
  • C+70 m✓
  • D+90 m

Working

✓

Total rise = (−40) − (−250) = −40 + 250 = +210 m over 3 equal stages → 210 ÷ 3 = +70 m each. The trap +210 forgets to divide by 3.

Q22

If a × (−1) is computed for any integer a, the result is:

  • Aalways negative
  • Balways positive
  • Calways 0
  • Dthe opposite of a✓

Working

✓

a × (−1) = −a, the opposite (additive inverse) of a, for every integer (e.g. 5 → −5, −5 → +5). It is not "always negative" — that fails when a is itself negative.

Q23

Evaluate (−6) + (−6) + (−6) + (−6) + (−6).

  • A−30✓
  • B+30
  • C−24
  • D−36

Working

✓

Five copies of −6: (−6) × 5 = −30. Repeated addition of a negative is multiplication by a positive count, staying negative. The trap +30 flips the sign.

Q24

The value of (−15) − (−15) + (−15) is:

  • A−45
  • B0
  • C−15✓
  • D+15

Working

✓

(−15) − (−15) = (−15) + 15 = 0, then 0 + (−15) = −15. The trap 0 stops after the cancelling pair and ignores the last term.

Q25

Which property is shown by (−6) × 3 = 3 × (−6)?

  • Aassociative
  • Bdistributive
  • Ccommutative✓
  • Didentity

Working

✓

Swapping the order of the two factors with the product unchanged is the COMMUTATIVE property of multiplication (a × b = b × a). Associative is about grouping three or more.

  • A−16
  • B+16✓
  • C−8
  • D+8

Working

✓

(−4)² = (−4) × (−4) = +16 (the negative is squared, two negative factors → positive). The trap −16 confuses it with −4².

Working

Q35

Which is the correct order to evaluate (−6) + 4 × (−3)?

Working

✓

Q38

A shopkeeper made a profit of ₹120 on Monday, a loss of ₹85 on Tuesday, and a loss of ₹60 on Wednesday. Over the three days he:

✓

Q47
