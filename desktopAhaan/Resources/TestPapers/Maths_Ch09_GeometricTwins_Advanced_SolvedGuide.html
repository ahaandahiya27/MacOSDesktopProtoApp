Set 1 · Q1–Q10

Q1

Two figures are congruent when they have the same shape and the same:

  • Acolour
  • Bposition
  • Csize✓
  • Dname

Working

✓

Congruent figures match in both shape and size.

Q2

Which of these is NOT a valid triangle congruence criterion?

  • AAAA✓
  • BSSS
  • CSAS
  • DASA

Working

✓

AAA fixes only the shape (similarity), not the size, so it is not a congruence rule.

Q3

The SAS criterion requires the angle to be:

  • Aany angle
  • Ba right angle
  • Cthe largest angle
  • Dthe included angle (between the two sides)✓

Working

✓

SAS works only when the known angle lies between the two known sides — the included angle.

Q4

The RHS criterion applies to:

  • Aall triangles
  • Bright-angled triangles✓
  • Cequilateral triangles
  • Dobtuse triangles

Working

✓

RHS (right angle–hypotenuse–side) is for right-angled triangles.

Q5

The ASA criterion matches two angles and the:

  • Alongest side
  • Bany side
  • Cincluded side✓
  • Dhypotenuse

Working

✓

ASA uses two angles and the side lying between them — the included side.

Q6

The SSS criterion matches:

  • Aall three sides✓
  • Btwo sides and an angle
  • Cthree angles
  • Dtwo angles and a side

Working

✓

SSS matches all three pairs of sides.

Q7

Two triangles with equal angles but different sizes are:

  • Acongruent
  • Bequal
  • Cidentical
  • Dsimilar but not congruent✓

Working

✓

Equal angles but different sizes make the triangles similar, not congruent.

Q8

The symbol used for "is congruent to" is:

  • A=
  • B≅✓
  • C~
  • D≈

Working

✓

The congruence symbol is ≅.

Q9

If △ABC ≅ △DEF, then side AB corresponds to side:

  • AEF
  • BDF
  • CDE✓
  • DFE

Working

✓

In △ABC ≅ △DEF the order of letters pairs A↔D, B↔E, so AB ↔ DE.

Q10

CPCT tells us that corresponding parts of congruent triangles are:

  • Aequal✓
  • Bsimilar only
  • Cproportional
  • Dsupplementary

Working

✓

CPCT: corresponding parts of congruent triangles are equal.

Q11

Is SSA a valid congruence criterion in general?

  • Ayes, always
  • Byes, for acute triangles
  • Cyes, for isosceles triangles

Working

✓

SSA is not a general congruence rule (the angle isn't between the two sides).

Q12

Two line segments are congruent when they have:

  • Athe same midpoint
  • Bequal length✓
  • Cthe same colour
  • Dthe same direction

Working

✓

Segments are congruent exactly when their lengths are equal.

Q13

Triangles with sides (5, 6, 7) and (5, 6, 7) are congruent by:

  • AASA
  • BRHS
  • CSSS✓
  • DAAA

Working

✓

All three sides match, so the triangles are congruent by SSS.

Q14

Two triangles each have sides 4 and 5 with a 60° angle between them. They are congruent by:

  • ASAS✓
  • BSSS
  • CASA
  • DAAA

Working

✓

Two sides and the angle between them match — SAS.

Q15

If △ABC ≅ △PQR and ∠A = 50°, then ∠P is:

  • A40°
  • B130°
  • C90°
  • D50°✓

Working

✓

Corresponding angles are equal, so ∠P = ∠A = 50°.

Q16

If △ABC ≅ △DEF and BC = 8, then EF is:

  • A4
  • B8✓
  • C16
  • Dcannot tell

Working

✓

Q17

  • ASSS

  • CRHS✓
  • DAAA

Working

✓

Equal hypotenuse and one equal leg in right triangles is the RHS case.

Two triangles each have angles 40° and 60° with the 5-unit side between them. They are congruent by:

  • AASA✓
  • BSAS
  • CSSS
  • DRHS

Q19

Two circles are congruent when they have equal:

  • Aareas only
  • Bcentres

  • Dradii✓

Working

✓

Circles are congruent when their radii are equal.

Q20

Two squares are congruent when they have equal:

  • Bsides✓

  • Dpositions

Working

✓

Squares are congruent when their side lengths are equal.

Q21

If △ABC ≅ △XYZ, then ∠C corresponds to:

  • A∠X
  • B∠Y
  • C∠Z✓
  • D∠A

Working

✓

A↔X, B↔Y, C↔Z, so ∠C corresponds to ∠Z.

Q22

Two triangles each with sides 3, 4 and 5 are:

  • Acongruent (SSS)✓
  • Bonly similar
  • Cnot comparable
  • Dcongruent only if drawn the same way up

Working

✓

Identical side triples 3, 4, 5 give congruence by SSS.

Q23

Triangles having all three angles equal (AAA) are always:

  • Acongruent
  • Bright-angled
  • Cthe same triangle
  • Dsimilar, but not necessarily congruent✓

Working

✓

AAA guarantees only the same shape — similar, not necessarily congruent.

Q24

If △ABC ≅ △DEF and the perimeter of △ABC is 24, the perimeter of △DEF is:

  • A12
  • B24✓
  • C48
  • Dcannot tell

Working

✓

Congruent triangles have equal corresponding sides, hence equal perimeters: 24.

Q25

The RHS congruence rule applies only to:

  • Ascalene triangles
  • Bisosceles triangles
  • Cright-angled triangles✓
  • Dequilateral triangles

Working

✓

RHS is a congruence test reserved for right-angled triangles.

Q26

In an isosceles triangle ABC with AB = AC, the two equal angles are:

  • A∠B and ∠C✓
  • B∠A and ∠B
  • C∠A and ∠C
  • Dall three

Working

✓

Angles opposite the equal sides AB and AC are ∠C and ∠B respectively, so ∠B = ∠C.

Q27

In a triangle with AB = AC and ∠B = 70°, the vertex angle ∠A is:

  • A70°
  • B110°
  • C55°
  • D40°✓

Working

✓

Base angles are 70° each, so ∠A = 180° − 70° − 70° = 40°.

Q28

The median drawn to the base of an isosceles triangle is also its:

  • Alongest side
  • Baltitude✓
  • Chypotenuse
  • Dexterior angle

Working

✓

In an isosceles triangle the median to the base is also the altitude (and bisector).

Q29

In an equilateral triangle, the three medians are:

  • Aperpendicular only
  • Bparallel
  • Cequal in length✓
  • Dunequal

Working

✓

By symmetry the three medians of an equilateral triangle are equal.

Q30

If two angles of a triangle are equal, the sides opposite them are:

  • Aequal✓
  • Bperpendicular
  • Csupplementary
  • Din ratio 2 : 1

Working

✓

The side-angle converse: equal angles force the opposite sides to be equal.

Q31

An isosceles triangle has a line of symmetry along the:

  • Abase
  • Blongest side
  • Cmedian to a leg
  • Daltitude from the apex✓

Working

✓

The axis of symmetry runs along the altitude from the apex to the base.

Q32

The base angles of an isosceles triangle whose vertex angle is 80° are each:

  • A80°
  • B50°✓
  • C100°
  • D40°

Working

✓

Base angles share 180° − 80° = 100°, so each is 50°.

Q33

In △ABC with AB = AC, the altitude from A bisects:

  • A∠B
  • Bside AB
  • Cside BC✓
  • Dside AC

Working

✓

The altitude from the apex of an isosceles triangle bisects the base BC.

Q34

Two congruent triangles always have equal:

  • Aareas✓
  • Bpositions
  • Ccolours
  • Dorientations

Working

✓

Congruent triangles are identical in size, hence equal in area.

Q35

If △ABC ≅ △DEF and the area of △ABC is 12, the area of △DEF is:

  • A6
  • B24
  • C144
  • D12✓

Working

✓

Equal triangles have equal areas: 12.

Q36

An equilateral triangle has how many lines of symmetry?

  • A1
  • B3✓
  • C0
  • D2

Working

✓

An equilateral triangle has 3 lines of symmetry.

Q37

The number of equal parts you must match to prove congruence by SSS is:

  • A1
  • B2
  • C3✓
  • D6

Working

✓

SSS needs the three pairs of sides matched.

Q38

If △PQR ≅ △STU, then side QR equals side:

  • ATU✓
  • BST
  • CSU
  • DUS

Working

✓

Q↔T, R↔U, so QR corresponds to TU.

Q39

Congruent figures are always:

  • Athe same colour
  • Blarger than each other
  • Cin the same place
  • Dsimilar✓

Working

✓

Congruent figures have the same shape, so they are necessarily similar.

Q40

Similar figures are always congruent. This statement is:

  • Atrue
  • Bfalse✓
  • Ctrue only for triangles
  • Dtrue only for circles

Working

✓

Similar figures can differ in size, so they need not be congruent — the statement is false.
