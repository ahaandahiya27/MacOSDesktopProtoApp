# Olympiad Test Paper — Social Science (Class 7)

| | |
|---|---|
| **Subject** | Social Science (NCERT Class 7) |

| **Total Questions** | 60 (Multiple Choice, single correct) |
| **Maximum Marks** | 240 |
| **Suggested Time** | 90 minutes |

**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Watch the classic traps: barter means goods-for-goods with NO money - the moment money is used it is no longer barter; money was invented AFTER barter to fix its problems; a note's value comes from trust and Reserve Bank backing, NOT from precious paper; modern coins and notes are FIAT money (valuable by law and trust, not precious metal); and UPI/cards/QR move the SAME rupees electronically - they are a new method, not a new currency. Do not write on this paper — mark answers on your answer sheet.
