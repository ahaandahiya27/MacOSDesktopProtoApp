# Olympiad Test Paper — Sanskrit (Class 7)
## Chapter 2: नित्यं पिबामः सुभाषितरसम् (Nityam Pibamah Subhashitarasam)

| | |
|---|---|
| **Subject** | Sanskrit (NCERT Class 7, Deepakam) |
| **Chapter** | 2 — नित्यं पिबामः सुभाषितरसम् (Nityam Pibamah Subhashitarasam) |
| **Total Questions** | 60 (Multiple Choice, single correct) |
| **Maximum Marks** | 240 |
| **Suggested Time** | 90 minutes |

**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Questions test the meaning and grammar of the subhashitas. Watch the classic traps: count exactly FIVE 'va' qualities (विद्या, वपुस्, वाणी, वस्त्र, विनय) and exactly SIX faults (निद्रा, तन्द्रा, भयम्, क्रोधः, आलस्यम्, दीर्घसूत्रता); आलस्यम् (laziness) and दीर्घसूत्रता (procrastination) are DIFFERENT faults; in the purification verse the intellect (बुद्धिः) is cleaned by KNOWLEDGE (ज्ञानेन), not water; and सुभाषितम् is NEUTER (plural सुभाषितानि). Sanskrit is quoted in Devanagari. Do not write on this paper — mark answers on your answer sheet.
