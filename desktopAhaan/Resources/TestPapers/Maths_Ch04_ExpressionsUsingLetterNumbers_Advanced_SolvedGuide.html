Set 1 · Q1–Q10

Q1

The value of 3a + 2b when a = 4 and b = −3 is:

  • A18
  • B0
  • C6✓
  • D−6

Working

✓

3(4) + 2(−3) = 12 − 6 = 6. Keep the sign of b exactly as given.

Q2

The value of 5x − 2y when x = −2 and y = 3 is:

  • A−16✓
  • B−4
  • C4
  • D16

Working

✓

5(−2) − 2(3) = −10 − 6 = −16.

Q3

The value of a² + b when a = 3 and b = −5 is:

  • A14
  • B−2
  • C1
  • D4✓

Working

✓

a² = 3² = 9; then 9 + (−5) = 4.

Q4

The value of 2(p + q) when p = 7 and q = −2 is:

  • A18
  • B10✓
  • C5
  • D14

Working

✓

Bracket first: 7 + (−2) = 5; then 2 × 5 = 10.

Q5

The value of (m − n)² when m = 5 and n = 8 is:

  • A−9
  • B−6
  • C9✓
  • D169

Working

✓

m − n = 5 − 8 = −3; then (−3)² = 9 (squaring removes the sign).

Q6

The value of 4k − k² when k = 3 is:

  • A3✓
  • B21
  • C−3
  • D9

Working

✓

4(3) − 3² = 12 − 9 = 3.

Q7

The value of ab − a − b when a = 2 and b = 5 is:

  • A10
  • B17
  • C13
  • D3✓

Working

✓

Q8

  • B12✓

  • D−36

Working

Q9

  • A18
  • B36
  • C9✓
  • D4

Working

Q10

The value of 10 − 2(x − 3) when x = 5 is:

  • A6✓

  • C14
  • D10

Working

"Five more than thrice n" is written as:

  • B5n + 3

✓

  • Dx − 8

Working

✓

  • D4s✓

"A number decreased by 7" is written as:

  • A7 − n
  • Bn − 7✓
  • C7n
  • Dn ÷ 7

Working

✓

"Decreased by 7" subtracts 7 from the number: n − 7.

Q25

"Twice the sum of a and b" is written as:

  • A2a + b
  • Ba + 2b
  • C2(a + b)✓
  • D2ab

Working

✓

Sum of a and b is (a + b); twice that is 2(a + b).

Q26

  • A50 + 12d✓
  • B62d
  • C50d + 12
  • D12 + 50d

Working

✓

Fixed ₹50 plus ₹12 for each of d km: 50 + 12d.

Q27

The perimeter of a rectangle of length l and breadth b is:

  • Alb
  • Bl + b
  • C4(l + b)
  • D2l + 2b✓

Working

✓

Q28

Q29

A person who is x years old now will, p years from now, be:

  • Ax − p
  • Bxp
  • Cx + p✓
  • Dp − x

Working

✓

Q30

The total number of legs of c cows and h hens is:

  • A5n
  • Bn + 3
