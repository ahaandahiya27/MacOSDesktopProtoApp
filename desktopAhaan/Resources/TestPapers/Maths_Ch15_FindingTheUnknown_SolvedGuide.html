Word → Equation

Key rule. Pick a letter for the unknown, translate each phrase literally, then equate. The verb is your equals sign.
Q1

The phrase "7 less than twice a number n" is written as:

  • A2(n − 7)
  • B2n − 7✓
  • C7 − 2n
  • D2n + 7

Working

✓

"Twice a number" = 2n; "7 less than" it = 2n − 7. (2(n − 7) would be "7 less than the number, then doubled".)

Q2

"When 5 is added to thrice a number, the result is 26." As an equation this is:

  • A3(x + 5) = 26
  • B5x + 3 = 26
  • C3x − 5 = 26
  • D3x + 5 = 26✓

Working

✓

"Thrice a number" = 3x; "5 added" = 3x + 5; "result is 26" → 3x + 5 = 26.

Q6

A number increased by 8 equals three times the result of decreasing the same number by 4. The number is:

  • A8
  • B5
  • C14
  • D10✓

Working

✓

x + 8 = 3(x − 4) → x + 8 = 3x − 12 → 8 + 12 = 3x − x → 20 = 2x → x = 10. Check: 10 + 8 = 18 = 3(10 − 4) = 18. ✓ (Forgetting to distribute the 3 over −4, i.e. x + 8 = 3x − 4, gives the trap 6.)

Q15

A number increased by 12 becomes three times the number. The number is:

  • A4
  • B6✓
  • C12
  • D3

Working

✓

x + 12 = 3x → 12 = 2x → x = 6.

Q18

The sum of a number and its successor is 5 less than three times the number. The number is:

  • A5
  • B4
  • C7
  • D6✓

Working

✓

Number = x, successor = x + 1. "Sum is 5 less than three times the number" → x + (x + 1) = 3x − 5 → 2x + 1 = 3x − 5 → 1 + 5 = 3x − 2x → x = 6. Check: 6 + 7 = 13 = 3·6 − 5 = 13. ✓

Q29

Find a number such that doubling it and adding 3 gives the same result as tripling it and subtracting 2.

  • A5✓
  • B1
  • C−5
  • D6

Working

✓

2x + 3 = 3x − 2 → 3 + 2 = 3x − 2x → x = 5. Check: 2·5 + 3 = 13 = 3·5 − 2. ✓

Q32

"When a number is divided by 5 and 3 is added, the result is 8." The number is:

  • A40

  • C55
  • D15

Working

✓

x/5 + 3 = 8 → x/5 = 5 → x = 25.

Q45

Brackets

Key rule. Multiply through the bracket FIRST, then collect like terms. Distribute, simplify, isolate.
Q7

Solve: 3(2x + 1) = 27.

  • A6
  • B9
  • C5
  • D4✓

Working

✓

3(2x + 1) = 27 → 6x + 3 = 27 → 6x = 24 → x = 4. Check: 3(8 + 1) = 27. ✓

Q23

Solve: 5 − 2(x − 1) = 1.

  • A−3
  • B3✓
  • C2
  • D4

Working

✓

5 − 2(x − 1) = 1 → 5 − 2x + 2 = 1 → 7 − 2x = 1 → 2x = 6 → x = 3. (The trap is writing 5 − 2x − 2; the bracket flips the sign of −1 to +2.) Check: 5 − 2(2) = 1. ✓

Q37

Solve: 2(3x − 1) = 4(x + 2).

  • A3
  • B10
  • C5✓
  • D1

Working

✓

2(3x − 1) = 4(x + 2) → 6x − 2 = 4x + 8 → 2x = 10 → x = 5. Check: 2·14 = 28 = 4·7. ✓

Q48

Solve: 3 − (2x − 5) = 4.

  • A4
  • B−2
  • C2✓
  • D6

Working

✓

3 − (2x − 5) = 4 → 3 − 2x + 5 = 4 → 8 − 2x = 4 → 2x = 4 → x = 2. Check: 3 − (4 − 5) = 3 − (−1) = 4. ✓

Q56

Solve: 2(x + 4) − 3 = x + 9.

  • A4✓
  • B5
  • C9
  • D1

Working

✓

2(x + 4) − 3 = x + 9 → 2x + 8 − 3 = x + 9 → 2x + 5 = x + 9 → x = 4. Check: 2·8 − 3 = 13 = 4 + 9. ✓

Fractions

Key rule. Multiply both sides by the LCM (or cross-multiply if the equation is one fraction = another). Clear the denominators before transposing.
Q4

One-third of a number exceeds one-fourth of the same number by 5. The number is:

  • A60✓
  • B5
  • C20
  • D12

Working

✓

"Exceeds by 5" → x/3 − x/4 = 5. Multiply by 12: 4x − 3x = 60 → x = 60. Check: 60/3 − 60/4 = 20 − 15 = 5. ✓ (Reading "exceeds by 5" as x/3 = x/4 + 5 gives the same equation; the trap 5 is the difference itself.)

Q8

Solve: (2x − 1)/3 = 5.

  • A7
  • B8✓
  • C16
  • D23

Working

✓

(2x − 1)/3 = 5 → 2x − 1 = 15 → 2x = 16 → x = 8. Check: (16 − 1)/3 = 5. ✓

Q16

Solve: x/2 + x/3 = 10.

  • A6
  • B4
  • C24
  • D12✓

Working

✓

x/2 + x/3 = 10 → multiply by 6: 3x + 2x = 60 → 5x = 60 → x = 12. Check: 6 + 4 = 10. ✓

Q22

Half of a number, decreased by 6, equals one-third of the same number. The number is:

  • A12
  • B18
  • C9
  • D36✓

Working

✓

"Half of a number, decreased by 6" = x/2 − 6; this equals one-third of it: x/2 − 6 = x/3. Multiply by 6: 3x − 36 = 2x → x = 36. Check: 36/2 − 6 = 12 = 36/3. ✓

Q27

Solve: (x − 3)/2 = (x + 1)/4.

  • A5
  • B3
  • C11
  • D7✓

Working

✓

(x − 3)/2 = (x + 1)/4 → cross-multiply: 4(x − 3) = 2(x + 1) → 4x − 12 = 2x + 2 → 2x = 14 → x = 7. Check: 4/2 = 2 = 8/4. ✓

Q34

Solve: 2x/3 − x/2 = 1.

  • A3
  • B2
  • C6✓
  • D12

Working

✓

2x/3 − x/2 = 1 → multiply by 6: 4x − 3x = 6 → x = 6. Check: 12/3 − 6/2 = 4 − 3 = 1. ✓

Q40

Solve: (x − 1)/2 + (x + 1)/3 = 4.

  • A4
  • B6
  • C5✓
  • D7

Working

✓

(x − 1)/2 + (x + 1)/3 = 4. Multiply by 6: 3(x − 1) + 2(x + 1) = 24 → 3x − 3 + 2x + 2 = 24 → 5x − 1 = 24 → 5x = 25 → x = 5. Check: 4/2 + 6/3 = 2 + 2 = 4. ✓ (Dropping a sign on the brackets, e.g. 3x − 3 + 2x − 2, gives 5x = 29 and no clean answer — a signal you distributed wrongly.)

Q53

Solve: x/2 + 4 = x − 1.

  • A5
  • B6
  • C8
  • D10✓

Working

✓

x/2 + 4 = x − 1 → 4 + 1 = x − x/2 → 5 = x/2 → x = 10. Check: 10/2 + 4 = 9 = 10 − 1. ✓

Q59

Solve: (2x + 1)/3 = (x + 4)/2.

  • A5
  • B7
  • C8
  • D10✓

Working

✓

(2x + 1)/3 = (x + 4)/2 → cross-multiply: 2(2x + 1) = 3(x + 4) → 4x + 2 = 3x + 12 → x = 10. Check: 21/3 = 7 = 14/2. ✓

Variables on Both Sides

Key rule. Move all x-terms to one side and all constants to the other in ONE pass. Subtract the smaller x-coefficient to keep x positive.
Q5

Solve: 7x + 4 = 3x + 20.

  • A6
  • B2
  • C4✓
  • D3

Working

✓

7x + 4 = 3x + 20 → 7x − 3x = 20 − 4 → 4x = 16 → x = 4. Check: 7·4 + 4 = 32 = 3·4 + 20. ✓

Checking by Substitution

Key rule. Plug the candidate back into the ORIGINAL equation. LHS = RHS confirms; anything else means the candidate is wrong.
Q9

Which value of x satisfies 5x − 7 = 2x + 5?

  • A2
  • B3
  • C6
  • D4✓

Working

✓

5x − 7 = 2x + 5 → 3x = 12 → x = 4. Check: 20 − 7 = 13 = 8 + 5. ✓

Q21

For which equation is x = 3 the solution?

  • A2x + 1 = 5
  • Bx − 3 = 3
  • C4x − 5 = 7✓
  • Dx/3 = 9

Working

✓

Test x = 3: (A) 2·3 + 1 = 7 ≠ 5; (B) 3 − 3 = 0 ≠ 3; (C) 4·3 − 5 = 7 ✓; (D) 3/3 = 1 ≠ 9. So (C).

Q36

x = −2 is a solution of which equation?

  • A3x + 1 = 5
  • B2x + 9 = 5✓
  • Cx − 2 = 0
  • D4x = 8

Working

✓

Test x = −2: (B) 2(−2) + 9 = 5 ✓. The others: (A) −5 ≠ 5, (C) −4 ≠ 0, (D) −8 ≠ 8. So (B).

Q47

x = 2 is a solution of every equation below **except**:

  • A3x − 1 = 5
  • B2x + 3 = 5✓
  • Cx + 4 = 6
  • D5x = 10

Working

✓

Test x = 2: (A) 5 = 5 ✓, (B) 2·2 + 3 = 7 ≠ 5 ✗, (C) 6 = 6 ✓, (D) 10 = 10 ✓. The exception is (B).

Q51

Which value of x satisfies BOTH 2x − 1 = x + 3 and x/2 + 1 = 3?

  • A3
  • B2
  • C4✓
  • D5

Working

✓

Solve each and find the common value. First: 2x − 1 = x + 3 → x = 4. Second: x/2 + 1 = 3 → x/2 = 2 → x = 4. Both give x = 4, so 4 satisfies both. ✓ (A value satisfying only one equation — e.g. checking just the first — is the trap.)

Patterns → Equation

Key rule. Read the rule that turns the position number into the term. Then equate that rule to the target value and solve.
Q14

A matchstick pattern uses 4 sticks for 1 square, 7 for 2 squares, 10 for 3 squares (each extra square adds 3 sticks). How many squares can be made with exactly 31 sticks?

  • A7
  • B9
  • C10✓
  • D11

Working

✓

Sticks for n squares = 3n + 1. Set 3n + 1 = 31 → 3n = 30 → n = 10. Check: 3·10 + 1 = 31. ✓

Q25

In the sequence 3, 5, 7, 9, … (nth term 2n + 1), which term equals 25?

  • Athe 11th
  • Bthe 12th✓
  • Cthe 13th
  • Dthe 24th

Working

✓

2n + 1 = 25 → 2n = 24 → n = 12. So the 12th term.

Q38

A taxi charges ₹50 fixed plus ₹12 per km. A ride costing ₹158 covered how many km?

  • A8
  • B9✓
  • C10
  • D12

Working

✓

50 + 12k = 158 → 12k = 108 → k = 9.

Q44

In the pattern 5, 8, 11, 14, … (each term is 3 more than the one before), which term equals 47?

  • Athe 16th
  • Bthe 14th
  • Cthe 47th
  • Dthe 15th✓

Working

✓

The terms go up by 3 from a first term of 5, so the nth term is 5 + 3(n − 1) = 3n + 2. Set 3n + 2 = 47 → 3n = 45 → n = 15. So 47 is the 15th term. Check: 3·15 + 2 = 47. ✓ (Picking 47 itself is the "the value IS the position" trap.)

Age & Number Problems

Key rule. Let x = today's value. Future = x + years; past = x − years. Set up the relation from the verbal condition.
Q3

If 4x − 9 = 2x + 7, then the value of 3x + 1 is:

  • A25✓
  • B24
  • C17
  • D9

Working

✓

4x − 9 = 2x + 7 → 4x − 2x = 7 + 9 → 2x = 16 → x = 8. Then 3x + 1 = 3·8 + 1 = 25. (Stopping at 3x = 24 gives the trap 24; using 2x + 1 gives 17.)

Q10

The sum of three consecutive integers is 72. The largest of them is:

  • A23
  • B25✓
  • C24
  • D21

Working

✓

Let the integers be n, n + 1, n + 2. Sum = 3n + 3 = 72 → 3n = 69 → n = 23. Largest = n + 2 = 25. (23 is the smallest — a common trap.)

Q11

A father is 4 times as old as his son, and the sum of their ages is 50 years. The son's age is:

  • A40
  • B12
  • C10✓
  • D8

Working

✓

Son = s, father = 4s. s + 4s = 50 → 5s = 50 → s = 10. (40 is the father's age.)

Q24

Reena is 5 years older than Sam. In 3 years the sum of their ages will be 33. Sam's present age is:

  • A11✓
  • B8
  • C16
  • D14

Working

✓

Now: Sam = s, Reena = s + 5. In 3 years: (s + 3) + (s + 5 + 3) = 33 → 2s + 11 = 33 → 2s = 22 → s = 11. Check: in 3 years 14 + 19 = 33. ✓

Q33

In a two-digit number the units digit is 3 more than the tens digit, and the sum of the two digits is 11. The number is:

  • A47✓
  • B74
  • C38
  • D29

Working

✓

tens = t, units = t + 3. Digit-sum: t + (t + 3) = 11 → 2t + 3 = 11 → 2t = 8 → t = 4, units = 7. The number is 47. Check: 4 + 7 = 11 and 7 = 4 + 3. ✓ (74 reverses the digits; 38 and 29 also sum to 11 but their units digit is not 3 more than the tens digit.)

Q42

The sum of two numbers is 30, and one is 6 more than the other. The larger number is:

  • A18✓
  • B12
  • C24
  • D15

Working

✓

Numbers x and x + 6. x + (x + 6) = 30 → 2x = 24 → x = 12. Larger = x + 6 = 18.

Q46

A two-digit number has digit-sum 9, and its tens digit is twice its units digit. The number is:

  • A36
  • B72
  • C81
  • D63✓

Working

✓

units = u, tens = 2u. Digit-sum 2u + u = 9 → 3u = 9 → u = 3, tens = 6 → the number is 63. Check: 6 + 3 = 9 and 6 = 2·3. ✓

Q55

The sum of four consecutive integers is 90. The smallest of them is:

n + (n+1) + (n+2) + (n+3) = 90 → 4n + 6 = 90 → 4n = 84 → n = 21. Check: 21 + 22 + 23 + 24 = 90. ✓

Q57

A mother is 26 years older than her daughter. In 6 years she will be 3 times as old as her daughter. The daughter's present age is:

  • A7✓

Money & Coins

Key rule. Total value = (count) × (denomination), summed across coin types. Write one equation per stated condition.
Q12

Four pencils and a ₹10 sharpener together cost ₹38. The cost of one pencil (in ₹) is:

  • A7✓
  • B9
  • C12
  • D6

Working

✓

4x + 10 = 38 → 4x = 28 → x = 7.

Q20

A box holds twenty ₹1 and ₹2 coins worth ₹35 in all. The number of ₹2 coins is:

  • A5
  • B15✓
  • C10
  • D20

Working

✓

Let t = number of ₹2 coins; then 20 − t are ₹1 coins. 2t + 1·(20 − t) = 35 → t + 20 = 35 → t = 15. Check: 15·2 + 5·1 = 35. ✓

Q35

A family bought 5 tickets for ₹155. Adult tickets cost ₹40 and child tickets ₹25. The number of child tickets bought was:

  • A3✓
  • B2
  • C5
  • D4

Working

✓

Child tickets = c, adult = 5 − c. 40(5 − c) + 25c = 155 → 200 − 40c + 25c = 155 → 200 − 15c = 155 → 15c = 45 → c = 3. Check: 3 child (₹75) + 2 adult (₹80) = ₹155. ✓

Q58

A shopkeeper sold 30 fruits for ₹201, charging ₹8 per apple and ₹5 per orange. The number of apples sold was:

  • A13
  • B17✓
  • C15
  • D20

Working

✓

apples = a, oranges = 30 − a. 8a + 5(30 − a) = 201 → 8a + 150 − 5a = 201 → 3a = 51 → a = 17. Check: 17·8 + 13·5 = 136 + 65 = 201. ✓

Geometry & Sharing

Key rule. For perimeter: 2(l + b) = P. For angles in a triangle: sum to 180°. For sharing: write each share as a multiple of one variable, then equate to the total.
Q13

The length of a rectangle is 5 cm more than its breadth, and its perimeter is 50 cm. The breadth (in cm) is:

  • A10✓
  • B15
  • C20
  • D7.5

Working

✓

breadth = b, length = b + 5. Perimeter 2(b + 5 + b) = 50 → 2(2b + 5) = 50 → 2b + 5 = 25 → 2b = 20 → b = 10. (Length is 15.)

Q19

The length of a rectangle is twice its breadth, and its perimeter is 54 cm. The length (in cm) is:

  • A18✓
  • B9
  • C27
  • D12

Working

✓

breadth = b, length = 2b. Perimeter = 2(2b + b) = 6b = 54 → b = 9. Length = 2b = 18. Check: 2(18 + 9) = 54. ✓ (9 is the breadth — the classic "answered the wrong unknown" trap.)

Q28

₹120 is shared between A and B so that A gets twice as much as B. B's share (in ₹) is:

  • A80
  • B60
  • C40✓
  • D30

Working

✓

B = b, A = 2b. 2b + b = 120 → 3b = 120 → b = 40. (A gets 80.)

Q30

Two angles of a triangle are equal, and the third is 30° more than each of them. Each equal angle measures:

  • A30°
  • B80°
  • C40°
  • D50°✓

Working

✓

x + x + (x + 30) = 180 → 3x + 30 = 180 → 3x = 150 → x = 50. Each equal angle = 50° (third = 80°). ✓

Q39

₹90 is divided among three friends so that the second gets twice the first and the third gets three times the first. The third friend's share (in ₹) is:

  • A45✓
  • B15
  • C30
  • D90

Working

✓

first = a, second = 2a, third = 3a. a + 2a + 3a = 90 → 6a = 90 → a = 15. Third = 3a = 45. Check: 15 + 30 + 45 = 90. ✓ (15 is the first friend's share, 30 the second — both are traps.)

Q43

An isosceles triangle has two equal sides of length x and a base of length (x − 2). Its perimeter is 25. Then x equals:

  • A7
  • B11
  • C9✓
  • D8

Working

✓

x + x + (x − 2) = 25 → 3x − 2 = 25 → 3x = 27 → x = 9. Check: 9 + 9 + 7 = 25. ✓

Q49

₹600 is shared among A, B and C so that B gets ₹50 more than A and C gets ₹50 more than B. A's share (in ₹) is:

  • A200
  • B250
  • C150✓
  • D100

Working

✓

A = a, B = a + 50, C = a + 100. Sum = 3a + 150 = 600 → 3a = 450 → a = 150. Check: 150 + 200 + 250 = 600. ✓

Q52

The angles of a triangle are in the ratio 1 : 2 : 3. The largest angle is:

  • A30°
  • B60°
  • C120°
  • D90°✓

Working

✓

Angles x, 2x, 3x. x + 2x + 3x = 180 → 6x = 180 → x = 30. Largest = 3x = 90°.
