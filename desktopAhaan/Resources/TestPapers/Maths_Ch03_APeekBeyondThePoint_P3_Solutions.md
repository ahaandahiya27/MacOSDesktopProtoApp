## Worked Solutions

**1. (B)** Pole = 4 + 0/10 + 9/100 = 4.09. Rod = 4 + 9/10 + 0/100 = 4.90. Lining up the points: 4.90 − 4.09 = 0.81. Saying 0 treats 4.09 and 4.90 as equal because both 'have a 9' — but the 9 sits in different places. 0.081 misplaces the point. 0.9 just copies the rod's tenths digit. The gap is 0.81.

**2. (C)** Compare from the left. Tenths first: 0.07 and 0.077 have 0 tenths; 0.7 and 0.707 have 7 tenths, so the two starting 0.0 are smallest. Between 0.07 (=0.070) and 0.077, hundredths tie at 7, thousandths 0 vs 7, so 0.07 < 0.077. Between 0.7 (=0.700) and 0.707, thousandths 0 vs 7, so 0.7 < 0.707. Order: 0.07 < 0.077 < 0.7 < 0.707. The option ranking 0.707 above 0.7 then placing 0.7 last treats 'more digits' as bigger; the descending options are reversed.

**3. (D)** 0.36 = 36/100. Divide top and bottom by 4: 36÷4 = 9, 100÷4 = 25, so 9/25. Check: 9/25 = 36/100 = 0.36. ✓ 36/10 = 3.6 (point misplaced). 18/100 = 0.18 (only halved, and not 0.36). 1/36 is unrelated.

**4. (A)** 'Four thousandths' = 4/1000, which fills the third place after the point and needs zeros in the tenths and hundredths places: 9.004. 9.4 is four tenths, 9.04 is four hundredths, 9.400 is also four tenths (the trailing zeros add nothing). Only 9.004 places the 4 in the thousandths slot.

**5. (A)** Total cut = 0.65 + 1.4 + 0.8. Line up the points: 0.65 + 1.40 = 2.05; 2.05 + 0.80 = 2.85 m. Remaining = 3.00 − 2.85 = 0.15 m. 0.85 m comes from cutting only the wrong pieces; 1.15 m forgets one piece; 0.25 m mislines the points. Answer: 0.15 m.

**6. (C)** The 4 is in the tenths place: value 0.4. The 6 is in the thousandths place: value 0.006. Difference = 0.400 − 0.006 = 0.394. The trap 0.402 subtracts wrongly (0.4 − 0.006 ≠ 0.402); 0.396 mishandles the borrow; 0.2 ignores the actual digits. Answer: 0.394.

**7. (B)** Distances from 2.5 (=2.50): 2.53 is 0.03 away; 2.59 is 0.09 away; 2.4 is 0.10 away; 2.6 is 0.10 away. The smallest gap is 0.03, so 2.53 is nearest. Picking 2.59 just because it 'looks close to 2.5' ignores the actual distance; 2.4 and 2.6 are each a full tenth away.

**8. (D)** Half of ₹48.50 = 48.50 ÷ 2. Half of 48 is 24; half of 0.50 is 0.25. So ₹24.25. ₹24.50 wrongly halves only the rupees and keeps the 50 paise; ₹24.05 misplaces the point; ₹97.00 doubles instead of halving. Answer: ₹24.25.

**9. (A)** Write to three places: 0.440, 0.404, 0.400, 0.044. Largest first by place value: 0.440 > 0.404 > 0.400 > 0.044, i.e. 0.44, 0.404, 0.4, 0.044. Ranking 0.404 first treats more digits as bigger; the ascending option reverses the order; placing 0.4 ahead of 0.404 ignores the thousandths.

**10. (A)** Rounding to the nearest tenth, look at the hundredths digit: it is 6, so round the tenths up. The tenths digit is 9, so 7.9 becomes 8.0 (the 9 rolls over). 7.9 rounds down wrongly; 8.1 over-rounds; 7.96 is not rounded at all. Answer: 8.0 kg.

**11. (B)** In 36.582: tenths digit = 5, hundredths = 8, thousandths = 2. Tenths + thousandths = 5 + 2 = 7. 13 mistakenly adds the hundredths (5+8); 10 uses the wrong pair (8+2); 5 reads only one digit. Answer: 7.

**12. (D)** Poured = 0.35 + 0.4 + 0.75. Line up points: 0.35 + 0.40 = 0.75; 0.75 + 0.75 = 1.50 L. Left = 2.00 − 1.50 = 0.50 L = 0.5 L. 0.45 L and 0.55 L come from mis-aligning the points; 1.5 L is the amount poured, not what is left. Answer: 0.5 L.

**13. (D)** List: 1st 0.2; 2nd 0.2+0.15 = 0.35; 3rd 0.35+0.15 = 0.50; 4th 0.50+0.15 = 0.65; 5th 0.65+0.15 = 0.80. So the fifth term is 0.8. 0.65 is the fourth term; 0.95 adds one step too many; 0.75 mis-adds. Answer: 0.8.

**14. (B)** 0.125 = 125/1000. Divide top and bottom by 125: 125÷125 = 1, 1000÷125 = 8, so 1/8. Check: 1/8 = 0.125. ✓ 1/4 = 0.25 (too big); 125/100 = 1.25 (point misplaced); 1/125 = 0.008. Answer: 1/8.

**15. (C)** Spent = 23.75 + 18.50 + 9.90. Add: 23.75 + 18.50 = 42.25; 42.25 + 9.90 = 52.15. Change = 100.00 − 52.15 = 47.85. ₹52.15 is the amount spent, not the change; ₹47.75 and ₹48.15 come from a borrowing slip. Answer: ₹47.85.

**16. (D)** The midpoint = (1.6 + 1.7) ÷ 2 = 3.3 ÷ 2 = 1.65. Half of a tenth is five hundredths, so 1.6 + 0.05 = 1.65. 1.605 places the 5 in the thousandths, far too small a step; 1.67 is past the middle; 1.7 is the endpoint. Answer: 1.65.

**17. (C)** Midpoint = (0.8 + 0.9) ÷ 2 = 1.7 ÷ 2 = 0.85. Equivalently 0.8 + half of 0.1 = 0.8 + 0.05 = 0.85. 0.89 sits near the right end; 0.805 adds only five thousandths; 0.18 is unrelated. Answer: 0.85.

**18. (D)** Forty-five thousandths = 45/1000, which occupies the hundredths and thousandths places, leaving a 0 in the tenths: 3.045. 3.45 reads it as forty-five hundredths; 3.450 also reads forty-five hundredths (trailing zero is harmless); 3.0045 makes it ten-thousandths. Answer: 3.045.

**19. (C)** 0.4 = 0.40, and 0.40 > 0.39 (40 hundredths beat 39 hundredths). True. 0.09 > 0.1 is false (0.09 < 0.10). 0.5 < 0.45 is the classic trap and false (0.50 > 0.45). 0.6 = 0.60 + 0.006 is false (the right side is 0.606). Answer: 0.4 > 0.39.

**20. (B)** Each book = 5.2 ÷ 4. 5.2 = 52 tenths; 52 ÷ 4 = 13 tenths = 1.3 kg. Check: 1.3 × 4 = 5.2. ✓ 1.05 kg multiplies to 4.2, not 5.2; 1.5 kg gives 6.0; 20.8 kg multiplies instead of divides. Answer: 1.3 kg.

**21. (C)** Work left to right, lining up points. 5.00 − 1.45 = 3.55; then 3.55 − 0.80 = 2.75. 2.65 and 2.85 come from a borrowing error; 3.75 subtracts only the first number. Answer: 2.75.

**22. (D)** 7/8: since 1000 ÷ 8 = 125, multiply 7/8 by 125/125 to get 875/1000 = 0.875. Check: 0.875 × 8 = 7.0. ✓ 0.78 reads the digits 7 and 8 straight off; 0.87 swaps the value; 0.125 is 1/8, not 7/8. Answer: 0.875.

**23. (B)** 4.7 = 4 wholes and 7 tenths. Each whole is 10 tenths, so 4 wholes = 40 tenths, plus 7 tenths = 47 tenths. Check: 47 tenths = 47/10 = 4.7. ✓ 7 counts only the digit after the point; 470 counts hundredths; 4.7 is the number itself. Answer: 47.

**24. (D)** Two decimal places means look at the third decimal digit, which is 7 (≥5), so round the hundredths up: 102.34 becomes 102.35. ₹102.34 rounds down wrongly; ₹102.3 and ₹102.4 round to one place, not two. Answer: ₹102.35.

**25. (B)** Needed = 5.00 − 2.85. Borrow: 5.00 − 2.85 = 2.15. Check: 2.85 + 2.15 = 5.00. ✓ 3.15 over-counts; 2.25 mishandles the borrow; 2.85 just repeats the start. Answer: 2.15.

**26. (C)** Compare 0.409, 0.041, 0.0999, 0.399. Tenths digit decides first: 0.409 has 4, 0.399 has 3, while 0.041 and 0.0999 have 0. So the winner is between 0.409 and 0.399; tenths 4 > 3, so 0.409 is largest. 0.041 and 0.0999 have 0 tenths and are far smaller; 0.399 'looks big' from its 9s but its tenths digit 3 loses to 4. Answer: 0.409.

**27. (B)** Total cost = 6.50 + 3.75 = 10.25. Change = 20.00 − 10.25 = 9.75. ₹10.25 is the amount spent, not the change; ₹9.25 and ₹10.75 come from borrowing slips. Answer: ₹9.75.

**28. (B)** Pieces = 4.2 ÷ 0.6 = 42 ÷ 6 = 7 (since both ×10). Check: 0.6 × 7 = 4.2. ✓ 6 gives 3.6 m; 8 gives 4.8 m; 0.7 confuses the answer with a length. Answer: 7.

**29. (A)** Adding one thousandth: 3.999 + 0.001 = 4.000 (the 9s roll over into a new whole). Check: 3.999 + 0.001 = 4.000. ✓ 3.9991 adds a ten-thousandth; 3.1000 changes the wrong digit; 4.999 adds a whole. Answer: 4.000.

**30. (A)** Order to three places: 0.880, 0.808, 0.800, 0.088. Largest = 0.88, smallest = 0.088. Difference = 0.880 − 0.088 = 0.792. 0.72 mishandles the borrow; 0.8 just copies a value; 0.088 is the smallest number, not the gap. Answer: 0.792.

**31. (C)** Align points: 2.45 − 1.80 = 0.65 m. 0.37 m comes from lining up the right-hand ends (2.45 − 1.8 read as 2.45 − 0.18 style error); 1.27 m and 0.55 m are borrowing slips. Check: 1.80 + 0.65 = 2.45. ✓ Answer: 0.65 m.

**32. (A)** 3/4 = 0.75, so 2 3/4 = 2 + 0.75 = 2.75. Check: 2.75 = 2 + 75/100 = 2 + 3/4. ✓ 2.34 and 2.43 just stick the digits 3 and 4 after the point; 2.075 treats 3/4 as thousandths. Answer: 2.75.

**33. (C)** Left to right, points aligned: 6.50 − 2.35 = 4.15; then 4.15 + 0.85 = 5.00 = 5.0. 4.0 and 5.7 come from misaligned points; 3.3 subtracts both instead of subtract-then-add. Answer: 5.0.

**34. (C)** 2.48 → nearest tenth: hundredths digit is 8 (≥5), round up, 2.4 becomes 2.5. ✓ '2.48 to nearest whole is 3' is false (it rounds to 2). '0.96 to nearest tenth is 0.9' is false (6 rounds up to 1.0). '7.5 to nearest whole is 7' is false (5 rounds up to 8). Answer: 2.48 → 2.5.

**35. (A)** Place value 8/1000 (thousandths) is the digit 8; place value 6/10 (tenths) is the digit 6. 8 + 6 = 14. 11 wrongly picks the hundredths 3 (3+8); 9 picks 3+6; 8 reads only one digit. Answer: 14.

**36. (B)** 3.50 + 1.25 = 4.75; then 4.75 − 0.90 = 3.85 L. 4.75 L forgets the removal; 3.15 L and 2.65 L come from a misaligned subtraction. Answer: 3.85 L.

**37. (B)** 1.2 = 120/100, because 1 whole = 100 hundredths and 0.2 = 20 hundredths; 100 + 20 = 120. Check: 120/100 = 1.20 = 1.2. ✓ 12 counts tenths; 1200 counts thousandths; 20 counts only the fractional part. Answer: 120.

**38. (C)** 3/20 = 15/100 (multiply top and bottom by 5), and 15/100 = 0.15. Check: 0.15 × 20 = 3. ✓ 0.32 reads the digits 3 and 2; 0.015 misplaces the point; 0.65 is unrelated. Answer: 0.15.

**39. (D)** Between 5.3 (=5.30) and 5.4 (=5.40) lie the hundredths 5.31 through 5.39. 5.36 is one of these. ✓ 5.4 is the endpoint, not between; 5.03 is far below; 5.43 is above 5.4. Answer: 5.36.

**41. (C)** 6 hundredths = 0.06. True = 1.40 − 0.06 = 1.34 kg. 1.46 kg adds instead of subtracts; 0.8 kg subtracts 0.6 (six tenths) wrongly; 1.394 kg subtracts six thousandths. Answer: 1.34 kg.

**48. (A)** 95.60 + 4.87 = 100.47; then 100.47 − 30.45 = 70.02. 69.02 and 70.22 come from carry/borrow slips; 60.02 subtracts wrongly. Answer: 70.02.
