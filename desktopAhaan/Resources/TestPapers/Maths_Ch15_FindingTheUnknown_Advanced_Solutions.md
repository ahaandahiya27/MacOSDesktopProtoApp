# Mathematics — Chapter 15: Finding the Unknown · Paper 2 (Advanced) Solutions

**1. (C)** Expand: 3x − 12 + 5 = 2x + 2 − 4. Combine: 3x − 7 = 2x − 2. Subtract 2x: x − 7 = −2. Add 7: x = 5. Quick check: LHS = 3·5 − 7 = 8; RHS = 2·5 − 2 = 8. ✓

**2. (B)** Multiply both sides by 12 to clear denominators: 4(x + 2) − 3(x − 1) = 24. Expand: 4x + 8 − 3x + 3 = 24. Simplify: x + 11 = 24. So x = 13. Always clear the denominator FIRST when you have unlike fractions.

**3. (C)** Expand both brackets: 8x − 12 − 7 = 3x + 3 + 8 → 8x − 19 = 3x + 11. Subtract 3x: 5x − 19 = 11. Add 19: 5x = 30. So x = 6.

**4. (D)** Two digits a, b with a + b = 9 and a × b = 18. They are roots of t² − 9t + 18 = 0, which factors as (t − 6)(t − 3) = 0. So the digits are 3 and 6 — giving the two-digit number 36 or 63.

**5. (D)** Three consecutive even integers: let them be n − 2, n, n + 2. Their sum is 3n = 78, so the middle integer n = 26. The other two are 24 and 28.

**6. (D)** Multiply both sides by 10 to clear decimals: 4x + 16 = 2x + 30. Subtract 2x: 2x + 16 = 30. So 2x = 14 and x = 7.

**7. (C)** Equal side = x, base = x − 6. Perimeter: 2x + (x − 6) = 36 → 3x − 6 = 36 → 3x = 42 → x = 14. Equal sides each measure 14 cm; the base is 8 cm. Sanity: 14 + 14 + 8 = 36 ✓.

**8. (D)** Multiply by LCM(3, 5) = 15: 5(x − 1) + 3(x + 1) = 30. Expand: 5x − 5 + 3x + 3 = 30 → 8x − 2 = 30 → 8x = 32 → x = 4.

**9. (A)** Half-distance trick: total 240 km, so each half is 120 km. First half time = 120/40 = 3 h. Second half time = 120/60 = 2 h. Total = 5 h. (Note: average speed is harmonic mean = 48 km/h, NOT the arithmetic mean 50.)

**10. (D)** Let the three numbers be 2k, 3k, 5k. Sum: 10k = 90 → k = 9. Largest = 5k = 45.

**11. (B)** Multiply by 3 to clear the denominator: 6x + (x − 1) = 27. Combine: 7x − 1 = 27 → 7x = 28 → x = 4.

**12. (C)** Let son's age = S, father's = 3S now. In 12 years: father = 3S + 12, son = S + 12. Setup: 3S + 12 = 2(S + 12) → 3S + 12 = 2S + 24 → S = 12 years.

**13. (B)** Angles sum to 180°: (3x − 10) + (2x + 5) + (x + 5) = 180. Combine: 6x = 180 → x = 30. Angles: 80°, 65°, 35°. Largest = 80°.

**14. (C)** Let f = ₹5 coins, t = ₹2 coins. f + t = 28 and 5f + 2t = 86. From first: t = 28 − f. Sub: 5f + 56 − 2f = 86 → 3f = 30 → f = 10.

**15. (A)** Work the brackets inside-out: 4 − [3 − (2x − 1)] = 4 − [3 − 2x + 1] = 4 − [4 − 2x] = 4 − 4 + 2x = 2x. So 2x = 6 → x = 3. Sign care matters here.

**16. (B)** Set up two equations from "5 years ago" and "5 years from now". Let Sam's current age = S, Rita's = R. Then R − 5 = 4(S − 5) and R + 5 = 2(S + 5). From the first: R = 4S − 15. Sub into the second: 4S − 15 + 5 = 2S + 10 → 4S − 10 = 2S + 10 → 2S = 20 → S = 10.

**17. (A)** Original: length L, breadth B, with L = B + 4. New length = 3L = 3B + 12; new breadth = 2B. New perimeter = 2(3B + 12 + 2B) = 10B + 24 = 84. So 10B = 60 → B = 6 cm.

**18. (C)** 3 notebooks at ₹x each + 2 pens at ₹(x + 12) each = ₹114. So 3x + 2(x + 12) = 114 → 5x + 24 = 114 → 5x = 90 → x = 18.

**19. (D)** First solve 7x − 4 = 5x + 6: subtract 5x → 2x − 4 = 6 → x = 5. Now plug into 2x² + 1: 2·25 + 1 = 51.

**20. (B)** Round trip is 600 km total. First leg time = 300/50 = 6 h; return time = 300/75 = 4 h. Total time = 10 h. Average speed = 600/10 = 60 km/h. Not the arithmetic mean of 62.5 — same trap as Q9.

**21. (C)** Cross-multiply: 3(x − 1) = 2(x + 1) → 3x − 3 = 2x + 2 → x = 5. Check: (5 − 1)/(5 + 1) = 4/6 = 2/3 ✓.

**22. (B)** Three consecutive odd integers, sum 75 → middle = 25. Smallest = 25 − 2 = 23. Largest = 27. Sanity: 23 + 25 + 27 = 75 ✓.

**23. (D)** Let man's age = x, son's = x/3. In 20 years: man = x + 20, son = x/3 + 20. Setup: x + 20 = 2(x/3 + 20). Expand: x + 20 = 2x/3 + 40. Move: x − 2x/3 = 20 → x/3 = 20 → x = 60.

**24. (D)** Multiply by 6 to clear both denominators: 2(2x − 3) = 3(x + 1) → 4x − 6 = 3x + 3 → x = 9.

**25. (C)** Start: 60 L mixture, 3:1 milk:water → 45 L milk, 15 L water. Adding only water keeps milk = 45 L. New target ratio 3:2 means milk/water = 3/2 → 45/(15 + w) = 3/2. Cross-multiply: 90 = 3(15 + w) → 90 = 45 + 3w → 3w = 45 → w = 15 L.

**26. (D)** Pattern: 5, 9, 13, … increments of 4. So sticks for n hexagons = 4n + 1. At n = 25: 4·25 + 1 = 101. Common error is to forget the +1.

**27. (A)** Let the first person's share = a. Then second = a + 20, third = 2a. Sum = a + (a + 20) + 2a = 4a + 20 = 240 → 4a = 220 → a = 55. Third's share = 2·55 = ₹110.

**28. (D)** Cross-multiply: 8 = 3(x − 2) → 8 = 3x − 6 → 3x = 14 → x = 14/3. Don't shortcut to "x − 2 = 8/3 → x = 8/3 + 2" — same answer, written 14/3 properly.

**29. (C)** Two equations: 4p + 6q = 66 and 3p + 4q = 47. Multiply the first by 3: 12p + 18q = 198. Multiply the second by 4: 12p + 16q = 188. Subtract: 2q = 10 → q = 5 (pencil). Sub back into 3p + 4·5 = 47 → 3p = 27 → p = ₹9.

**30. (C)** Let grandson = g, grandfather = 5g. Sum: 6g = 72 → g = 12 years.

**31. (A)** Distribute the −2: 6 − 6 + 2x = 4x − 8 → 2x = 4x − 8. Subtract 4x: −2x = −8 → x = 4.

**32. (C)** Let tens = t, units = u. The number is 10t + u. Conditions: 10t + u = 4(t + u) and t = u − 3. From first: 10t + u = 4t + 4u → 6t = 3u → u = 2t. Combined with u = t + 3: 2t = t + 3 → t = 3 → u = 6. Number = 36.

**33. (D)** Quadrilateral angles sum to 360°. Ratio 2:3:4:6 means 15 equal parts (2+3+4+6 = 15). Smallest = (2/15)·360 = 48°.

**34. (C)** Combine like terms: 4x + (2 + 4 + 6) = 60 → 4x + 12 = 60 → 4x = 48 → x = 12. The integers are 12, 14, 16, 18 — sum 60 ✓.

**35. (B)** Two equations: 5a + 3b = 490 and 2a + 4b = 280 (a = apple ₹/kg, b = banana ₹/kg). Multiply first by 4: 20a + 12b = 1960. Multiply second by 3: 6a + 12b = 840. Subtract: 14a = 1120 → a = ₹80/kg.

**36. (C)** Coin counts are in ratio 3:2:1 — let basic unit = k. Counts: 3k, 2k, k. Value: 3k·1 + 2k·2 + k·5 = 3k + 4k + 5k = 12k = 72 → k = 6. Number of ₹2 coins = 2k = 12.

**37. (B)** Cross-multiply: 5(x + 1) = 2(2x − 1) → 5x + 5 = 4x − 2 → x = −7. Don't be afraid of negative answers — the equation is symmetric in algebraic structure.

**38. (B)** Let breadth = b. Length = 2b + 4. Area b(2b + 4) = 96 → 2b² + 4b − 96 = 0 → b² + 2b − 48 = 0. Factor: (b + 8)(b − 6) = 0 → b = 6 (positive root only — breadths are positive).

**39. (A)** Solve 4(x + 3) = 3(x + 7): 4x + 12 = 3x + 21 → x = 9. Then 5x − 11 = 45 − 11 = 34.

**40. (D)** Let total = m. A gets m/2; B gets m/3. C gets the rest. m/2 + m/3 + 5 = m → multiply by 6: 3m + 2m + 30 = 6m → 5m + 30 = 6m → m = 30.

**41. (C)** |x − 4| = 7 means x − 4 = 7 OR x − 4 = −7. First gives x = 11; second gives x = −3. Both are valid; the answer must be the option that lists BOTH.

**42. (A)** Let tens = t, units = u. Number = 10t + u; reversed = 10u + t. Difference: 10t + u − (10u + t) = 9t − 9u = 9(t − u) = 18 → t − u = 2. With t + u = 12: t = 7, u = 5. Number = 75.

**43. (A)** Expand both: LHS = 2x² + 2x − x − 1 = 2x² + x − 1. RHS = 2x² − 2x + x − 1 = 2x² − x − 1. Equate: x − 1 = −x − 1 → 2x = 0 → x = 0. The 2x² terms and the constants cancelled — a common trap is to forget that this LEAVES a linear equation.

**44. (B)** Interior angle 120° → exterior = 180 − 120 = 60°. Number of sides = 360°/60° = 6. So it's a regular hexagon.

**45. (B)** Downstream speed = 24/3 = 8 km/h; upstream = 24/4 = 6 km/h. Boat speed in still water = (downstream + upstream)/2 = (8 + 6)/2 = 7 km/h. (The current speed is the difference/2 = 1 km/h.)

**46. (B)** Let daughter's age = d. Mother = 3d now. 10 years ago: mom − 10 = 5(d − 10) → 3d − 10 = 5d − 50 → 2d = 40 → d = 20. Mother = 60.

**47. (C)** Multiply both sides by 4: (3x − 1) + 2(x + 1) = 5x + 3 → 3x − 1 + 2x + 2 = 5x + 3 → 5x + 1 = 5x + 3 → 1 = 3. This is a contradiction — the equation has NO solution because the variable terms cancel and leave a false statement.

**48. (A)** Same speed v in both crossings: (200 + x)/15 = (350 + x)/22.5. Cross-multiply: 22.5(200 + x) = 15(350 + x) → 4500 + 22.5x = 5250 + 15x → 7.5x = 750 → x = 100 m.

**49. (A)** "Four-fifths exceeds three-fourths by 1": 4n/5 − 3n/4 = 1. LCD 20: 16n/20 − 15n/20 = n/20 = 1 → n = 20. Sanity: 4·20/5 = 16, 3·20/4 = 15, difference = 1 ✓.

**50. (A)** Let boys = b, girls = b + 4. Together: 2b + 4 = 20 → b = 8, girls = 12.

**51. (A)** Let c = correct, w = wrong. c + w = 30 and 4c − w = 80. Add the two: 5c = 110 → c = 22. So 22 correct, 8 wrong.

**52. (A)** Expand carefully: 7 − 6x − 15 + 4x − 4 = 0 → (−6x + 4x) + (7 − 15 − 4) = 0 → −2x − 12 = 0 → x = −6. The 7 − 15 − 4 = −12 is where the sign trap usually bites.

**53. (B)** Let numerator = n, denominator = n + 3. New fraction: (n − 2)/(n + 4) = 1/3 → 3(n − 2) = n + 4 → 3n − 6 = n + 4 → 2n = 10 → n = 5. Original fraction = 5/8.

**54. (A)** Father = son + 28. In 6 years: father + 6 = 3(son + 6) − 4 → (son + 28) + 6 = 3(son + 6) − 4 → son + 34 = 3·son + 14 → 2·son = 20 → son = 10. Father = 38.

**55. (C)** Multiply by LCM(4, 6, 12) = 12: 3x + 2x + x = 72 → 6x = 72 → x = 12. Clearing the LCM first is faster than adding the fractions.

**56. (A)** Add the two equations: (2x − y) + (x + y) = 7 + 5 → 3x = 12 → x = 4. (Then y = 1, but the question only asks for x.)

**57. (C)** Original speed = 480/8 = 60 km/h. New speed = 80 km/h. New time = 480/80 = 6 h. Saved time = 8 − 6 = 2 h.

**58. (B)** Each exterior angle in a regular polygon = 360°/n. So 30 = 360/n → n = 12. A regular dodecagon.

**59. (A)** Let the number = n. Equation: n + 2/n = 9/2. Multiply by 2n: 2n² + 4 = 9n → 2n² − 9n + 4 = 0. Solve via factoring: (2n − 1)(n − 4) = 0 → n = 1/2 or n = 4. The condition n > 1 picks n = 4.

**60. (D)** Each of the 3 siblings ages 6 years in the next 6 years, adding 18 to their combined age. Future sum = current sum + 18 = 60, so current sum = 42.
