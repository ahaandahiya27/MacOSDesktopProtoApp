**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. Reason from cause to effect — what turns a kingdom into an empire, the six features that hold one together, and how Magadha grew into the Maurya empire. Watch the traps: an *emperor* rules over ordinary kings; Ashoka used *Prakrit in Brahmi* so common people could read his edicts; *Kauṭilya* (Chāṇakya) wrote the *Arthaśhāstra* and the *saptānga* theory. This paper does not repeat any question from Paper 1.
