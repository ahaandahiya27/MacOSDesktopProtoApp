Set 1 · Q1–Q10

Q1

In the "taller children in front" game, each child calls out how many TALLER children stand ahead of them in the line. Which of these numbers can the FIRST child in the line never say anything but?

  • Athe height of the tallest child
  • Bthe number of children behind them
  • Cany number from 0 upward
  • D0✓

Working

✓

The first child in the line has nobody standing ahead of them, so the number of taller children in front is exactly 0 — always. (Being the "tallest" is option-A's trap: saying 0 only means no one taller is ahead, which is automatic for the front position regardless of height.)

Q2

A line of 5 children plays the "taller in front" game. Which of these called-out sequences (front to back) is IMPOSSIBLE?

  • A0, 1, 2, 3, 4
  • B0, 1, 2, 3, 5✓
  • C0, 0, 0, 0, 0
  • D0, 1, 0, 2, 1

Working

✓

A child can name at most as many taller children as there are people ahead. In a line of 5, the back child has only 4 ahead, so the largest possible call is 4. "0, 1, 2, 3, 5" ends in 5 — impossible. The others obey the bound (every value ≤ number ahead).

Q3

Five number cards, each showing an odd number, are laid down. Which total can they NEVER add up to?

  • A30✓
  • B41
  • C25
  • D15

Working

✓

Five odd numbers always add to an ODD total (odd count of odds → odd). 30 is even, so it can never be the sum. 41, 25 and 15 are all odd and are achievable. So the impossible total is 30.

Q4

What is the parity of the sum 7 + 9 + 11 + 13 + 15 + 17 (six odd numbers)?

  • Ait depends on the actual values
  • Bodd
  • Ceven✓
  • Dneither even nor odd

Working

✓

Six odd numbers is an EVEN count of odds, so the sum is even. (Actual sum 7+9+11+13+15+17 = 72, even.) Parity is fixed by the count, not the values — so "it depends" is the trap.

Q5

The Virahāṅka–Fibonacci sequence begins 1, 2, 3, 5, 8, 13, 21, … . What is the very next term after 21?

  • A33
  • B42
  • C34✓
  • D29

Working

✓

Each term is the sum of the two before: after …, 13, 21 the next is 13 + 21 = 34. (Adding a constant like +12 to get 33 is the "fixed gap" misconception.)

Q6

In a cryptarithm, T + T + T = UT, where UT is a two-digit number whose units digit equals T. What digit is T?

  • A9
  • B0
  • C2
  • D5✓

Working

✓

T + T + T = 3T must be a two-digit number ending in T. Try T = 5: 3×5 = 15, ends in 5 = T, with U = 1. ✓ T = 2 gives 6 (one digit, no U); larger T overshoots the ending-in-T condition. So T = 5.

Q7

A 3×3 grid is filled with the digits 1 to 9, each used exactly once. What is the SMALLEST sum any single row can possibly have?

  • A24
  • B6✓
  • C1
  • D15

Working

✓

The smallest a row can be is the three smallest distinct digits: 1 + 2 + 3 = 6. (1 would need a single cell, not a row sum — that's the trap.)

Q8

In a 3×3 grid filled with 1–9 (no repeats), the three row sums are 13, 17 and one unknown value. What is the third row sum?

  • A15✓
  • B16
  • C30
  • D14

Working

✓

The three row sums always total 1+2+…+9 = 45 (the 45-invariant). So the third = 45 − 13 − 17 = 15.

Q9

Ahaan claims he wrote down 7 whole numbers that add to an EVEN total, and that exactly 3 of them are odd. Is this possible?

  • AYes, if the even numbers are large enough
  • BNo — an odd count of odd numbers makes the total odd✓
  • CYes, if one of the numbers is zero
  • DOnly if all 7 numbers are odd

Working

✓

Exactly 3 odd numbers is an ODD count of odds, which forces an ODD total. An odd total can never be even, so it is impossible — no matter how large the even numbers are. Answer: No.

Q10

How many different rhythms of exactly 4 beats can be made using short (1-beat) and long (2-beat) syllables?

  • A4
  • B6
  • C8
  • D5✓

Working

✓

Rhythm counts follow 1, 2, 3, 5, … (each the sum of the previous two). For 1 beat: 1 way; 2 beats: 2; 3 beats: 3; 4 beats: 3 + 2 = 5. So 5 rhythms.

Q11

The sum of three distinct digits chosen from 1–9 is 24. Which three digits must they be?

  • A7, 8, 9✓
  • B8, 9, 6
  • C9, 9, 6
  • D6, 8, 7

Working

✓

Three distinct digits from 1–9 summing to 24 must be the three largest, 7 + 8 + 9 = 24 (the maximum). 8+9+6 = 23 and 6+8+7 = 21 fall short; 9,9,6 repeats a digit. So 7, 8, 9.

Q12

Which of the following sums is ODD?

  • Athe sum of four odd numbers
  • Bthe sum of the first 10 even numbers
  • Cthe sum of seven odd numbers✓
  • Dthe sum of three even numbers and two odd numbers

Working

✓

Parity of each: four odds → even; first 10 evens → even; three evens + two odds → even (two odds make even); seven odds → ODD (odd count of odds). So the odd one is "the sum of seven odd numbers."

Q14

A 3×3 grid is to be filled with 1–9 (no repeats). One row is required to sum to 26. Why is this impossible?

  • A26 is even and rows must be odd
  • BThe greatest possible row sum is 7 + 8 + 9 = 24✓
  • C26 is not divisible by 3
  • DOnly the middle row can reach 26

Working

✓

The largest a row of three distinct digits from 1–9 can reach is 7 + 8 + 9 = 24. Since 26 > 24, no row can sum to 26. (Divisibility by 3 is irrelevant here.)

Q15

Two odd numbers are written as 2m + 1 and 2n + 1. Their sum equals 2(m + n + 1). What does this PROVE?

  • Aodd + odd is sometimes even
  • Bthe sum depends on m and n
  • Codd + odd is always even✓
  • Dodd + odd is always odd

Working

✓

(2m+1) + (2n+1) = 2m + 2n + 2 = 2(m + n + 1), a multiple of 2 — hence even — for ALL whole m, n. This is a general proof that odd + odd is ALWAYS even (not just in examples).

Q17

Which list of numbers follows the Virahāṅka–Fibonacci RULE (each term is the sum of the previous two), starting from 4 and 7?

Q18

A child in the "taller in front" game says "3". What does this tell you for certain?

  • Athe child is the third tallest
  • Bthere are exactly 3 children behind this child
  • Cthe child is 3rd in line
  • Dexactly 3 taller children stand ahead of this child✓

Working

✓

The number a child calls is, by the rule of the game, exactly how many TALLER children stand ahead of them — here, 3. It says nothing certain about their rank, position in line, or how many are behind.

Q19

Each consecutive pair of terms in 1, 1, 2, 3, 5, 8, 13, 21, … has a ratio. As we go further along, these ratios get closer and closer to which value?

  • Aexactly 2
  • Bexactly 1.5
  • Cabout 1.618✓
  • Dabout 3.14

Working

✓

Ratios of consecutive terms (2/1, 3/2, 5/3, 8/5, 13/8, …) close in on the golden ratio φ ≈ 1.618. (Not 2, 1.5, or π ≈ 3.14.)

Q20

In the cryptarithm AB + BA = 132, where A and B are single digits, what is A + B?

  • A11
  • B12✓
  • C6
  • D13

Working

✓

AB + BA = (10A + B) + (10B + A) = 11A + 11B = 11(A + B) = 132 → A + B = 132 ÷ 11 = 12.

Q24

In the "taller children in front" game with several children, which statement is ALWAYS true?

  • Asomeone always says a number bigger than 0
  • Bthe called-out numbers are always in increasing order
  • Cthe first child always says 0✓
  • Devery child says a different number

Working

✓

The front child has no one ahead, so they always call 0 — always true. The numbers need not increase, need not all differ, and no one is forced to exceed 0 (e.g. everyone in increasing-height order calls 0).

Q25

A two-digit number is a "palindrome" if reading it left-to-right gives the same as right-to-left (like 44 or 77). How many two-digit palindromes are there?

  • A10

  • C9✓
  • D11

Working

✓

Two-digit palindromes have equal digits: 11, 22, 33, 44, 55, 66, 77, 88, 99 — that's 9. (10 wrongly counts 00; 11/18 over-count.)

Q26

Which of these statements about parity is the only one that is FALSE?

  • Aeven + even = even
  • Bodd + odd = even
  • Ceven + odd = odd
  • Dodd + odd = odd✓

Working

✓

even+even = even ✓, odd+odd = even ✓, even+odd = odd ✓ are all true. "odd + odd = odd" is FALSE (two odds give an even). So the false one is (D).

A digit T satisfies T + T = a two-digit number whose tens digit is 1. What is the smallest such T?

2T must be a two-digit number with tens digit 1, i.e. 10 ≤ 2T ≤ 19. The smallest T with 2T ≥ 10 is T = 5 (2×5 = 10). (T = 4 gives 8, only one digit.)

Q32

In a line of children playing the "taller in front" game, the last (back) child says "0". What does this mean?

  • Ano taller child stands ahead of the back child✓
  • Bthe line has only one child
  • Cthe back child is the shortest
  • Dthe back child is shorter than everyone ahead

Working

✓

Calling "0" always means no taller child stands ahead — that is its exact meaning for any position, including the back. It does NOT force the line to have one child or make that child the shortest (others ahead could be shorter).

Q33

Which of the following can be the sum of FIVE consecutive whole numbers?

  • A32
  • B36
  • C38
  • D30✓

Working

✓

Five consecutive whole numbers n, …, n+4 sum to 5n + 10 = 5(n + 2), a multiple of 5. Among the options only 30 is a multiple of 5 (30 = 4+5+6+7+8). 32, 36, 38 are impossible.

Q34

In the cryptarithm 1A + A1 = 33 (A is a single digit), what is A?

  • A1

  • C3
  • D0

Working

✓

1A + A1 = (10 + A) + (10A + 1) = 11 + 11A = 33 → 11A = 22 → A = 2. Check: 12 + 21 = 33. ✓

Q35

How many different rhythms of exactly 5 beats can be made from short (1-beat) and long (2-beat) syllables?

  • D21

Working

Rhythm counts: 1, 2, 3, 5, 8 for 1, 2, 3, 4, 5 beats. So 5 beats give 8 rhythms (5 + 3 from the recurrence). (13 is for 6 beats.)

Q36

A sum of several odd numbers turned out to be even. Which is the only possible number of odd numbers below?

  • A6✓
  • B5
  • C3
  • D1

Working

✓

A sum of odds is even only when the COUNT of odds is even. Among the options only 6 is even, so 6 odd numbers can sum to even. (5, 3, 1 are odd counts → odd total.)

Q37

The product (not sum) of two odd numbers is always:

  • Aodd✓
  • Beven
  • Ca multiple of 4
  • Dsometimes even, sometimes odd

Working

✓

Odd × odd = odd: writing them 2m+1 and 2n+1, the product is 4mn + 2m + 2n + 1 = 2(2mn + m + n) + 1, which is one more than an even number — odd. (Multiple of 4 fails, e.g. 3×5 = 15.)

In a 3×3 grid filled with 1–9, the first two columns sum to 15 and 18. What does the third column sum to?

The three column sums also total 45 (every cell counted once). So the third column = 45 − 15 − 18 = 12.

Q39

The first child in a "taller in front" line of 4 says "0". The numbers called are 0, a, b, c. What is the GREATEST value c (the back child) could possibly say?

Q40

Which number is divisible by 9?

Q42

A teacher says: "I checked that 3 + 5 = 8 is even, 7 + 9 = 16 is even, and 11 + 13 = 24 is even, so odd + odd is always even." What is the status of her reasoning?

  • BExamples can prove a statement if there are at least three

✓

Checking three examples cannot PROVE a universal claim — examples can only suggest a pattern or disprove it with a counterexample. The conclusion happens to be true (provable by 2m+1 + 2n+1 = even), but her reasoning by examples is not a proof.

Q48

Which group of three distinct digits from 1–9 has a sum that is NOT possible as a single row of a 3×3 grid of 1–9?

Q49

When a whole number N is doubled, the result always ends in an EVEN digit. Which of these can therefore NEVER be the units digit of 2N?

  • A7✓
  • B4
  • C0
  • D8

Working

✓

Q50

In the cryptarithm AA + A = BA, where A and B are single non-zero digits and the answer's units digit is A, what is A?

  • A9
  • B5
  • Cimpossible for any such A✓
  • D7

Working

✓

AA + A = 11A + A = 12A. For the answer to end in A we need 12A ≡ A (mod 10), i.e. 2A ≡ 0 (mod 10), so A = 0 or 5; A is non-zero, so A = 5 → 12×5 = 60, which ends in 0, not 5. No non-zero digit works, so it is impossible.
