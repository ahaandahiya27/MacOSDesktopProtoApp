Set 1 · Q1–Q10

Q1

A bulb in a circuit glows only when the circuit is:

  • Aopen
  • Bbroken
  • Ccomplete (closed)✓
  • Dshort

Working

✓

A bulb lights only when the circuit is a complete (closed) loop so current can flow.

Q2

In the symbol for a single cell, the longer thin line stands for the:

  • Apositive terminal✓
  • Bnegative terminal
  • Cswitch
  • Dbulb

Working

✓

In a cell's symbol the longer thin line is the positive terminal.

Q3

A battery is:

  • Aa single wire
  • Bone bulb
  • Ca type of switch
  • Dtwo or more cells joined together✓

Working

✓

A battery is two or more cells joined together.

Q4

When a switch in a circuit is open, the bulb:

  • Aglows brighter
  • Bdoes not glow✓
  • Cglows dimly
  • Dflickers

Working

✓

An open switch breaks the loop, so no current flows and the bulb does not glow.

Q5

The component used to complete or break a circuit at will is the:

  • Acell
  • Bbulb
  • Cswitch✓
  • Dwire

Working

✓

A switch is the component that completes or breaks the circuit.

Q6

The shorter, thicker line in a cell's symbol marks the:

  • Apositive terminal
  • Bbulb
  • Cwire
  • Dnegative terminal✓

Working

✓

The shorter, thicker line marks the negative terminal of the cell.

Q7

Current flows through a circuit only when the path forms a:

  • Astraight line
  • Bsingle wire
  • Cdead end
  • Dclosed loop✓

Working

✓

Current flows only when the path is a closed loop.

Q8

If the filament of a bulb breaks, the bulb:

  • Aglows brighter
  • Bdoes not glow (the circuit is open)✓
  • Cchanges colour
  • Dheats the wire

Working

✓

A broken filament opens the circuit, so the bulb does not glow.

Q9

Two or more cells joined together to give more energy make a:

  • Aswitch
  • Bfuse
  • Cbattery✓
  • Dresistor

Working

✓

Cells joined together form a battery.

Q10

The symbol of an electric bulb is:

  • Aa circle with a cross inside✓
  • Btwo parallel lines
  • Ca zig-zag line
  • Dan arrow

Working

✓

The bulb symbol is a circle with a cross inside.
