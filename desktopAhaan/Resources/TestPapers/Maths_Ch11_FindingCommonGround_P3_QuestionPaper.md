**Marking scheme:** **+4** for each correct answer · **−1** for each wrong answer · **0** if unattempted.

**Instructions:** Each question has four options (A), (B), (C), (D); exactly one is correct. HCF can never exceed the smaller number and uses the LOWEST powers of common primes, while LCM uses the HIGHEST powers of all primes and equals the product only for co-prime pairs. Do not write on this paper — mark answers on your answer sheet.
