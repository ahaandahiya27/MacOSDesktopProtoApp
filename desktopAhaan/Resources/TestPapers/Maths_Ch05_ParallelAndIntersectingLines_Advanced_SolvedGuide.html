Set 1 · Q1–Q10

Q1

The complement of 35° is:

  • A65°
  • B55°✓
  • C145°
  • D35°

Working

✓

Complement means "adds to 90°": 90° − 35° = 55°.

Q2

The supplement of 110° is:

  • A110°
  • B90°
  • C20°
  • D70°✓

Working

✓

Supplement means "adds to 180°": 180° − 110° = 70°.

Q3

Two complementary angles are such that one is four times the other. The larger angle is:

  • A72°✓
  • B18°
  • C144°
  • D36°

Working

✓

Let the angles be x and 4x; x + 4x = 90 → x = 18°, so the larger is 4 × 18 = 72°.

Q4

The supplement of an angle is three times the angle. The angle is:

  • A135°
  • B60°
  • C45°✓
  • D90°

Working

✓

x + 3x = 180 → 4x = 180 → x = 45°.

Q5

An angle that equals its own complement measures:

  • A90°
  • B45°✓
  • C60°
  • D30°

Working

✓

x + x = 90 → x = 45°.

Q6

An angle that equals its own supplement measures:

  • A45°
  • B180°
  • C60°
  • D90°✓

Working

✓

x + x = 180 → x = 90°.

Q7

The complement of 1° is:

  • A89°✓
  • B179°
  • C91°
  • D1°

Working

✓

90° − 1° = 89°.

Q8

Two supplementary angles are in the ratio 2 : 3. The smaller angle is:

  • A108°
  • B36°
  • C72°✓
  • D60°

Working

✓

2k + 3k = 180 → k = 36; the smaller is 2 × 36 = 72°.

Q9

For an angle of 50°, the supplement minus the complement equals:

  • A50°
  • B90°✓
  • C40°
  • D130°

Working

✓

Supplement = 130°, complement = 40°; 130° − 40° = 90°.

Q10

Q11

Two angles form a linear pair; one is 65°. The other is:

  • A115°✓
  • B25°
  • C65°
  • D295°

Working

✓

A linear pair sums to 180°: 180° − 65° = 115°.

Q12

Vertically opposite angles are always:

  • Asupplementary
  • Bcomplementary
  • Cequal✓
  • Dright angles

Working

✓

Vertically opposite angles are always equal.

Q13

Two lines cross and one of the four angles is 40°. An angle adjacent to it measures:

  • A40°
  • B140°✓
  • C50°
  • D320°

Working

✓

An adjacent angle forms a linear pair with the 40° angle: 180° − 40° = 140°.

Q14

At a point on a straight line, three angles x, 2x and 3x are formed. The value of x is:

  • A60°
  • B90°
  • C45°
  • D30°✓

Working

✓

x + 2x + 3x = 180 → 6x = 180 → x = 30°.

Q15

The two angles of a linear pair are always:

  • Asupplementary✓
  • Bequal
  • Ccomplementary
  • Dvertically opposite

Working

✓

A linear pair always adds to 180°, i.e. the angles are supplementary.

Q16

Two adjacent angles on a straight line are (2x + 10)° and (3x − 30)°. The value of x is:

  • A50
  • B30
  • C40✓
  • D20

Working

✓

(2x + 10) + (3x − 30) = 180 → 5x − 20 = 180 → 5x = 200 → x = 40.

Q17

Two lines intersect and one of the angles is 90°. The other three angles are:

  • A45° each
  • Ball 90°✓
  • C180° each
  • D30°, 60°, 90°

Working

✓

Intersecting lines with one right angle are perpendicular, so all four angles are 90°.

Q18

The angle vertically opposite to 123° measures:

  • A57°
  • B237°
  • C67°
  • D123°✓

Working

✓

Vertically opposite angles are equal, so it is 123°.

Q19

The angles around a single point add up to:

  • A360°✓
  • B180°
  • C90°
  • D270°

Working

✓

Angles around a point total 360°.

Q20

Three angles meeting at a point are 120°, 150° and x. Then x is:

  • A30°
  • B60°
  • C90°✓
  • D120°

Working

✓

120 + 150 + x = 360 → x = 90°.

  • Asupplementary
  • Bequal✓

  • Dreflex

  • Dsupplementary✓

Q23

  • B110°

  • D35°

Working

✓

  • B25°
  • C65°✓
  • D130°

Working

✓

Q26

A transversal meets one of two parallel lines at 50°. The co-interior angle at the other line is:

  • A50°
  • B40°

  • D130°✓

Q27

Two parallel lines are cut by a transversal; one angle is 3x and its co-interior angle is 2x. Then x is:

  • A36°✓
  • B60°
  • C90°
  • D18°

✓

Q28

Alternate exterior angles are equal precisely when the two lines are:

  • Aperpendicular
  • Bintersecting
  • Cparallel✓
  • Dskew

Working

✓

Alternate exterior angles are equal only when the lines are parallel.

Q29

If a transversal makes a pair of corresponding angles equal, the two lines must be:

  • Aperpendicular
  • Bparallel✓

  • Dthe same line

Working

✓

Q30

Two parallel lines cut by a transversal give alternate angles (x + 20)° and (2x − 40)°. Then x is:

Set 4 · Q31–Q40

Q31

Two parallel lines cut by a transversal give co-interior angles (x + 30)° and (x − 10)°. Then x is:

  • A80✓
  • B70
  • C90
  • D100

Working

✓

Co-interior angles are supplementary: (x + 30) + (x − 10) = 180 → 2x + 20 = 180 → x = 80.

Q32

A transversal perpendicular to one of two parallel lines meets the other line at:

  • A45°
  • B60°
  • C90°✓
  • D30°

Working

✓

A line perpendicular to one of two parallels is perpendicular to the other too — 90°.

Q33

On two parallel lines a transversal makes a 45° angle. Its corresponding angle is:

  • A135°
  • B45°✓
  • C90°
  • D55°

Working

✓

Corresponding angles on parallel lines are equal: 45°.

Q34

Two parallel lines are cut by a transversal; one interior angle is 125°. Its co-interior angle is:

  • A125°
  • B65°
  • C35°
  • D55°✓

Working

✓

Co-interior to a 125° angle: 180° − 125° = 55°.

Q35

Two lines are cut by a transversal and a pair of co-interior angles sums to 170°. The lines are:

  • Anot parallel✓
  • Bparallel
  • Cperpendicular
  • Dthe same line

Working

✓

Parallel lines force co-interior angles to total 180°; 170° ≠ 180°, so the lines are not parallel.

Q36

Lines AB and CD intersect at O with ∠AOC = 50°. The angle ∠BOD is:

  • A130°
  • B40°
  • C50°✓
  • D90°

Working

✓

∠BOD is vertically opposite ∠AOC, so it equals 50°.

Q37

For the same crossing (∠AOC = 50°), the angle ∠AOD is:

  • A50°
  • B130°✓
  • C40°
  • D90°

Working

✓

∠AOD forms a linear pair with ∠AOC: 180° − 50° = 130°.

Q38

Two complementary angles differ such that one is 12° more than the other. The larger angle is:

  • A39°
  • B78°
  • C45°
  • D51°✓

Working

✓

x + (x + 12) = 90 → 2x = 78 → x = 39, so the larger is 39 + 12 = 51°.

Q39

The bisector of an 80° angle creates two angles, each measuring:

  • A40°✓
  • B80°
  • C160°
  • D20°

Working

✓

A bisector halves the angle: 80° ÷ 2 = 40° each.

Q40

An angle whose supplement is 20° more than the angle itself measures:

  • A100°
  • B90°
  • C80°✓
  • D70°

Working

✓

x + 20 is the supplement, so x + (x + 20) = 180 → 2x = 160 → x = 80°.

Q41

Three equal angles lie along a straight line. Each measures:

  • A90°
  • B60°✓
  • C45°
  • D120°

Working

✓

3 equal angles on a line: 180° ÷ 3 = 60° each.

Q42

Two complementary angles differ by 30°. The larger is:

  • A30°
  • B45°
  • C75°
  • D60°✓

Working

✓

x + (x + 30) = 90? No — complementary means sum 90 and difference 30: the angles are 60° and 30°, so the larger is 60°.

Q43

On two parallel lines, the bisectors of a pair of co-interior angles meet at:

  • A90°✓
  • B45°
  • C60°
  • D180°

Working

✓

The bisectors of two supplementary co-interior angles meet at a right angle, 90°.

Q44

An angle that is seven times its complement measures:

  • A11.25°
  • B70°
  • C78.75°✓
  • D82°

Working

✓

x = 7(90 − x) → x = 630 − 7x → 8x = 630 → x = 78.75°.

✓
