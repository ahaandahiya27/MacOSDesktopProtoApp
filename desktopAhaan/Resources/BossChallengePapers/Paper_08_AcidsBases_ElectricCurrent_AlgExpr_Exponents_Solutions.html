Q1Acids, Bases & Salts A liquid turns blue litmus red but leaves red litmus unchanged. What can you safely conclude?
(A) It is basic.
(B) It is a salt and so always basic.
(C) It is acidic. ✓
(D) It is neutral.
Correct answer: C

The idea Acids turn blue litmus red; bases turn red litmus blue; a neutral liquid changes neither.

Blue litmus -> red => an acid is present

So the liquid is acidic.

Where you meet it in real life This is exactly how a lab tests an unknown liquid with a single strip of litmus.

Why the other options miss
  • A: A base would turn the RED litmus blue, which did not happen.
  • B: Salts can be acidic, basic OR neutral; 'always basic' is false.
  • D: A neutral liquid changes neither colour, but here blue litmus turned red.
