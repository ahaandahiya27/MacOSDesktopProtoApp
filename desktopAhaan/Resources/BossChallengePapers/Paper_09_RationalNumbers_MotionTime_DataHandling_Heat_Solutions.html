Q1Rational Numbers A number is called rational only if it can be written as p/q where p and q are integers and:
(A) p is zero
(B) q is zero
(C) p equals q
(D) q is not zero ✓
Correct answer: D

The idea A rational number is a ratio p/q of integers. Division by zero has no meaning, so the bottom number must not be zero.

Rational means a ratio p/q
p and q are integers
q can be anything EXCEPT 0, since dividing by 0 is undefined.

Where you meet it in real life This is why a calculator shows 'error' if you ever divide by zero.

Why the other options miss
  • A: p may be zero (0/5 = 0 is rational); it is q that must not be zero.
  • B: If q were zero the fraction would be undefined, so this is exactly what is NOT allowed.
  • C: p and q need not be equal; 2/3 is perfectly rational.
